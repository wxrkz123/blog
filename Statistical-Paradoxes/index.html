统计学里有一类现象，第一次见到时会让人怀疑自己算错了。它们不是数学游戏，而是在新闻、政策评估和论文中反复出现的真实错误。这篇文章讲四个最常见的，每个都配一个真实的故事和一段很短的模拟代码，读完以后，你会在很多地方认出它们。

所有代码只用到 NumPy 和 pandas：

import numpy as np
import pandas as pd

一、辛普森悖论：分开看和合起来看，结论相反

伯克利的招生数据

1973 年秋季，加州大学伯克利分校研究生院的录取数据显示，男生的录取率明显高于女生。学校担心被起诉性别歧视，统计学家 Bickel 等人（1975）仔细分析了这份数据。下面是申请人数最多的 6 个系（为了保密，系名用字母代替）：

ucb = pd.DataFrame(
    [("A", 512, 825, 89, 108), ("B", 353, 560, 17, 25), ("C", 120, 325, 202, 593),
     ("D", 138, 417, 131, 375), ("E", 53, 191, 94, 393), ("F", 22, 373, 24, 341)],
    columns=["系", "男录取", "男申请", "女录取", "女申请"]).set_index("系")
ucb["男录取率"] = ucb["男录取"] / ucb["男申请"]
ucb["女录取率"] = ucb["女录取"] / ucb["女申请"]
print(ucb[["男申请", "男录取率", "女申请", "女录取率"]].round(2).to_string())
total = ucb.sum()
print(f"合计：男 {total['男录取'] / total['男申请']:.1%}，女 {total['女录取'] / total['女申请']:.1%}")
   男申请  男录取率  女申请  女录取率
系
A  825  0.62  108  0.82
B  560  0.63   25  0.68
C  325  0.37  593  0.34
D  417  0.33  375  0.35
E  191  0.28  393  0.24
F  373  0.06  341  0.07
合计：男 44.5%，女 30.4%

合起来看，男生的录取率比女生高 14 个百分点；分到每个系看，6 个系中有 4 个是女生的录取率更高（A 系高出 20 个百分点），另外两个系男生也只高 3～4 个百分点。没有哪个系明显偏向男生，合起来却差了这么多。

原因在申请人数那两列：男生大多申请录取率高的系，女生大多申请录取率低的系。

ucb["系录取率"] = (ucb["男录取"] + ucb["女录取"]) / (ucb["男申请"] + ucb["女申请"])
easy = ucb.index[:2]                              # A、B 两系的录取率超过 60%
print(f"A、B 两系的总录取率：{ucb.loc[easy, '系录取率'].round(2).tolist()}")
print(f"申请 A、B 两系的比例：男 {ucb.loc[easy, '男申请'].sum() / total['男申请']:.0%}，"
      f"女 {ucb.loc[easy, '女申请'].sum() / total['女申请']:.0%}")

# 假设女生和男生一样分布在各系（用男生的申请分布加权），女生的录取率是多少？
w = ucb["男申请"] / total["男申请"]
print(f"按男生的申请分布加权：男 {(w * ucb['男录取率']).sum():.1%}，女 {(w * ucb['女录取率']).sum():.1%}")
A、B 两系的总录取率：[0.64, 0.63]
申请 A、B 两系的比例：男 51%，女 7%
按男生的申请分布加权：男 44.5%，女 51.6%

男生有一半申请了 A、B 这两个容易录取的系，女生只有 7%。如果女生按照和男生相同的比例申请各个系，她们的录取率反而比男生高。总录取率的差距来自申请的去向，而不是各系的录取决定。

一个连续变量的例子

同样的现象也会出现在回归中。假设我们调查了三个年龄段的人每周的运动时间和胆固醇水平：年龄越大，胆固醇越高，而年纪大的人也恰好运动更多；在每个年龄段内部，运动越多，胆固醇越低。

rng = np.random.default_rng(1)
groups = []
for k, age in enumerate([30, 45, 60]):
    x = rng.normal(2 + 2 * k, 0.8, 200)                           # 每周运动小时数，年纪大的运动更多
    y = 150 + 1.2 * age - 6 * (x - (2 + 2 * k)) + rng.normal(0, 8, 200)
    groups.append(pd.DataFrame({"年龄": age, "运动": x, "胆固醇": y}))
health = pd.concat(groups, ignore_index=True)

slope = lambda d: np.polyfit(d["运动"], d["胆固醇"], 1)[0]
print(f"所有人一起回归：运动每多 1 小时，胆固醇 {slope(health):+.1f}")
for age, d in health.groupby("年龄"):
    print(f"  {age} 岁左右：{slope(d):+.1f}")
所有人一起回归：运动每多 1 小时，胆固醇 +6.2
  30 岁左右：-5.6
  45 岁左右：-6.0
  60 岁左右：-5.9

所有人放在一起，看起来“运动越多胆固醇越高”；每个年龄组内部，都是运动越多胆固醇越低。把年龄放进回归，就能得到组内的关系。

该相信哪一个？

辛普森悖论最让人困惑的地方是：数据本身不能告诉你该相信合起来的结果还是分开的结果。答案取决于变量之间的因果关系：

  • 运动的例子中，年龄同时影响运动和胆固醇，是混杂因素，应当控制，分组的结果才是运动的作用；
  • 招生的例子中，申请哪个系是性别影响录取的中间环节。如果问题是“各系在录取时有没有歧视”，应当比较同一个系内的录取率；如果问题是“女生整体上是否更难进入研究生院”，合计的数字也有意义，只是原因不在录取环节，而在申请之前（比如女生集中申请的院系名额本来就少）。

用因果图想清楚该控制什么，见因果推断系列的第 01 篇。

二、伯克森悖论：筛选出来的负相关

好论文为什么总是“要么严谨，要么有趣”？

很多研究生都有这种感觉：顶级期刊上的论文，方法特别严谨的往往结论平淡，结论特别有趣的往往方法有漏洞。是严谨和有趣天生互相矛盾吗？

用一个简单的模拟检验这个想法：一万篇投稿，严谨程度和新颖程度完全独立；审稿人看的是两者之和，超过门槛才能发表：

rng = np.random.default_rng(2)
rigor, novelty = rng.normal(size=10_000), rng.normal(size=10_000)
published = rigor + novelty > 2
print(f"发表率：{published.mean():.1%}")
print(f"全部投稿中，严谨与新颖的相关系数：{np.corrcoef(rigor, novelty)[0, 1]:+.2f}")
print(f"已发表的论文中：{np.corrcoef(rigor[published], novelty[published])[0, 1]:+.2f}")
发表率：8.2%
全部投稿中，严谨与新颖的相关系数：+0.01
已发表的论文中：-0.71

在全部投稿中，两者毫不相关；只看发表了的论文，相关系数变成了强烈的负数。原因很简单：一篇不太严谨的论文能发表，一定是因为它特别新颖，反过来也一样。筛选条件同时依赖两个变量时，在筛选后的样本里，这两个变量会出现虚假的负相关。

这个现象以医学统计学家 Berkson（1946）命名。他注意到，用住院病人做研究时，两种本来无关的疾病会显得负相关（或正相关），因为一个人得了其中任何一种都可能住院，住院病人这个样本本身就是筛选出来的。生活中的例子很多：

  • “长得好看的人性格都不好”：你只会和至少在一方面有吸引力的人交往；
  • “名校毕业生的工作能力并不比普通学校的强”：只看同一家公司录用的人，学历不够好的人一定在其他方面更突出；
  • “有工作的女性中，教育程度和工资的关系”：只有工资足够高的人才会选择工作，这是样本选择模型要解决的问题。

在因果图里，“发表”是严谨和新颖共同的结果，叫做对撞变量（collider）。以对撞变量为条件（只看它的某个取值，或者把它放进回归）就会制造出虚假的相关。这也是为什么回归中不能随便加入“坏控制”：见内生性系列的第 01 篇。

三、幸存者偏差：看不见的失败者

飞机上的弹孔

二战期间，美国哥伦比亚大学的统计研究小组（Statistical Research Group）研究过怎样根据返航飞机的损伤来判断飞机的哪些部位最需要保护。流传最广的版本是：军方想在弹孔最多的地方加装装甲，统计学家 Abraham Wald 指出应该反过来，加在没有弹孔的地方，因为那些部位中弹的飞机根本没能飞回来。

这个故事在流传中被简化和加工过：Wald 当时写的是一系列技术报告，用数学方法从幸存飞机的损伤推算各部位的易损程度（Mangel 和 Samaniego 1984 年整理了这些工作）。但核心的道理是一样的：只看幸存下来的样本，会系统性地误判。

基金的业绩

金融研究里，幸存者偏差是一个具体的、可以度量的问题。业绩差的基金会被清盘或者合并，从数据库中消失；如果只用现在还存在的基金计算平均业绩，就会高估基金经理的能力。

模拟 2000 只基金，每只基金每年相对于市场的超额收益是均值为 0、标准差 10% 的随机数，也就是说，没有任何基金经理有真正的选股能力；累计超额收益跌破 -15% 的基金当年清盘：

rng = np.random.default_rng(3)
n_funds, n_years = 2000, 10
excess = rng.normal(0, 0.10, (n_funds, n_years))      # 每年的超额收益，真实均值为 0
alive = np.ones(n_funds, dtype=bool)
life = np.full(n_funds, n_years)                     # 每只基金存续了几年
cum = np.zeros(n_funds)
for t in range(n_years):
    cum += np.where(alive, excess[:, t], 0)
    closed = alive & (cum < -0.15)
    life[closed] = t + 1
    alive &= ~closed

observed = [excess[i, :life[i]].mean() for i in range(n_funds)]   # 每只基金存续期间的平均超额收益
print(f"10 年后还存在的基金：{alive.mean():.0%}")
print(f"只看存活的基金：平均每年超额收益 {excess[alive].mean():+.2%}")
print(f"包括清盘的基金（各自存续期间）：{np.mean(observed):+.2%}")
10 年后还存在的基金：49%
只看存活的基金：平均每年超额收益 +2.23%
包括清盘的基金（各自存续期间）：-2.77%

一半的基金在 10 年内被清盘。只看活下来的基金，它们平均每年跑赢市场 2 个百分点左右，看起来基金经理很有本事；但这完全是筛选的结果。反过来，把清盘基金也算进来，平均超额收益是负的：清盘的基金恰恰是因为运气差才被淘汰的，它们存续期间的业绩当然低于 0。两种算法都不等于真实的 0，正确的做法是把每只基金每一年的收益都计入（不管它后来是否清盘），这需要一个没有幸存者偏差的数据库，保留已经消失的基金。Brown 等（1992）和 Elton、Gruber 和 Blake（1996）对这个问题做了系统的研究。

类似的例子：只研究现在还在上市的公司（退市的公司被排除）；“成功人士都是大学辍学”（没有统计辍学后不成功的人）；“老房子质量都很好”（质量差的早就拆了）。

四、均值回归：什么都不做也会“进步”

高尔顿的身高数据

“回归”这个词就来自这个现象。19 世纪 80 年代，高尔顿（Galton 1886）研究父母和子女的身高时发现：特别高的父母，子女通常也高，但没有父母那么高；特别矮的父母，子女通常也矮，但没有那么矮。子女的身高“回归”到平均水平。他称之为“向平庸回归”（regression towards mediocrity）。

这不是什么生物学规律，而是任何两次测量不完全相关的变量都会出现的统计现象。

补习班的“效果”

一个班 1000 个学生，每个学生的真实水平不同；每次考试的成绩等于真实水平加上运气（当天的状态、题目是否正好复习到）。第一次考试后，学校给成绩最差的 10% 安排了补习，第二次考试他们平均提高了很多。补习有效吗？

rng = np.random.default_rng(4)
ability = rng.normal(70, 8, 1000)                  # 真实水平
test1 = ability + rng.normal(0, 6, 1000)           # 两次考试的运气相互独立
test2 = ability + rng.normal(0, 6, 1000)           # 第二次考试前，没有人做任何事
low, high = test1 <= np.quantile(test1, 0.1), test1 >= np.quantile(test1, 0.9)
print(f"第一次最差的 10%：{test1[low].mean():.1f} → {test2[low].mean():.1f}")
print(f"第一次最好的 10%：{test1[high].mean():.1f} → {test2[high].mean():.1f}")
print(f"用第一次成绩预测第二次的斜率：{np.polyfit(test1, test2, 1)[0]:.2f}")
第一次最差的 10%：51.8 → 58.9
第一次最好的 10%：87.2 → 80.4
用第一次成绩预测第二次的斜率：0.63

这次模拟里没有任何补习，成绩最差的 10% 第二次平均提高了 7 分，最好的 10% 下降了 7 分左右。原因是：第一次考得特别差的人，除了水平较低，大多还碰上了坏运气；第二次的运气是重新抽的，平均来说会好一些。

均值回归的例子到处都是：

  • 心理学家卡尼曼（Kahneman 2011，第 17 章）讲过，以色列空军的飞行教官相信“批评比表扬有效”：学员飞得特别好受到表扬后，下一次往往变差；飞得特别差受到批评后，下一次往往变好。其实无论教官说什么，都会这样；
  • 体育杂志的“封面诅咒”：表现最好的那个赛季上了封面，下个赛季往往变差；
  • 交通事故最多的路口装了摄像头，第二年事故明显减少；
  • 收入突然下降的人报名参加了职业培训，培训后收入回升（这叫 Ashenfelter 的下沉，Ashenfelter 1978）。

后两个例子是政策评估中的大问题：项目往往在问题最严重的时候启动，即使项目毫无作用，结果也会改善。解决办法是找一个同样经历了低谷、但没有接受处理的对照组，比较两组的变化，这正是双重差分的思路。

五、共同的教训

现象 发生了什么 怎样避免
辛普森悖论 第三个变量同时影响分组和结果，合起来和分开的结论相反 想清楚因果关系，决定应该控制什么
伯克森悖论 样本是按两个变量的组合筛选出来的，筛选制造了相关 问一句“这个样本是怎么来的”，不要以对撞变量为条件
幸存者偏差 失败的个体从数据中消失了 使用保留了退出者的数据，或者至少报告退出率
均值回归 按极端值挑出来的个体，下一次会自然地回到平均 不要只看处理组的前后变化，要有对照组

四个现象的共同点是：数据是怎样产生的、样本是怎样选出来的，往往比数据里的数字更重要。拿到一份数据时，先问三个问题：谁在这个样本里，谁不在？他们是怎样被选进来的？如果没有任何处理，结果会怎样变化？

更多这类错误，见实证研究最常见的 20 个错误。
