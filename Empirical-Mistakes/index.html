实证研究最常见的 20 个错误

这篇文章把这个博客各个系列中反复出现的错误汇总在一起。它们有几个共同点：程序不会报错，结果看起来很合理，而且很常见。每条错误都有一段解释，大部分附了一个几行代码的模拟，用已知答案的数据演示错误有多大，最后链接到详细讲解的文章。

所有模拟共用下面的准备代码：

import numpy as np
import pandas as pd
import statsmodels.api as sm
import statsmodels.formula.api as smf
import warnings
warnings.simplefilter("ignore")

def ols(y, X):
    """最小二乘的系数和常规标准误，用于大量重复的模拟。"""
    X = np.column_stack([np.ones(len(y)), X])
    b, *_ = np.linalg.lstsq(X, y, rcond=None)
    e = y - X @ b
    V = e @ e / (len(y) - X.shape[1]) * np.linalg.inv(X.T @ X)
    return b, np.sqrt(np.diag(V))
print("ok")
ok

一、数据阶段

1. 合并之后不检查行数

一对一的合并，行数不应该变化。如果右表中的键有重复（同一家公司有两条行业记录、同一天有两条价格），合并后左表的行会被复制，之后的求和、平均、回归都被重复计算，而且不会有任何提示：

firms = pd.DataFrame({"firm": [1, 2, 3], "assets": [100, 200, 300]})
industry = pd.DataFrame({"firm": [1, 2, 2, 3], "ind": ["银行", "电子", "通信", "医药"]})   # 公司 2 有两条记录
merged = firms.merge(industry, on="firm")
print(len(firms), "→", len(merged), "  总资产：", firms["assets"].sum(), "→", merged["assets"].sum())
try:
    firms.merge(industry, on="firm", validate="one_to_one")
except pd.errors.MergeError as e:
    print("validate 参数直接报错：", str(e).splitlines()[0])
3 → 4   总资产： 600 → 800
validate 参数直接报错： Merge keys are not unique in right dataset; not a one-to-one merge

做法：每次合并都写 validate，合并前后打印行数。详见SQL 系列第 03 篇和实证研究工作流第 03 篇。

2. 缺失值让每个回归的样本悄悄变化

统计软件会自动删掉有缺失值的观测。不同的回归用了不同的控制变量，样本就不同，各列之间的系数变化可能来自样本变化，而不是控制变量的作用：

rng = np.random.default_rng(1)
n = 1000
df = pd.DataFrame({"x": rng.normal(size=n), "z": rng.normal(size=n)})
df["y"] = 1 + 0.5 * df["x"] + rng.normal(size=n)
df.loc[df["y"] > 1.5, "z"] = np.nan                 # 控制变量 z 只在 y 较大时缺失
m1 = smf.ols("y ~ x", data=df).fit()
m2 = smf.ols("y ~ x + z", data=df).fit()
print(f"不加 z：n = {int(m1.nobs)}，x 的系数 {m1.params['x']:.3f}")
print(f"加上 z：n = {int(m2.nobs)}，x 的系数 {m2.params['x']:.3f}")
不加 z：n = 1000，x 的系数 0.470
加上 z：n = 675，x 的系数 0.243

z 和 y 毫无关系，加上它本不应该改变 x 的系数。系数变小，完全是因为 z 的缺失删掉了 y 较大的观测（按被解释变量筛选样本会让系数偏向 0）。做法：先确定一个所有回归共用的样本，在表格中报告每一列的观测数。详见实证研究工作流第 03 篇。

3. 前视偏差

用了在当时还无法得到的信息。典型的例子：用 12 月 31 日的年报数据在 1 月份构造投资组合（年报通常要到次年 3–4 月才公布）；用整个样本的均值和标准差标准化一个预测变量；用今天的指数成分股回测十年前的策略。做法：对每个变量问一句“在决策的那一刻，我真的知道这个值吗？”，用公告日而不是报告期对齐数据。详见金融实证系列第 04 篇和期货回测系列第 03 篇。

4. 幸存者偏差

只看到“活下来”的样本。如果数据库里只有现在还存在的基金或公司，表现差而倒闭、退市的那些就消失了，平均表现被高估：

rng = np.random.default_rng(2)
ret = rng.normal(0.0, 0.15, size=(5000, 10))         # 5000 只基金 10 年的年收益，真实平均为 0
wealth = np.cumprod(1 + ret, axis=1)
alive = wealth.min(axis=1) > 0.7                     # 净值曾经跌破 0.7 的基金被清盘
print(f"全部基金的平均年收益：{ret.mean():.2%}")
print(f"活下来的 {alive.mean():.0%} 的基金：{ret[alive].mean():.2%}")
全部基金的平均年收益：0.03%
活下来的 56% 的基金：2.94%

做法：使用包含已退市、已清盘个体的数据库（这正是付费数据库的价值之一），并说明样本是怎样构造的。

5. 单位和口径不一致

收益率一会儿是百分比、一会儿是小数（SQL 系列第 04 篇的数据就是小数）；金额有的是元、有的是万元；名义值和实际值混用；季度数据和年度数据直接合并。这类错误会让系数差 100 倍或者完全没有意义。做法：每个变量在数据字典里写明单位，读入后用 describe() 看一眼数值范围是否合理。

二、回归设定

6. 遗漏变量偏差

遗漏了一个同时影响被解释变量、又和解释变量相关的变量，系数就吸收了它的作用：

rng = np.random.default_rng(3)
n = 5000
ability = rng.normal(size=n)
educ = 12 + 2 * ability + rng.normal(size=n)
wage = 1 + 0.08 * educ + 0.2 * ability + rng.normal(0, 0.3, size=n)
print(f"真实的教育回报 0.080；遗漏能力：{ols(wage, educ)[0][1]:.3f}；控制能力：{ols(wage, np.column_stack([educ, ability]))[0][1]:.3f}")
真实的教育回报 0.080；遗漏能力：0.160；控制能力：0.085

做法：写出你认为影响结果的所有因素，逐个想清楚它是否和解释变量相关；无法控制时，需要工具变量、面板固定效应、DID 等识别策略。详见回归系列第 03 篇和第 09 篇。

7. 坏控制：控制了不该控制的变量

“控制变量越多越好”是错的。控制了处理变量的结果（中介变量），会把一部分真实效应控制掉；控制了处理和结果的共同结果（对撞变量），会凭空制造出相关：

rng = np.random.default_rng(4)
n = 5000
talent = rng.normal(size=n)                          # 才华
looks = rng.normal(size=n)                           # 外貌，和才华毫无关系
famous = (talent + looks + rng.normal(size=n) > 1.5).astype(float)   # 出名取决于两者
b_all = ols(looks, talent)[0][1]
b_ctrl = ols(looks, np.column_stack([talent, famous]))[0][1]
b_sub = ols(looks[famous == 1], talent[famous == 1])[0][1]
print(f"全部样本：{b_all:.3f}；控制“是否出名”：{b_ctrl:.3f}；只看名人：{b_sub:.3f}")
全部样本：-0.022；控制“是否出名”：-0.201；只看名人：-0.392

才华和外貌本来无关，但只要控制了“是否出名”，或者只研究名人，两者就呈现出负相关。做法：只控制在处理发生之前就已经确定的变量；用因果图判断该控制什么。详见因果推断系列第 01 篇。

8. 用 R² 判断模型好坏或因果关系

R² 衡量的是拟合程度，不是因果关系是否可信。一个识别得很好的随机实验，R² 可能只有 0.02；一个充满内生性的回归，R² 可以高达 0.9（比如两个都有时间趋势的序列，见第 19 条）。做法：判断一个回归可不可信，看识别策略，不看 R²。详见回归系列第 02 篇。

9. 用 log(y+1) 处理 0

被解释变量有很多 0 时（专利数、贸易额、捐款），常见的做法是取 。但这个变换的系数既不是弹性也不是百分比变化，而且结果随加的常数（1、0.01、1000）大幅变化，取决于 的单位。做法：计数数据用泊松回归或 PPML，0 和正值分开建模，或者报告 0 的比例和正值部分的结果。详见计量进阶系列第 04 篇。

10. 把 Logit 的系数当成边际效应

非线性模型的系数不能像线性回归那样直接解释：

rng = np.random.default_rng(5)
n = 5000
x = rng.normal(size=n)
y = (rng.uniform(size=n) < 1 / (1 + np.exp(-(-1 + 0.8 * x)))).astype(int)
logit = sm.Logit(y, sm.add_constant(x)).fit(disp=0)
ame = logit.get_margeff(at="overall").margeff[0]
lpm = sm.OLS(y, sm.add_constant(x)).fit().params[1]
print(f"Logit 系数 {logit.params[1]:.3f}；平均边际效应 {ame:.3f}；线性概率模型 {lpm:.3f}")
Logit 系数 0.753；平均边际效应 0.141；线性概率模型 0.140

Logit 的系数约 0.75，它是对数几率的变化；x 增加 1 个单位，发生的概率实际上平均只增加约 0.14，和线性概率模型的结果几乎一样。做法：报告平均边际效应；交互项在非线性模型中的解释更复杂，要计算交叉偏导数。详见回归系列第 11 篇。

三、统计推断

11. 标准误没有聚类，或者聚类在了错误的层级

处理在省份层面分配（比如某些省份实施了政策），而误差项在同一省份内相关，常规标准误会严重低估不确定性：

rng = np.random.default_rng(6)
G, m, reps = 50, 40, 500                     # 50 个省份，每省 40 个观测
rej_ols = rej_cl = 0
g = np.repeat(np.arange(G), m)
for _ in range(reps):
    d = np.repeat(rng.integers(0, 2, G), m).astype(float)      # 政策在省份层面分配，真实效应为 0
    y = np.repeat(rng.normal(size=G), m) + rng.normal(size=G * m)
    fit = sm.OLS(y, sm.add_constant(d))
    rej_ols += abs(fit.fit().tvalues[1]) > 1.96
    rej_cl += abs(fit.fit(cov_type="cluster", cov_kwds={"groups": g}).tvalues[1]) > 1.96
print(f"名义水平 5%；常规标准误的拒绝率 {rej_ols / reps:.0%}，按省份聚类 {rej_cl / reps:.0%}")
名义水平 5%；常规标准误的拒绝率 62%，按省份聚类 5%

真实效应为 0，常规标准误却在一半以上的模拟中“发现”了显著的效应。做法：至少在处理分配的层级上聚类。详见回归系列第 08 篇和DID 系列第 08 篇。

12. 聚类太少时仍然使用聚类标准误

聚类标准误依赖“聚类数很多”的大样本理论。只有十几个省份、几个行业时，它仍然会低估不确定性。做法：聚类数少于 30–50 个时，用野自助法（wild cluster bootstrap）或随机化推断。详见DID 系列第 08 篇。

13. “一个显著、一个不显著”不等于两者有显著差异

男性样本中系数显著，女性样本中不显著，于是得出结论“效应存在性别差异”。这是最常见的统计错误之一：

b1, se1 = 0.25, 0.10          # 男性：t = 2.5，显著
b2, se2 = 0.10, 0.10          # 女性：t = 1.0，不显著
diff, se_diff = b1 - b2, np.sqrt(se1 ** 2 + se2 ** 2)
print(f"差异 {diff:.2f}，标准误 {se_diff:.3f}，t = {diff / se_diff:.2f}")
差异 0.15，标准误 0.141，t = 1.06

两个系数的差异只有 1 个标准误左右，远远不显著。做法：直接检验差异（交互项或者上面的差异检验）。详见金融实证系列第 08 篇和计量进阶系列第 07 篇。

14. 多重检验与 p-hacking

尝试足够多的设定、变量、子样本，总能找到一个显著的结果：

rng = np.random.default_rng(7)
reps, k, n = 1000, 20, 200
found = 0
for _ in range(reps):
    y = rng.normal(size=n)
    X = rng.normal(size=(n, k))               # 20 个和 y 毫无关系的候选变量
    t = [abs(ols(y, X[:, j])[0][1] / ols(y, X[:, j])[1][1]) for j in range(k)]
    found += max(t) > 1.96
print(f"试 20 个无关变量，至少一个“显著”的概率：{found / reps:.0%}（理论值 1 − 0.95^20 = {1 - 0.95 ** 20:.0%}）")
试 20 个无关变量，至少一个“显著”的概率：68%（理论值 1 − 0.95^20 = 64%）

做法：事先确定主要设定（预注册或至少写在研究笔记里）；报告所有尝试过的设定；必要时做多重检验校正。详见统计学基础第 08 篇。

15. 把“不显著”当成“没有效应”

不显著只说明数据不足以排除 0，可能是效应真的很小，也可能只是样本太小、检验功效太低：

rng = np.random.default_rng(8)
reps = 2000
for n in [50, 200, 1000]:
    sig = 0
    for _ in range(reps):
        d = rng.integers(0, 2, n)
        y = 0.2 * d + rng.normal(size=n)          # 真实效应 0.2 个标准差
        b, se = ols(y, d)
        sig += abs(b[1] / se[1]) > 1.96
    print(f"n = {n:4d}：检验功效 {sig / reps:.0%}")
n =   50：检验功效 11%
n =  200：检验功效 30%
n = 1000：检验功效 89%

真实效应是 0.2 个标准差，但样本只有 50 个时，近九成的研究会得到“不显著”；即使有 200 个观测，也有七成得不到显著的结果。做法：报告置信区间而不只是 p 值，说明数据能排除多大的效应；研究设计阶段先做功效分析。详见统计学基础第 07 篇。

四、因果识别

16. 用“事前系数不显著”证明平行趋势

事件研究图中处理前的系数都不显著，常被当作“平行趋势成立”的证明。但不显著可能只是功效太低（第 15 条），而且即使事前趋势很平行，也不能保证事后的反事实趋势平行；只报告通过预检验的设定，还会让估计有偏。做法：报告事前系数的置信区间，做对平行趋势偏离的敏感性分析（如 HonestDiD）。详见DID 系列第 11 篇。

17. 交错 DID 直接用双向固定效应

不同个体在不同时间接受处理、处理效应随时间变化时，双向固定效应（TWFE）回归会把已经处理的个体当作对照组，得到的系数可能和每一个个体的真实效应符号都相反。做法：用 Callaway–Sant’Anna、Sun–Abraham、插补法等异质性稳健的估计量，并用 Goodman-Bacon 分解检查 TWFE 的权重。详见DID 系列第 09 篇和第 10 篇。

18. 弱工具变量

工具变量和内生变量的相关性很弱时，IV 估计量严重偏向 OLS，常规的置信区间也不可信。“工具变量在第一阶段显著”远远不够。做法：报告第一阶段的 F 统计量（经验门槛 10，更严格的标准更高），用对弱工具变量稳健的检验（如 Anderson–Rubin 检验）。详见因果推断系列第 08 篇。

五、时间序列与预测

19. 伪回归

两个互相独立的随机游走（比如两个都有趋势的宏观序列）做回归，经常得到高度显著的系数和很高的 R²：

rng = np.random.default_rng(9)
reps, T = 1000, 200
rej, r2 = 0, []
for _ in range(reps):
    y, x = rng.normal(size=(2, T)).cumsum(axis=1)       # 两个互相独立的随机游走
    b, se = ols(y, x)
    rej += abs(b[1] / se[1]) > 1.96
    r2.append(np.corrcoef(x, y)[0, 1] ** 2)
print(f"两个独立的随机游走：{rej / reps:.0%} 的回归“显著”，R² 的中位数 {np.median(r2):.2f}")
两个独立的随机游走：85% 的回归“显著”，R² 的中位数 0.17

做法：先检验单位根；非平稳的序列用差分，或者在协整的框架下分析。详见时间序列系列第 03 篇和第 08 篇。

20. 数据泄漏与样本内选模型

在全部数据上挑选“最好的”模型或策略，再在同一份数据上报告它的表现，结果一定过于乐观：

rng = np.random.default_rng(10)
n_strategies, T = 200, 240
rets = rng.normal(0, 0.04, size=(n_strategies, 2 * T))     # 200 个毫无预测能力的策略，各 40 年月收益
ins, oos = rets[:, :T], rets[:, T:]
sharpe = lambda r: r.mean(axis=-1) / r.std(axis=-1) * np.sqrt(12)
best = sharpe(ins).argmax()
print(f"样本内最好的策略：夏普比率 {sharpe(ins)[best]:.2f}；同一个策略在样本外：{sharpe(oos[best]):.2f}")
样本内最好的策略：夏普比率 0.59；同一个策略在样本外：-0.42

同样的问题发生在：用全样本的统计量做标准化或特征选择后再做交叉验证；反复修改策略直到“样本外”表现好看（样本外也就变成了样本内）。做法：所有的选择都只用训练数据完成；真正的样本外数据只用一次。详见机器学习系列第 03 篇和期货回测系列第 10 篇。

投稿前的检查清单

数据

  • 每次合并都检查了行数和键的唯一性
  • 所有回归使用同一个样本，表中报告了观测数
  • 每个变量在决策时点都是可以得到的
  • 样本包含已退出的个体，或者说明了幸存者偏差的方向
  • 变量的单位、口径一致，并写在了数据字典里

设定

  • 控制变量都在处理之前确定，没有控制中介变量或对撞变量
  • 没有用 R² 论证因果关系
  • 计数和有 0 的数据没有用 log(y+1)
  • 非线性模型报告了边际效应

推断

  • 标准误至少聚类在处理分配的层级；聚类数少时用了野自助法
  • 比较两组效应时直接检验了差异
  • 报告了所有尝试过的设定，而不只是显著的那个
  • 不显著的结果报告了置信区间和功效

识别

  • 平行趋势做了敏感性分析，而不只是预检验
  • 交错处理用了异质性稳健的估计量
  • 报告了工具变量第一阶段的 F 统计量

时间序列与预测

  • 检验了单位根，没有对非平稳序列做水平值回归
  • 模型选择只用了训练数据，样本外数据只用了一次

最后一条适用于所有情况：每个结果都能从原始数据一键重新生成（实证研究工作流第 01 篇）。很多错误是在复现自己结果的时候才被发现的。
