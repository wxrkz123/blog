电脑最擅长的事情就是计算。这一篇我们把 Python 当成一个超级计算器，学会各种计算方法。

## 一、在交互模式里当计算器用

打开 IDLE，在带 `>>>` 的窗口里，直接输入算式并回车，Python 会马上告诉你结果：

```python
>>> 3 + 5
8
>>> 10 - 7
3
```

做简单计算时，交互模式比写文件方便得多。本篇前半部分都用这种方式演示，你可以跟着一起输入。

## 二、基本运算

### 加减乘除

| 运算 | 数学符号 | Python 写法 | 例子 | 结果 |
|---|---|---|---|---|
| 加 | + | `+` | `3 + 2` | `5` |
| 减 | − | `-` | `3 - 2` | `1` |
| 乘 | × | `*` | `3 * 2` | `6` |
| 除 | ÷ | `/` | `3 / 2` | `1.5` |

乘号和除号跟数学里长得不一样，因为键盘上没有 `×` 和 `÷`：

- 乘号是 `*`（星号，按 `Shift + 8`）；
- 除号是 `/`（斜杠，在键盘右下角，问号的下面）。

```python
>>> 6 * 7
42
>>> 10 / 4
2.5
```

### 除法的结果总是带小数点

注意下面这个例子：

```python
>>> 10 / 2
5.0
```

10 除以 2 明明等于 5，为什么显示 `5.0`？

因为在 Python 里，**用 `/` 做除法，结果总是小数**，哪怕刚好能除尽。`5.0` 和 `5` 的值是一样的，只是写法不同。下面马上解释整数和小数的区别。

### 整除和取余

小学时我们学过“有余数的除法”：17 ÷ 5 = 3 …… 2。Python 也能做：

| 运算 | Python 写法 | 例子 | 结果 | 意思 |
|---|---|---|---|---|
| 整除 | `//` | `17 // 5` | `3` | 商是多少（去掉小数部分） |
| 取余 | `%` | `17 % 5` | `2` | 余数是多少 |

```python
>>> 17 // 5
3
>>> 17 % 5
2
```

取余（`%`）看起来没什么用，其实非常常用。比如：

**判断一个数是奇数还是偶数**：除以 2 余 0 就是偶数，余 1 就是奇数。

```python
>>> 10 % 2
0
>>> 7 % 2
1
```

**把分钟换算成“几小时几分钟”**：

```python
>>> 135 // 60
2
>>> 135 % 60
15
```

135 分钟就是 2 小时 15 分钟。

### 乘方

“2 的 10 次方”在 Python 里写成 `2 ** 10`（两个星号）：

```python
>>> 2 ** 10
1024
>>> 3 ** 2
9
```

Python 的整数可以非常大，不用担心算不下：

```python
>>> 2 ** 100
1267650600228229401496703205376
```

## 三、运算顺序

Python 的运算顺序和数学一样：**先乘方，再乘除，后加减；有括号先算括号里的。**

```python
>>> 2 + 3 * 4
14
>>> (2 + 3) * 4
20
```

第一个式子先算 `3 * 4 = 12`，再加 2 得 14；第二个先算括号里的 `2 + 3 = 5`，再乘 4 得 20。

注意：Python 里**只有小括号** `()`。数学里的中括号、大括号，在 Python 里都要写成小括号，可以一层套一层：

```python
>>> ((1 + 2) * 3 + 1) * 2
20
```

> 💡 **小建议**：如果你不确定运算顺序，**就加括号**。多加的括号不会出错，还能让代码更容易看懂。

## 四、整数和小数

Python 里的数字主要有两种：

| 类型 | 英文名 | 例子 | 说明 |
|---|---|---|---|
| 整数 | `int` | `18`、`-5`、`0` | 没有小数点 |
| 小数 | `float` | `3.14`、`-0.5`、`5.0` | 有小数点，也叫“浮点数” |

可以用 `type()` 查看一个数据是什么类型：

```python
>>> type(18)
<class 'int'>
>>> type(3.14)
<class 'float'>
>>> type(5.0)
<class 'float'>
```

`<class 'int'>` 的意思是“这是一个 int（整数）类型的数据”。你现在只需要关心引号里的 `int` 或 `float`。

整数和小数可以一起计算，结果是小数：

```python
>>> 3 + 0.5
3.5
>>> 2 * 1.5
3.0
```

### 一个奇怪的现象：0.1 + 0.2

试试这个：

```python
>>> 0.1 + 0.2
0.30000000000000004
```

结果不是 0.3，而是 0.30000000000000004！这是 Python 算错了吗？

不是 Python 的问题。电脑内部用二进制（只有 0 和 1）存储小数，而 0.1 这样的小数在二进制里是一个无限循环小数，就像 1/3 在十进制里是 0.3333…… 一样，只能存一个非常接近的近似值。所以小数计算偶尔会有极小的误差，几乎所有编程语言都这样。

日常使用中，用 `round()` 把结果保留几位小数就可以了：

```python
>>> round(0.1 + 0.2, 2)
0.3
>>> round(3.14159, 2)
3.14
```

`round(数字, 位数)` 表示“把数字四舍五入，保留几位小数”。

> 如果你以后要做精确的金额计算，可以使用 Python 自带的 `decimal` 模块，不过那是后话了，现在知道有这么回事就行。

## 五、在程序里计算

交互模式适合随手算算，真正写程序时，我们通常把数字存进变量再计算。在 IDLE 里新建文件，输入：

```python
# 计算长方形的面积和周长
length = 8
width = 5

area = length * width
perimeter = (length + width) * 2

print("长：", length, "宽：", width)
print("面积：", area)
print("周长：", perimeter)
```

保存后按 F5 运行：

```text
长： 8 宽： 5
面积： 40
周长： 26
```

> **注意**：在文件里写程序时，只写 `length * width` 是不会显示任何东西的，**必须用 print 才能显示结果**。只有在交互模式（`>>>`）里，Python 才会自动显示每一行的结果。

再来一个实用的例子，计算考试平均分：

```python
chinese = 92
math = 88
english = 95

total = chinese + math + english
average = total / 3

print("总分：", total)
print("平均分：", round(average, 1))
```

```text
总分： 275
平均分： 91.7
```

## 六、简写：+= 和它的兄弟们

上一篇学过，让变量增加 1 可以这样写：

```python
score = 10
score = score + 5
print(score)
```

```text
15
```

因为这种写法太常用了，Python 提供了一种简写：

```python
score = 10
score += 5      # 等同于 score = score + 5
print(score)
```

```text
15
```

同样的简写还有：

| 简写 | 完整写法 |
|---|---|
| `x += 3` | `x = x + 3` |
| `x -= 3` | `x = x - 3` |
| `x *= 3` | `x = x * 3` |
| `x /= 3` | `x = x / 3` |

例子：一个存钱罐，每次存钱或取钱后显示余额：

```python
money = 100
print("开始有", money, "元")

money += 50
print("存入 50 元后有", money, "元")

money -= 30
print("取出 30 元后有", money, "元")

money *= 2
print("翻倍后有", money, "元")
```

```text
开始有 100 元
存入 50 元后有 150 元
取出 30 元后有 120 元
翻倍后有 240 元
```

## 七、几个好用的数学功能

| 写法 | 作用 | 例子 | 结果 |
|---|---|---|---|
| `abs(x)` | 绝对值 | `abs(-7)` | `7` |
| `round(x, n)` | 四舍五入保留 n 位小数 | `round(2.567, 1)` | `2.6` |
| `max(a, b, ...)` | 最大值 | `max(3, 9, 5)` | `9` |
| `min(a, b, ...)` | 最小值 | `min(3, 9, 5)` | `3` |

```python
>>> abs(-7)
7
>>> max(3, 9, 5)
9
>>> min(3, 9, 5)
3
```

## 动手试试

写一个程序，把一个总秒数（比如 3725 秒）换算成“几小时几分几秒”：

```python
total_seconds = 3725

hours = total_seconds // 3600          # 1 小时 = 3600 秒
remaining = total_seconds % 3600       # 去掉整小时后，还剩多少秒
minutes = remaining // 60
seconds = remaining % 60

print(total_seconds, "秒 =", hours, "小时", minutes, "分", seconds, "秒")
```

```text
3725 秒 = 1 小时 2 分 5 秒
```

把 3725 换成别的数字试试，比如 100000。

## 新手常见错误

### 1. 用了数学符号 × ÷

```text
3 × 4     ← 错误
3 ÷ 4     ← 错误
3 * 4     ← 正确
3 / 4     ← 正确
```

### 2. 除以 0

<!-- raises -->
```python
print(10 / 0)
```

```text
Traceback (most recent call last):
  File "C:\Users\xiaoming\Desktop\python学习\demo.py", line 1, in <module>
    print(10 / 0)
          ~~~^~~
ZeroDivisionError: division by zero
```

数学里不能除以 0，Python 也不行。`ZeroDivisionError` 就是“除以零错误”。

### 3. 在文件里忘了 print

在文件里写：

```python
3 + 5
```

运行后什么都不显示。这不是出错了，而是你没有让 Python 显示结果。要写成 `print(3 + 5)`。

### 4. 数字里加了逗号

我们平时写大数字习惯加逗号，比如 1,000,000。但在 Python 里逗号有别的意思，不能这样写。如果想让大数字更好读，可以用**下划线**：

```python
>>> 1_000_000 + 1
1000001
```

## 小结

- 加减乘除：`+`、`-`、`*`、`/`；整除 `//`，取余 `%`，乘方 `**`。
- `/` 的结果**总是小数**，`//` 的结果去掉小数部分。
- 运算顺序和数学一样，有括号先算括号；**拿不准就加括号**。
- 数字分整数（`int`）和小数（`float`），用 `type()` 可以查看类型。
- 小数计算可能有极小误差（如 `0.1 + 0.2`），用 `round()` 保留几位小数即可。
- `x += 1` 是 `x = x + 1` 的简写。
- 在文件里写程序，**必须用 print 才能看到结果**。

**练习 2**：华氏温度转摄氏温度的公式是：摄氏度 = (华氏度 − 32) × 5 ÷ 9。写程序把 98.6 华氏度换算成摄氏度，结果保留 1 位小数。

**练习 4**：你有 1000 元，存进银行，年利率 3%，每年的利息会加入本金继续计算（复利）。10 年后有多少钱？结果保留 2 位小数。

提示：每过一年，钱就变成原来的 1.03 倍。

<details>
<summary>点击查看答案</summary>

```python
money = 1000
money = money * 1.03 ** 10
print("10 年后有", round(money, 2), "元")
```

```text
10 年后有 1343.92 元
```

`1.03 ** 10` 就是 1.03 自己乘以自己 10 次。乘方 `**` 比乘法 `*` 先算，所以不用加括号。

</details>
