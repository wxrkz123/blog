## 一、研究背景

教科书里的竞争性劳动力市场模型告诉我们：最低工资如果高于市场均衡工资，企业会减少雇佣，就业下降。这个结论很符合直觉，但它在现实中成立吗？

1992 年 4 月 1 日，美国新泽西州（New Jersey，NJ）把最低工资从每小时 4.25 美元提高到 5.05 美元。而紧邻的宾夕法尼亚州（Pennsylvania，PA）东部没有调整，仍然是 4.25 美元。

Card 和 Krueger 在政策实施前（1992 年 2—3 月）和实施后（1992 年 11—12 月）分别调查了两州约 410 家快餐店（汉堡王、肯德基、温蒂汉堡、Roy Rogers）的雇佣情况，用“全职等价雇员人数”（FTE，兼职按 0.5 人折算）衡量就业。

这里：

- **处理组**：新泽西州的快餐店（受到最低工资上调的影响）；
- **对照组**：宾夕法尼亚州东部的快餐店（未受影响）；
- **处理前**：1992 年 2—3 月；
- **处理后**：1992 年 11—12 月。

## 二、四格表

论文表 3 报告了每家店的平均 FTE 就业人数：

| | 处理前（2—3 月） | 处理后（11—12 月） | 前后变化 |
| --- | --- | --- | --- |
| **宾夕法尼亚（对照组）** | 23.33 | 21.17 | −2.16 |
| **新泽西（处理组）** | 20.44 | 21.03 | +0.59 |
| **两州差异（NJ − PA）** | −2.89 | −0.14 | **+2.76** |

右下角那个数字就是 DID 估计值。我们先看看三种“不同的比较”分别得到什么。

## 三、比较一：只看新泽西的前后变化

新泽西的就业从 20.44 增加到 21.03，增加了 **0.59 人**。

能说“最低工资让每家店多雇了 0.59 人”吗？不能。因为在这段时间里，还有很多其他因素在变化：1992 年美国经济正从衰退中缓慢恢复、快餐行业有季节性波动（2 月和 11 月的客流不同）……这些因素都会影响就业。**前后对比把所有“同期发生的其他变化”都算在了政策头上。**

## 四、比较二：只看政策后的两州差异

政策实施后，新泽西每家店 21.03 人，宾夕法尼亚 21.17 人，新泽西 **少 0.14 人**。

能说“最低工资让就业减少了 0.14 人”吗？也不能。因为两州的快餐店 **本来就不一样**：从政策前的数据看，新泽西的店平均比宾夕法尼亚少 2.89 人。店铺规模、城市化程度、连锁品牌构成都可能不同。**截面对比把“两组本来就有的差异”算在了政策头上。**

这正是上一篇讲的 **选择偏差**。

这就是最基本的 **2×2 DID**：两个组、两个时期，四个均值，两次相减。

## 六、用 Python 算一遍

```python
import pandas as pd

ck = pd.DataFrame(
    {"before": [23.33, 20.44], "after": [21.17, 21.03]},
    index=["PA（对照组）", "NJ（处理组）"],
)
ck["change"] = ck["after"] - ck["before"]
ck.loc["NJ − PA"] = ck.loc["NJ（处理组）"] - ck.loc["PA（对照组）"]
print(ck.round(2))

did = ck.loc["NJ − PA", "change"]
print(f"DID 估计值: {did:.2f}")
```

```text
DID 估计值: 2.75
```

## 八、Card 和 Krueger 的结论与争议

DID 估计值是 **+2.76**，也就是说，提高最低工资后新泽西快餐店的就业 **不降反升**，与教科书的预测相反。这个结果在当时引起了极大争议：

- Neumark 和 Wascher（2000）用快餐店的工资单数据重新研究，得到了负的就业效应，认为原始电话调查数据存在测量误差；
- Card 和 Krueger（2000）用美国劳工统计局（BLS）的官方数据回应，结论仍然是没有显著的负效应。

这场争论本身不是本系列的重点，但它说明了一件事：**DID 的结论高度依赖于数据质量和对照组的可比性**。后面讲稳健性检验时会回到这一点。Card 也因为在劳动经济学和自然实验方法上的贡献，与 Angrist、Imbens 一起获得了 2021 年诺贝尔经济学奖。

## 小结

- 2×2 DID = （处理组后 − 处理组前）−（对照组后 − 对照组前）。
- 前后对比的问题：把同期其他变化算作政策效应；截面对比的问题：把组间固有差异算作政策效应。
- DID 用前后差消除组的固定差异，用组间差消除共同时间冲击。
- DID 成立的关键是：两组受到的时间冲击相同，即 **平行趋势**。
