如果让你在屏幕上显示 5 遍“我爱学习”，你可能会这样写：

```python
print("我爱学习")
print("我爱学习")
print("我爱学习")
print("我爱学习")
print("我爱学习")
```

那如果是 1000 遍呢？复制粘贴 1000 行显然不是好办法。

电脑最擅长的就是**不知疲倦地重复做事**。这一篇我们学习**循环**，用几行代码让程序重复执行成千上万次。

## 一、for 循环：重复指定的次数

### 最简单的 for 循环

```python
for i in range(5):
    print("我爱学习")
```

```text
我爱学习
我爱学习
我爱学习
我爱学习
我爱学习
```

只用两行，就把“我爱学习”显示了 5 遍。想显示 1000 遍？把 5 改成 1000 就行。

格式和 `if` 很像：

```text
for 变量 in range(次数):
    要重复执行的代码
```

- 第一行末尾要有**冒号**；
- 要重复的代码要**缩进 4 个空格**。缩进的部分叫做**循环体**。

### 循环变量 i 是什么？

`for i in range(5)` 里的 `i` 是一个变量，每循环一次，它的值都会变化。我们把它显示出来看看：

```python
for i in range(5):
    print("这是第", i, "次")
```

```text
这是第 0 次
这是第 1 次
这是第 2 次
这是第 3 次
这是第 4 次
```

`range(5)` 会依次产生 0、1、2、3、4 这五个数（**从 0 开始，不包括 5**），每次循环，`i` 就取其中的一个数。

> 又是从 0 开始！和字符串的索引一样。`range(5)` 产生的数字个数正好是 5 个，所以循环 5 次。

变量名不一定要叫 `i`，可以起任何名字，只是 `i` 是程序员的习惯写法。

### range 的更多用法

| 写法 | 产生的数字 | 说明 |
|---|---|---|
| `range(5)` | 0, 1, 2, 3, 4 | 从 0 开始，到 5 之前结束 |
| `range(1, 6)` | 1, 2, 3, 4, 5 | 从 1 开始，到 6 之前结束 |
| `range(0, 10, 2)` | 0, 2, 4, 6, 8 | 每次加 2 |
| `range(5, 0, -1)` | 5, 4, 3, 2, 1 | 每次减 1（倒着数） |

规律是 `range(开始, 结束, 步长)`，**包括开始，不包括结束**（和字符串切片一样）。

```python
for n in range(1, 6):
    print(n)
```

```text
1
2
3
4
5
```

倒计时：

```python
for n in range(5, 0, -1):
    print(n)
print("发射！🚀")
```

```text
5
4
3
2
1
发射！🚀
```

注意最后一行 `print("发射！🚀")` 没有缩进，所以它**不在循环里**，只会在循环结束后执行一次。

## 二、用循环做累加

循环最经典的用法之一：**累加**。比如计算 1 + 2 + 3 + … + 100：

```python
total = 0
for n in range(1, 101):
    total = total + n
print(total)
```

```text
5050
```

想象你手里有一个计数器 `total`，一开始是 0：

| 第几次循环 | n | total 变成 |
|---|---|---|
| 第 1 次 | 1 | 0 + 1 = 1 |
| 第 2 次 | 2 | 1 + 2 = 3 |
| 第 3 次 | 3 | 3 + 3 = 6 |
| …… | …… | …… |
| 第 100 次 | 100 | 4950 + 100 = 5050 |

几行代码，瞬间完成了 100 次加法。

> 注意 `total = 0` 必须写在循环**外面**、循环之前。如果写在循环里面，每次循环都会被重新清零。

## 三、遍历字符串

`for` 不仅能配合 `range`，还能**一个一个地取出字符串里的字符**，这叫做**遍历**：

```python
for char in "你好世界":
    print(char)
```

```text
你
好
世
界
```

数一数一句话里有几个“的”：

```python
sentence = "我的猫的名字是小白的猫"
count = 0
for char in sentence:
    if char == "的":
        count += 1
print(f"一共有 {count} 个“的”")
```

```text
一共有 3 个“的”
```

注意这里循环里面有 if，if 里面的代码要缩进**两层**（8 个空格）。

## 四、while 循环：条件成立就一直重复

`for` 循环适合**知道要重复几次**的情况。如果不知道要重复几次，只知道“**什么时候停**”，就用 `while`（英文“当……的时候”）：

```python
count = 1
while count <= 5:
    print(f"第 {count} 次")
    count += 1
print("结束")
```

```text
第 1 次
第 2 次
第 3 次
第 4 次
第 5 次
结束
```

`while` 的执行过程是：

1. 检查条件 `count <= 5`；
2. 如果成立，执行循环体，然后**回到第 1 步**再检查；
3. 如果不成立，结束循环，执行后面的代码。

一个更适合 while 的例子：存钱。每月存 1500 元，多少个月能存够 10000 元？

```python
saved = 0
months = 0
while saved < 10000:
    saved += 1500
    months += 1
print(f"需要 {months} 个月，那时存了 {saved} 元")
```

```text
需要 7 个月，那时存了 10500 元
```

事先不知道要循环几次，但知道“存够 10000 就停”，这正是 while 的用武之地。

### 小心死循环！

如果 while 的条件**永远成立**，循环就永远不会停止，这叫做**死循环**：

<!-- norun -->
```python
count = 1
while count <= 5:
    print("停不下来了！")
    # 忘了写 count += 1，count 永远是 1
```

这个程序会不停地显示“停不下来了！”。

> 🛑 **如果程序陷入死循环，按键盘上的 `Ctrl + C` 就能强行停止它。** 在 IDLE 里也可以点菜单 **Shell → Interrupt Execution**。

写 while 循环时，一定要确认循环体里有让条件**最终变得不成立**的代码。

## 五、break 和 continue

### break：立刻跳出循环

`break`（英文“打断”）会**立刻结束整个循环**：

```python
for n in range(1, 100):
    if n * n > 50:
        print(f"第一个平方大于 50 的数是 {n}")
        break
```

```text
第一个平方大于 50 的数是 8
```

找到答案后就不用再继续找了，用 break 直接结束。

`while True` 配合 `break` 是一种非常常用的写法。`while True` 表示“一直循环”，然后在循环中用 `break` 决定什么时候停：

<!-- stdin: 你好 | 今天天气不错 | 退出 -->
```python
while True:
    text = input("请说点什么（输入“退出”结束）：")
    if text == "退出":
        break
    print(f"你说的是：{text}")
print("再见！")
```

```text
请说点什么（输入“退出”结束）：你好
你说的是：你好
请说点什么（输入“退出”结束）：今天天气不错
你说的是：今天天气不错
请说点什么（输入“退出”结束）：退出
再见！
```

### continue：跳过这一次，继续下一次

`continue`（英文“继续”）会**跳过本次循环剩下的代码**，直接开始下一次：

```python
for n in range(1, 11):
    if n % 3 == 0:
        continue
    print(n)
```

```text
1
2
4
5
7
8
10
```

遇到 3 的倍数时，`continue` 让程序跳过了下面的 `print`，所以 3、6、9 没有显示。

| | 作用 | 比喻 |
|---|---|---|
| `break` | 结束整个循环 | 跑步时直接退出比赛 |
| `continue` | 跳过这一次，进入下一次 | 跳过这一圈，接着跑下一圈 |

## 六、循环里面套循环

循环里还可以再写循环，这叫**嵌套循环**。外层循环每执行一次，内层循环都要完整地执行一遍。

用星号画一个直角三角形：

```python
for row in range(1, 6):
    print("*" * row)
```

```text
*
**
***
****
*****
```

这个其实只用了一层循环（利用了字符串乘法）。下面是一个真正的嵌套循环，**九九乘法表**：

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={i * j}", end="\t")
    print()
```

```text
1×1=1
1×2=2	2×2=4
1×3=3	2×3=6	3×3=9
1×4=4	2×4=8	3×4=12	4×4=16
1×5=5	2×5=10	3×5=15	4×5=20	5×5=25
1×6=6	2×6=12	3×6=18	4×6=24	5×6=30	6×6=36
1×7=7	2×7=14	3×7=21	4×7=28	5×7=35	6×7=42	7×7=49
1×8=8	2×8=16	3×8=24	4×8=32	5×8=40	6×8=48	7×8=56	8×8=64
1×9=9	2×9=18	3×9=27	4×9=36	5×9=45	6×9=54	7×9=63	8×9=72	9×9=81
```

这里有两个新东西：

- `print(..., end="\t")`：print 默认在结尾自动换行，`end="\t"` 让它在结尾加一个**制表符**（相当于按一下 Tab 键，用来对齐）而不换行，这样同一行的算式就能排在一起；
- 内层循环结束后的 `print()`：显示一个换行，开始新的一行。

外层循环 `i` 控制“第几行”，内层循环 `j` 控制“这一行的第几个”。第 i 行有 i 个算式，所以内层是 `range(1, i + 1)`。

## 动手试试：猜数字游戏

把学过的 `input`、`if`、`while`、`break` 组合起来，做一个小游戏：

<!-- stdin: 50 | 75 | 62 | 68 -->
```python
secret = 68          # 谜底（第 13 篇会教你生成随机数）
tries = 0

print("我想了一个 1 到 100 之间的数，你来猜！")

while True:
    guess = int(input("你猜是多少？"))
    tries += 1
    if guess > secret:
        print("太大了")
    elif guess < secret:
        print("太小了")
    else:
        print(f"🎉 猜对了！你一共猜了 {tries} 次")
        break
```

```text
我想了一个 1 到 100 之间的数，你来猜！
你猜是多少？50
太小了
你猜是多少？75
太大了
你猜是多少？62
太小了
你猜是多少？68
🎉 猜对了！你一共猜了 4 次
```

> 💡 小技巧：每次都猜“剩下范围的中间值”，最多 7 次就一定能猜中 1 到 100 之间的任何数。这个思路在编程里叫做“二分查找”。

## 新手常见错误

### 1. 忘了缩进，或缩进错了位置

```python
total = 0
for n in range(1, 4):
    total += n
    print(total)
```

```text
1
3
6
```

```python
total = 0
for n in range(1, 4):
    total += n
print(total)
```

```text
6
```

两段代码只差了 `print` 前的缩进，结果完全不同：第一段的 print 在循环**里面**，每次循环都显示；第二段的 print 在循环**外面**，只在最后显示一次。写代码时要想清楚：**这一行是要重复执行，还是只执行一次？**

### 2. range 的范围差一个

想要 1 到 10，写成了 `range(1, 10)`，结果只有 1 到 9。记住 **range 不包括结束值**，要写 `range(1, 11)`。

### 3. 累加变量放进了循环里

```python
for n in range(1, 4):
    total = 0
    total += n
print(total)
```

```text
3
```

`total = 0` 在循环里，每次都被清零了，最后只剩下最后一次加的 3。

### 4. while 死循环

忘了改变条件中的变量。记住：遇到死循环按 **`Ctrl + C`**。

## 小结

- **for 循环**：`for i in range(n):` 重复 n 次；`range(开始, 结束, 步长)` **不包括结束值**。
- `for 字符 in 字符串:` 可以逐个取出字符串里的字符。
- **while 循环**：条件成立就一直重复，适合“不知道要几次，但知道什么时候停”的情况。
- 当心死循环，按 `Ctrl + C` 可以强行停止。
- `break` 结束整个循环，`continue` 跳过本次进入下一次。
- `while True` + `break` 是很常用的写法。
- 循环体要缩进；累加用的变量要在循环**之前**初始化。
