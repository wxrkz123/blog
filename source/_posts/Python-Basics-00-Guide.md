## Python 是什么？

**程序**就是一份写给电脑的“操作说明书”。比如：

> 1. 问用户叫什么名字；
> 2. 在屏幕上显示“你好，某某”。

但电脑看不懂中文，它只认识一种叫“编程语言”的东西。**Python 就是其中一种编程语言**，而且是公认最适合初学者的一种，因为它写起来很像英语。

比如上面那份说明书，用 Python 写出来是这样的：

```python
name = "小明"
print("你好，" + name)
```

运行结果：

```text
你好，小明
```

即使你现在还看不懂每个符号，大概也能猜出它在干什么：先记下一个名字“小明”，然后把“你好，小明”打印（print）到屏幕上。

## 学 Python 能做什么？

- **处理表格和数据**：几万行的 Excel，几秒钟就能统计完；
- **自动化办公**：批量重命名文件、批量生成报告；
- **数据分析和画图**：本站的金融、计量经济学文章大量使用 Python；
- **写小工具、小游戏**；
- **人工智能**：现在几乎所有 AI 相关的工作都离不开 Python。

当然，这些都需要先打好基础。这个系列就是帮你打基础的。

## 怎样读这个系列

### 1. 一定要动手敲代码

学编程和学游泳一样，**光看是学不会的**。每篇文章里的代码，请你：

1. **自己敲一遍**，不要复制粘贴（刚开始敲得慢没关系，这能帮你记住）；
2. 运行它，看看结果和文章里写的是不是一样；
3. **改一改**再运行，比如把“小明”改成你的名字，看看会发生什么。

### 2. 看懂代码的格式

文章里有两种灰色的框。

一种是**代码**，右上角会写着 `PYTHON`，这是需要你敲进电脑的内容：

```python
print("我是代码")
```

另一种是**运行结果**，紧跟在代码后面，是程序运行后屏幕上显示的内容：

```text
我是代码
```

### 3. 出错了不要慌

刚开始学，代码出错是**非常正常**的事情，写了十几年代码的程序员每天也都在出错。

出错时，Python 会显示一段英文提示。第 11 篇会专门教你怎么看懂它。在那之前，如果出错了，请先检查这几点：

- **括号、引号是不是用了中文符号？** 代码里的符号必须是英文的：`(` `)` `"` `:` `,`，而不是 `（` `）` `“` `：` `，`。这是新手最常见的错误，没有之一。
- **括号、引号是不是成对出现？** 有左括号就要有右括号。
- **大小写对不对？** `print` 和 `Print` 在 Python 看来是两个完全不同的东西。
