SciPy 入门：统计、优化与金融计算

SciPy 是建立在 NumPy 之上的科学计算库。NumPy 提供了数组和基本的运算，SciPy 则在此基础上提供了大量现成的数学工具：概率分布与统计检验、方程求根与最优化、插值、数值积分、线性代数、信号处理等。

对金融来说，SciPy 最常用的是这几个子模块：

子模块 功能 金融中的用途
stats 概率分布、统计检验 收益率分布、正态性检验、VaR、期权定价中的正态分布
optimize 求根、最优化、曲线拟合 内部收益率、到期收益率、隐含波动率、投资组合优化、收益率曲线拟合
interpolate 插值 利率期限结构
integrate 数值积分 期权的期望收益

NumPy 入门中的 numpy_financial 可以直接算内部收益率，但遇到它没有提供的问题（比如债券的到期收益率、期权的隐含波动率），就需要用 SciPy 自己求解。本文围绕这几个子模块，结合金融场景来介绍。读这篇之前，最好先读 NumPy 和 pandas 入门。

一、安装与导入

pip install scipy
import numpy as np
import pandas as pd
import scipy
from scipy import stats, optimize, interpolate, integrate    #按需导入子模块

print(scipy.__version__)    #查看SciPy版本信息
1.18.1

和 NumPy 不同，SciPy 一般不整体导入，而是用到哪个子模块就导入哪个，比如 from scipy import stats。

二、stats：概率分布与统计检验

概率分布

stats 模块里每一种分布都是一个对象，有一套统一的方法：

stats.norm.pdf(x, loc, scale)    #概率密度函数
stats.norm.cdf(x, loc, scale)    #累积分布函数：P(X <= x)
stats.norm.ppf(q, loc, scale)    #分位数函数：cdf的反函数
stats.norm.rvs(loc, scale, size)    #随机抽样
stats.norm.fit(data)    #用数据估计分布的参数

其中 loc 是位置参数（正态分布的均值），scale 是尺度参数（正态分布的标准差）。把 norm 换成 t、chi2、lognorm 等，就是其他分布，用法完全一样。NumPy 的随机数只能“抽”，而 SciPy 的分布对象还能算概率和分位数，这在金融中用得非常多：

print("标准正态分布小于-1.96的概率：", round(stats.norm.cdf(-1.96), 4))
print("标准正态分布的1%分位数：", round(stats.norm.ppf(0.01), 4))
print("自由度为5的t分布的1%分位数：", round(stats.t.ppf(0.01, df=5), 4))
标准正态分布小于-1.96的概率： 0.025
标准正态分布的1%分位数： -2.3263
自由度为5的t分布的1%分位数： -3.3649

t 分布的尾部比正态分布更“厚”：同样是 1% 的分位数，t 分布离中心远得多。这正是金融收益率的特点，后面计算 VaR 时会用到。

描述统计与正态性检验

和 pandas 入门一样，先用 NumPy 模拟三只股票 2023 年的日收盘价：

rng = np.random.default_rng(2119)    #固定随机种子，和pandas、matplotlib两篇文章的数据相同
dates = pd.bdate_range("2023-01-02", "2023-12-29")
daily_ret = rng.normal([0.0006, 0.0002, 0.0009], [0.018, 0.011, 0.026], size=(len(dates), 3))
prices = pd.DataFrame(100 * np.exp(daily_ret.cumsum(axis=0)),
                      index=dates, columns=["股票A", "股票B", "股票C"]).round(2)
ret = prices.pct_change().dropna()

d = stats.describe(ret["股票C"])
print(f"样本量 {d.nobs}，最小值 {d.minmax[0]:.4f}，最大值 {d.minmax[1]:.4f}")
print(f"均值 {d.mean:.5f}，方差 {d.variance:.6f}，偏度 {d.skewness:.3f}，峰度 {d.kurtosis:.3f}")
样本量 259，最小值 -0.0828，最大值 0.0918
均值 0.00194，方差 0.000649，偏度 -0.050，峰度 0.390

stats.describe 一次给出样本量、最小最大值、均值、方差、偏度和峰度（这里的峰度是“超额峰度”，正态分布为 0）。

检验收益率是否服从正态分布，最常用的是 Jarque-Bera 检验，它同时检验偏度是否为 0、峰度是否为 3：

jb = stats.jarque_bera(ret["股票C"])
print(f"模拟数据：JB统计量 = {jb.statistic:.2f}，p值 = {jb.pvalue:.3f}")

fat = stats.t.rvs(df=4, size=5000, random_state=3) * 0.015    #用t分布模拟“厚尾”的收益率
jb2 = stats.jarque_bera(fat)
print(f"厚尾数据：JB统计量 = {jb2.statistic:.2f}，p值 = {jb2.pvalue:.3g}")
模拟数据：JB统计量 = 1.75，p值 = 0.416
厚尾数据：JB统计量 = 29036.18，p值 = 0

原假设是“服从正态分布”。模拟的股票收益率本来就是用正态分布生成的，p 值很大，不能拒绝正态分布；用 t 分布生成的厚尾数据，p 值几乎为 0，强烈拒绝正态分布。真实的股票日收益率做这个检验，结果通常和第二种一样。

t 检验

股票 C 全年的平均日收益率是正的，但这能说明它的期望收益真的大于 0 吗？还是只是运气？用单样本 t 检验：

for name in ret.columns:
    t = stats.ttest_1samp(ret[name], popmean=0)
    print(f"{name}：平均日收益率 {ret[name].mean():.4%}，t = {t.statistic:.2f}，p = {t.pvalue:.3f}")
股票A：平均日收益率 0.0761%，t = 0.68，p = 0.497
股票B：平均日收益率 0.0288%，t = 0.40，p = 0.687
股票C：平均日收益率 0.1943%，t = 1.23，p = 0.221

三只股票的 p 值都远大于 0.05，即使是全年涨了 50% 多的股票 C，也不能说它的期望收益显著大于 0。原因是日收益率的波动太大了，一年 259 个交易日的数据根本不足以把“真本事”和“运气”区分开。这是金融数据分析中非常重要的一课：收益率的均值很难被准确地估计。

两组数据的均值比较用 stats.ttest_ind(a, b)，配对数据用 stats.ttest_rel(a, b)。

三、optimize：求根、最优化与曲线拟合

求根：内部收益率与到期收益率

NumPy 入门用 npf.irr 计算内部收益率，它的本质就是求方程 的根。用 optimize.brentq 可以自己求解，它需要一个函数和一个包含根的区间：

cash_flows = np.array([-1000, 300, 400, 400, 300])    #期初投资1000，之后四年的现金流

def npv(r):
    return np.sum(cash_flows / (1 + r) ** np.arange(len(cash_flows)))

irr = optimize.brentq(npv, -0.99, 1)    #在-99%到100%之间找使NPV=0的利率
print(f"内含报酬率：{irr:.4%}")
print(f"验证：NPV({irr:.4f}) = {npv(irr):.2e}")
内含报酬率：14.8950%
验证：NPV(0.1490) = -3.13e-13

同样的方法可以计算债券的到期收益率（YTM）：使债券未来现金流的现值等于当前价格的贴现率。一只面值 100 元、票面利率 3%、每年付息、还有 5 年到期的债券，现在的价格是 98 元：

def bond_price(y, coupon=3, face=100, years=5):
    t = np.arange(1, years + 1)
    return np.sum(coupon / (1 + y) ** t) + face / (1 + y) ** years

ytm = optimize.brentq(lambda y: bond_price(y) - 98, 0, 1)
print(f"到期收益率：{ytm:.4%}")
到期收益率：3.4422%

价格低于面值（折价）时，到期收益率高于票面利率，这符合债券定价的基本规律。

最优化：最小方差组合

optimize.minimize 用来求一个函数的最小值，还可以加上约束条件：

optimize.minimize(fun, x0, method, bounds, constraints)

其中 fun 是要最小化的函数，x0 是初始值，bounds 是每个变量的取值范围，constraints 是约束条件。

用它求三只股票的最小方差组合：权重加起来等于 1，不允许卖空（每个权重在 0 到 1 之间），让组合的方差最小：

cov = ret.cov().values * 252    #年化协方差矩阵
mean = ret.mean().values * 252    #年化平均收益率

def port_vol(w):
    return np.sqrt(w @ cov @ w)

res = optimize.minimize(
    port_vol,
    x0=np.ones(3) / 3,    #从等权重开始
    method="SLSQP",
    bounds=[(0, 1)] * 3,    #不允许卖空
    constraints={"type": "eq", "fun": lambda w: w.sum() - 1},    #权重之和等于1
)
print("是否成功：", res.success)
print("最小方差组合的权重：", {name: round(float(x), 3) for name, x in zip(ret.columns, res.x)})
print(f"组合的年化波动率：{res.fun:.2%}（单只股票中最低的是 {np.sqrt(np.diag(cov)).min():.2%}）")
是否成功： True
最小方差组合的权重： {'股票A': 0.264, '股票B': 0.61, '股票C': 0.125}
组合的年化波动率：13.98%（单只股票中最低的是 18.27%）

最小方差组合的波动率只有 14%，比波动最小的股票 B（18%）还低，这就是分散投资的效果。method="SLSQP" 是一种支持等式和不等式约束的算法，带约束的问题一般就用它。

曲线拟合：收益率曲线

optimize.curve_fit 用最小二乘法，把一个指定形式的函数拟合到数据上。金融中的典型例子是用 Nelson-Siegel 模型拟合国债的收益率曲线：

其中 是期限， 代表长期利率水平， 代表短期与长期利率之差， 代表曲线中段的弯曲程度。

maturity = np.array([0.25, 0.5, 1, 2, 3, 5, 7, 10, 30])    #期限（年）
yields = np.array([1.40, 1.48, 1.58, 1.80, 1.95, 2.12, 2.28, 2.35, 2.55])    #收益率（%），示意数据

def nelson_siegel(tau, b0, b1, b2, lam):
    x = tau / lam
    f1 = (1 - np.exp(-x)) / x
    return b0 + b1 * f1 + b2 * (f1 - np.exp(-x))

params, _ = optimize.curve_fit(nelson_siegel, maturity, yields, p0=[2.5, -1, 1, 2])
print("参数：", {name: round(float(x), 3) for name, x in zip(["b0", "b1", "b2", "lambda"], params)})
print("拟合误差（基点）：", ((nelson_siegel(maturity, *params) - yields) * 100).round(1))
参数： {'b0': 2.637, 'b1': -1.311, 'b2': -0.0, 'lambda': 2.094}
拟合误差（基点）： [ 0.2 -0.9  1.5 -0.7 -0.9  1.9 -2.1  1.5 -0.4]

（这里的收益率是示意数据，形状接近近年中国国债的收益率曲线。）

四个参数就把 9 个期限的收益率拟合得很好，误差都在 3 个基点（0.03%）以内。p0 是参数的初始值，非线性的拟合问题最好给一个合理的初始值，否则可能不收敛。

四、interpolate：插值

市场上只有几个关键期限的收益率，如果需要 4 年期、15 年期的收益率怎么办？最简单的方法是插值：

linear = interpolate.interp1d(maturity, yields)    #线性插值
spline = interpolate.CubicSpline(maturity, yields, bc_type="natural")    #三次样条插值（自然边界条件）

for tau in [4, 15, 20]:
    print(f"{tau}年期：线性插值 {float(linear(tau)):.3f}%，三次样条 {float(spline(tau)):.3f}%，"
          f"Nelson-Siegel {nelson_siegel(tau, *params):.3f}%")
4年期：线性插值 2.035%，三次样条 2.043%，Nelson-Siegel 2.053%
15年期：线性插值 2.400%，三次样条 2.384%，Nelson-Siegel 2.454%
20年期：线性插值 2.450%，三次样条 2.432%，Nelson-Siegel 2.500%

把三种方法画在一起比较（画图的方法见 Matplotlib 入门）：

import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "PingFang SC", "WenQuanYi Zen Hei"]
plt.rcParams["axes.unicode_minus"] = False

grid = np.linspace(0.25, 30, 300)
fig, ax = plt.subplots(figsize=(8, 4.5))
ax.plot(grid, linear(grid), color="grey", ls="--", label="线性插值")
ax.plot(grid, spline(grid), color="tab:blue", label="三次样条插值")
ax.plot(grid, nelson_siegel(grid, *params), color="tab:red", label="Nelson-Siegel拟合")
ax.scatter(maturity, yields, color="black", zorder=3, label="市场报价（示意）")
ax.set_xlabel("期限（年）")
ax.set_ylabel("收益率（%）")
ax.set_title("收益率曲线：插值与拟合")
ax.legend()
ax.grid(alpha=0.3)
fig.tight_layout()
plt.show()

这里的三次样条用了“自然边界条件”（bc_type="natural"）。如果用默认的边界条件，10 年到 30 年之间数据点很稀疏，样条曲线会向下弯出一个不合理的“坑”（20 年期只有 1.76%），可以自己试一试。插值方法在数据点稀疏的地方要格外小心。

  • 插值的曲线一定经过每个数据点，适合需要和市场报价完全一致的场合（比如给债券定价）；
  • 拟合的曲线不一定经过数据点，但更平滑，参数也有经济含义，适合分析收益率曲线的形状和变化。

五、integrate：数值积分

integrate.quad 计算一元函数的定积分：

integrate.quad(func, a, b)    #计算func在[a, b]上的积分，返回(积分值, 误差估计)

金融中的一个例子：期权到期时的期望收益，就是收益函数乘以概率密度后的积分。比如，假设股票到期价格服从对数正态分布，看涨期权的期望收益 ：

S0, K, r, sigma, T = 100, 105, 0.02, 0.25, 1    #现价、行权价、无风险利率、波动率、期限（年）
ST_dist = stats.lognorm(s=sigma * np.sqrt(T), scale=S0 * np.exp((r - sigma**2 / 2) * T))    #风险中性下的到期价格分布

payoff, err = integrate.quad(lambda s: (s - K) * ST_dist.pdf(s), K, np.inf)    #只有S>K时才有收益
print(f"到期期望收益：{payoff:.4f}（误差估计 {err:.1e}）")
print(f"贴现到今天的期权价格：{np.exp(-r * T) * payoff:.4f}")
到期期望收益：8.8747（误差估计 2.1e-09）
贴现到今天的期权价格：8.6990

积分的上限可以是无穷大 np.inf。下一节用 Black-Scholes 公式验证这个结果。

六、Black-Scholes 期权定价与隐含波动率

Black-Scholes 公式给出欧式看涨期权的价格：

其中 是标准正态分布的累积分布函数，正好就是 stats.norm.cdf：

def bs_call(S0, K, r, sigma, T):
    d1 = (np.log(S0 / K) + (r + sigma**2 / 2) * T) / (sigma * np.sqrt(T))
    d2 = d1 - sigma * np.sqrt(T)
    return S0 * stats.norm.cdf(d1) - K * np.exp(-r * T) * stats.norm.cdf(d2)

print(f"Black-Scholes公式：{bs_call(S0, K, r, sigma, T):.4f}")
Black-Scholes公式：8.6990

和上一节数值积分的结果完全一致。

反过来，如果市场上这个期权的价格是 10 元，它隐含的波动率是多少？这就是隐含波动率：使 Black-Scholes 价格等于市场价格的波动率。公式没法直接反解，又是一个求根问题：

market_price = 10
iv = optimize.brentq(lambda s: bs_call(S0, K, r, s, T) - market_price, 0.001, 3)
print(f"隐含波动率：{iv:.2%}")
隐含波动率：28.26%

市场价格 10 元高于用 25% 波动率算出的 8.70 元，说明市场预期未来的波动更大，隐含波动率约为 28%。各个期权的隐含波动率是期权交易员最关注的指标，著名的“恐慌指数” VIX 就是根据标普 500 指数期权的隐含波动率计算的。

七、最大夏普比率组合

第三节求了最小方差组合。更常用的是夏普比率最大的组合：每承担一单位风险，获得的超额收益最多。minimize 只能求最小值，所以最小化夏普比率的相反数：

rf = 0.02    #无风险利率

def neg_sharpe(w):
    return -(w @ mean - rf) / port_vol(w)

res2 = optimize.minimize(neg_sharpe, x0=np.ones(3) / 3, method="SLSQP",
                         bounds=[(0, 1)] * 3, constraints={"type": "eq", "fun": lambda w: w.sum() - 1})
w = res2.x
print("最大夏普比率组合的权重：", {name: round(float(x), 3) for name, x in zip(ret.columns, w)})
print(f"年化收益率 {w @ mean:.2%}，年化波动率 {port_vol(w):.2%}，夏普比率 {-res2.fun:.3f}")
最大夏普比率组合的权重： {'股票A': 0.325, '股票B': 0.258, '股票C': 0.417}
年化收益率 28.54%，年化波动率 19.50%，夏普比率 1.361

在 Matplotlib 入门中，我们随机生成了 3000 个组合，从中找出夏普比率最高的一个。这里用最优化直接求出了最优解，结果和随机搜索的最好结果很接近，但更精确，也快得多。

需要提醒的是：第二节的 t 检验已经说明，用一年的数据估计的平均收益率非常不可靠。最大夏普比率组合对平均收益率的估计非常敏感，实际应用时往往效果并不好。相比之下，最小方差组合只用到协方差矩阵，更加稳健。

八、三种方法计算 VaR

最后，用 stats 模块计算股票 C 的 99% 单日风险价值（VaR）：在 99% 的概率下，一天最多亏多少。

r = ret["股票C"]
var_hist = -np.percentile(r, 1)    #历史模拟法：直接取历史收益率的1%分位数
var_norm = -stats.norm.ppf(0.01, loc=r.mean(), scale=r.std())    #参数法：假设正态分布
nu, loc, scale = stats.t.fit(r)    #用数据估计t分布的参数
var_t = -stats.t.ppf(0.01, nu, loc, scale)    #参数法：假设t分布

print(f"历史模拟法：{var_hist:.2%}")
print(f"正态分布法：{var_norm:.2%}")
print(f"t分布法：  {var_t:.2%}（估计的自由度 {nu:.1f}）")
历史模拟法：5.71%
正态分布法：5.73%
t分布法：  5.90%（估计的自由度 19.9）

三种方法的结果很接近，因为模拟的收益率本来就服从正态分布：t 分布估计出的自由度约为 20，自由度这么大的 t 分布和正态分布已经相差不多了。

对真实的股票收益率，估计出的自由度通常只有 3 到 6，这时正态分布法会明显低估 VaR。可以用第二节那组用 t 分布生成的厚尾数据试一试：

nu2, loc2, scale2 = stats.t.fit(fat)
print(f"厚尾数据：历史模拟法 {-np.percentile(fat, 1):.2%}，"
      f"正态分布法 {-stats.norm.ppf(0.01, fat.mean(), fat.std()):.2%}，"
      f"t分布法 {-stats.t.ppf(0.01, nu2, loc2, scale2):.2%}（自由度 {nu2:.1f}）")
厚尾数据：历史模拟法 5.73%，正态分布法 4.95%，t分布法 5.70%（自由度 3.8）

对厚尾数据，正态分布法给出的 VaR 明显偏小（约低估了 0.8 个百分点），t 分布法与历史模拟法几乎相同。用正态分布来衡量风险，会低估极端损失发生的可能。

小结

子模块 常用函数 金融中的用途
stats 分布对象的 pdf、cdf、ppf、fit；jarque_bera、ttest_1samp 收益率分布与正态性检验、VaR、Black-Scholes
optimize brentq 求根；minimize 带约束的最优化；curve_fit 曲线拟合 内部收益率、到期收益率、隐含波动率；投资组合；收益率曲线
interpolate interp1d、CubicSpline 利率期限结构插值
integrate quad 期权的期望收益

几点提醒：收益率的均值很难准确估计，依赖预期收益的优化结果要谨慎对待；插值方法在数据点稀疏的地方要检查曲线是否合理；用正态分布衡量风险会低估厚尾数据的极端损失。
