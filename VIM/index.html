Vim 常用命令速查表

编程 计算机 软件工具
计算机
发布日期:   2022-05-20
文章字数:   2676 字
阅读时长:   9 分

Vim 的命令很多，但它们有规律可循：先弄清楚自己处在哪个模式，再记住少数几个操作符和移动命令，就能组合出大部分操作。本文按模式分组整理常用命令，表格中的 Ctrl+r 表示同时按 Ctrl 和 r，<Esc>、<Enter> 表示对应的按键。

一、四种模式及切换

模式 用途 怎样进入 怎样退出
普通模式（Normal） 移动光标、复制、删除、粘贴 打开文件时的默认模式；其他模式按 <Esc> —
插入模式（Insert） 输入文本 普通模式下按 i、a、o 等（见第四节） <Esc>
可视模式（Visual） 选中一段文本再操作 普通模式下按 v、V、Ctrl+v <Esc> 或再按一次同样的键
命令行模式（Command-line） 保存、退出、查找、替换、设置选项 普通模式下按 :、/、? <Enter> 执行，<Esc> 取消

不确定自己在哪个模式时，按两次 <Esc>，一定会回到普通模式。

二、打开文件

在终端中：

命令 作用
vim file 打开文件；文件不存在时，保存后新建
vim +n file 打开文件，光标停在第 n 行
vim + file 打开文件，光标停在最后一行
vim +/pattern file 打开文件，光标停在第一个匹配 pattern 的位置
vim -R file 只读方式打开
vim -r file 从交换文件恢复上次异常退出时未保存的内容
vim -O a.txt b.txt 左右分屏打开两个文件（-o 为上下分屏）

三、普通模式

移动光标

命令 作用
h j k l 左、下、上、右
w / b / e 下一个单词开头 / 上一个单词开头 / 当前（下一个）单词结尾
W / B / E 同上，但以空白分隔“单词”，-、. 等标点不算分隔
0 行首（第一个字符）
^ 行首第一个非空白字符
$ 行尾
g_ 行尾最后一个非空白字符
gg / G 文件第一行 / 最后一行
nG 或 :n 第 n 行
n| 当前行的第 n 列
f字符 / F字符 在当前行向右 / 向左跳到下一个该字符
t字符 / T字符 同上，但停在该字符前一格
; / , 重复上一次 f、t、F、T（同向 / 反向）
% 跳到匹配的括号 ()、[]、{}
( / ) 上一个 / 下一个句子
{ / } 上一个 / 下一个段落（空行分隔）
H / M / L 屏幕顶部 / 中间 / 底部
`. 上一次修改的位置
Ctrl+o / Ctrl+i 跳回 / 跳进（在跳转历史中前后移动）

大多数移动命令前面可以加数字，表示重复次数：5j 向下 5 行，3w 向后 3 个单词。

滚屏

命令 作用
Ctrl+f / Ctrl+b 向下 / 向上翻一整屏
Ctrl+d / Ctrl+u 向下 / 向上翻半屏
zz / zt / zb 把当前行滚到屏幕中间 / 顶部 / 底部

删除、复制、粘贴

Vim 的“复制”和“剪切”默认存进 Vim 自己的寄存器，而不是系统剪贴板（见本节末尾）。删除的内容也会存进寄存器，所以“删除”就是“剪切”。

命令 作用
x / X 删除光标处 / 光标前的一个字符
dd 删除（剪切）当前行；3dd 删除 3 行
D 删除从光标到行尾
dw 删除从光标到下一个单词开头
dG / dgg 删除从当前行到文件末尾 / 开头
yy 复制当前行；3yy 复制 3 行
yw 复制从光标到下一个单词开头
y$ 复制从光标到行尾
p / P 粘贴到光标后（下一行）/ 光标前（上一行）
r字符 把光标处的字符替换成另一个字符
J 把下一行合并到当前行
. 重复上一次修改操作

系统剪贴板：在支持剪贴板的 Vim 中（vim --version 输出里有 +clipboard），"+y 复制到系统剪贴板，"+p 从系统剪贴板粘贴。

撤销与重做

命令 作用
u 撤销上一次修改
Ctrl+r 重做（撤销的撤销）
U 撤销最近修改过的那一行上的所有修改

大小写

命令 作用
~ 切换光标处字符的大小写，并右移一格
guw / gUw 把单词变成小写 / 大写
guu / gUU 把整行变成小写 / 大写

组合规律：操作符 + 移动

上面的 dw、yy、gUw 不是孤立的命令，而是操作符和移动的组合：

操作符 含义
d 删除
y 复制
c 修改（删除后进入插入模式）
> / < 增加 / 减少缩进
gu / gU 变成小写 / 大写

操作符后面接任何移动命令，就作用在光标到移动终点之间的文本上：d$ 删除到行尾，c3w 修改 3 个单词，yG 复制到文件末尾，>} 把到段落结尾的行都缩进。连按两次操作符表示作用于整行：dd、yy、cc、>>。

比移动更好用的是文本对象：i 表示“内部”，a 表示“连同边界”。

命令 作用
diw / daw 删除光标所在的单词 / 单词及其后的空格
ci" 修改双引号内的内容（光标在引号内任何位置都可以）
di( 或 dib 删除括号内的内容
da( 删除括号及其中的内容
yi{ 复制花括号内的内容
cit 修改 HTML/XML 标签内的内容
dap 删除整个段落

记住几个操作符和几个文本对象，就相当于记住了几十个命令。

四、插入模式

进入插入模式

命令 插入的位置
i / a 光标前 / 光标后
I / A 行首第一个非空白字符前 / 行尾
o / O 在当前行下方 / 上方新开一行
s 删除光标处的字符后插入
S 或 cc 删除整行内容后插入
C 删除到行尾后插入

插入模式中的快捷键

按键 作用
<Esc> 或 Ctrl+[ 回到普通模式
Ctrl+w 删除光标前的一个单词
Ctrl+u 删除光标前到行首的内容
Ctrl+n / Ctrl+p 根据文件中已有的单词自动补全
Ctrl+r = 内置计算器：输入表达式（如 3*7+1）后按 <Enter>，结果插入到光标处
Ctrl+o 临时执行一个普通模式命令，然后回到插入模式

五、可视模式

命令 作用
v 按字符选择
V 按行选择
Ctrl+v 按矩形块选择
gv 重新选中上一次选择的区域
o 光标跳到选区的另一端
O 块选择时，光标跳到同一行的另一个角

选中之后，可以用操作符处理选区：

命令 作用
y / d / c 复制 / 删除 / 修改选区
> / < 增加 / 减少缩进
u / U / ~ 变成小写 / 变成大写 / 切换大小写
J 合并选中的行
: 对选中的行执行命令行命令（自动填入 :'<,'>）

块选择的妙用：Ctrl+v 选中多行的同一列，按 I 输入内容，再按 <Esc>，内容会插入到每一行，常用于批量加注释。

六、命令行模式

保存与退出

命令 作用
:w 保存
:w file 另存为 file
:q 退出（有未保存的修改时会拒绝）
:q! 不保存，强制退出
:wq 保存并退出
:x 或普通模式下 ZZ 有修改时保存后退出，没有修改时直接退出（不改变文件的修改时间）
ZQ 普通模式下，不保存直接退出，相当于 :q!
:wa / :qa 保存全部 / 退出全部（打开多个文件时）

查找

命令 作用
/abc 从光标处向下查找 abc
?abc 从光标处向上查找 abc
n / N 下一个 / 上一个匹配（相对于查找方向）
* / # 向下 / 向上查找光标所在的单词
/^abc / /abc$ 查找行首 / 行尾的 abc
/\<abc\> 只匹配完整的单词 abc
:noh 取消查找结果的高亮

替换

替换的格式是 :范围s/查找/替换/标志：

命令 作用
:s/a/b/ 当前行的第一个 a 替换为 b
:s/a/b/g 当前行的所有 a 替换为 b
:%s/a/b/g 全文的所有 a 替换为 b
:%s/a/b/gc 全文替换，每一处都询问确认
:10,20s/a/b/g 第 10 到 20 行替换
:'<,'>s/a/b/g 在可视模式选中的行中替换
:%s/\s\+$// 删除全文行尾的空白

行操作与其他

命令 作用
:10,20d 删除第 10 到 20 行
:10,20m 30 把第 10 到 20 行移动到第 30 行之后
:set nu / :set nonu 显示 / 隐藏行号
:set paste 粘贴模式（从外部粘贴代码时不自动缩进），:set nopaste 关闭
:syntax on 开启语法高亮
:!命令 执行 shell 命令，如 :!ls

多文件

命令 作用
:e file 打开另一个文件
:ls 列出所有打开的文件（缓冲区），%a 表示当前文件，# 表示上一个文件
:bn / :bp 下一个 / 上一个缓冲区
:b n 切换到编号为 n 的缓冲区
:sp file / :vsp file 上下 / 左右分屏打开文件
Ctrl+w w 在分屏窗口之间切换

编辑命令行

按键 作用
↑ / ↓ 上一条 / 下一条历史命令（先输入开头几个字符，可以只翻看以它开头的命令）
Ctrl+b / Ctrl+e 移到命令行开头 / 结尾
Shift+← / Shift+→ 向左 / 向右移动一个单词
Tab 补全命令或文件名

七、配置文件 .vimrc

在命令行模式中设置的选项（如 :set nu），关闭 Vim 后就失效了。要永久生效，写进个人配置文件 ~/.vimrc（没有就新建）。系统的全局配置文件一般是 /etc/vimrc 或 /etc/vim/vimrc，个人配置的优先级更高。一个简单的例子：

set number          " 显示行号
syntax on           " 语法高亮
set tabstop=4       " Tab 显示为 4 个空格宽
set shiftwidth=4    " 缩进 4 个空格
set expandtab       " 输入 Tab 时插入空格
set autoindent      " 新行沿用上一行的缩进
set hlsearch        " 高亮查找结果
set incsearch       " 输入查找内容时即时跳转
set ignorecase      " 查找时忽略大小写……
set smartcase       " ……但查找内容包含大写字母时区分大小写
set encoding=utf-8

八、交换文件与异常退出

编辑文件时，Vim 会在同一目录下生成一个隐藏的交换文件 .文件名.swp，用于在异常退出（终端断开、系统崩溃）后恢复内容。再次打开文件时，如果交换文件还在，Vim 会提示你选择：

  • R（Recover）：从交换文件恢复未保存的修改；
  • E（Edit anyway）：忽略交换文件，直接编辑；
  • D（Delete it）：删除交换文件。

确认不需要恢复后，也可以在终端里手动删除：rm .文件名.swp。如果同一个文件被另一个 Vim 进程打开着，也会出现这个提示，这时应该先关闭另一个进程。
