这个博客的大部分内容是成体系的系列教程：每个系列从基础讲起，按顺序读下来就是一门完整的课。系列之间也有先后关系，比如学回归之前最好先懂统计，学因果推断之前最好先会回归。这一页帮你找到适合自己的起点和顺序。

所有系列的代码都是 Python，文中的输出都是实际运行的结果。如果你还不会 Python，几条路线都从第一步“Python 基础”开始。每篇含代码的文章顶部都可以下载对应的 Jupyter 笔记本；遇到不认识的术语，可以查术语表（中英文对照，链接到讲解它的文章）。

第一步：Python 基础（所有路线共用）

你的情况 从哪里开始
完全没有写过代码 「Python 零基础入门」：每篇只讲一件事，最后做一个记账本小项目
会一点 Python，想真正弄懂它 「Python 从入门到精通」：对象模型、描述符、元类、并发和性能优化
要用 Python 做数据分析 再读四篇库的入门：NumPy（数组与计算）→ pandas（表格与时间序列）→ Matplotlib（画图）→ SciPy（统计与优化）

还没有装好 Python？先看Python 环境怎么装；不熟悉命令行的话，命令行入门只讲最常用的那一部分。

不需要把 Python 系列全部读完再往下走。会写函数、会用 pandas 读数据和画图，就可以进入下面的路线，遇到不懂的再回来查。

路线一：做实证研究（经济学、管理学、公共政策）

目标是能独立完成一篇实证论文：估计、推断、识别因果效应，并且让结果可以复现。

开始之前，可以先读两篇轻松的单篇文章：三个改变经济学的研究讲霍乱地图、最低工资和征兵抽签的故事，看看可信的因果证据长什么样；数据会骗人讲辛普森悖论、伯克森悖论、幸存者偏差和均值回归。

  1. 统计基础：「统计学基础：概率与推断」。标准误、置信区间、假设检验是后面所有内容的语言，第 03、04、06、08 篇最重要。
  2. 回归分析：「计量经济学基础：回归分析」。系数怎么解释、标准误怎么选、回归什么时候会出错。这是整条路线的核心。
    • 论文要处理内生性、回应审稿人“有没有内生性问题”：读 「内生性：从诊断到识别」，系统讲遗漏变量、测量误差、反向因果，以及固定效应、工具变量、敏感性分析等方法的适用条件和常见误区。之后读 「机制、异质性与稳健性」：机制检验、调节效应、异质性分析和稳健性检验的可靠做法。
    • 数据是类别、计数、在 0 处堆积，或者有样本选择、需要 GMM：接着读 「计量经济学进阶：非线性模型与 GMM」。
    • 要测算企业、地区的效率或全要素生产率：读 「随机前沿分析」，并和「运筹分析」中的 DEA 对照。
  3. 识别因果效应，按研究设计选择：
    • 有政策实施前后的面板数据：「DID 从入门到精通」；
    • 想系统学习各种方法（随机实验、匹配、工具变量、断点回归、合成控制、双重机器学习）：「因果推断从入门到精通」。
    • 学完方法想在真实数据上练手：「经典论文复现」，用原始数据逐表复现九篇经典论文（增长回归、简历实验、STAR、LaLonde、Card、Angrist–Evans、险胜选举、城堡法、波士顿房贷），并检查结论对设定的敏感性。
  4. 按研究需要补充：
    • 数据是时间序列（GDP、通胀、利率）：「时间序列计量从入门到精通」；
    • 研究的概念要用问卷量表测量（满意度、组织承诺、能力），或者要检验中介机制：「结构方程模型」；
    • 数据带有地理位置（省市县、城市街区），关心相邻地区之间的相关和溢出：「空间计量入门」；
    • 数据是关系（贸易、持股、合作、引用、朋友），想描述网络结构或估计同群效应：「复杂网络分析」；
    • 想用机器学习做预测，或者用于因果推断：「统计学习与机器学习」。
    • 研究金融市场（资产定价、公司金融、事件研究）：「金融实证方法」；
    • 数据要从网上获取，或者要把新闻、年报、政策文件这类文本变成变量：「数据获取与文本分析」。
    • 数据量大、分散在多张表里，或者需要长期维护一个研究数据库：「SQL 与数据库」。
  5. 工作流程：「实证研究工作流」。项目结构、Git、数据清洗、表格和数字的自动化。建议在开始第一个项目时就读，越早养成习惯越好。论文中的图怎样画，见论文里的图怎样画才好；用 AI 工具辅助时要检查什么，见用 AI 辅助写代码和做研究。
  6. 写作与发表：怎样找研究选题（好选题的四个条件、选题来源、一页纸研究设计）→ 文献检索与管理（找文献、Zotero、快速读论文）→ 「文献综述与元分析」（写有论点的综述；系统综述和元分析的完整方法）→ LaTeX 论文排版入门 → 怎样写实证论文的引言和回复审稿意见。
  7. 投稿之前：对照实证研究最常见的 20 个错误逐条检查，文末有一份检查清单。

路线二：量化投资与金融数据分析

目标是能正确地分析金融数据，写出不偷看未来、扣除成本的回测，并判断结果是否可信。

  1. Python 和四个数据分析库（见第一步），重点是 pandas 的时间序列部分。
  2. 统计基础：「统计学基础：概率与推断」，特别是假设检验、多重检验与 p-hacking，它们解释了为什么大多数回测结果不可信。
  3. 回归与时间序列：回归分析的前六篇，然后是「时间序列计量」，重点是平稳性、协整和波动率（GARCH）。
  4. 金融实证方法：「金融实证方法」。收益率与超额收益、CAPM 与因子模型、组合排序、Fama–MacBeth 回归和事件研究，金融学论文中最常用的实证工具。
  5. 期权定价：「期权定价与衍生品」。无套利与风险中性定价、二叉树、Black–Scholes、对冲、蒙特卡洛，以及隐含波动率和 VIX。
  6. 期货回测：「用 Python 做期货回测：以豆粕为例」。数据、绩效指标、回测框架、各类策略，以及过拟合与样本外检验。
  7. 机器学习预测：「统计学习与机器学习」，特别是时间序列的交叉验证和预测股票收益率的实战。
  8. 组合优化：「优化建模从入门到精通」的凸优化和不确定性部分，讲了均值方差模型和鲁棒优化。

路线三：机器学习与数据分析

  1. Python 和四个数据分析库（见第一步）。
  2. 统计基础：「统计学基础：概率与推断」。偏差、方差、抽样分布这些概念，是理解机器学习的钥匙。
  3. 回归分析：回归分析的前五篇。线性回归是几乎所有机器学习模型的出发点。
  4. 机器学习：「统计学习与机器学习」。从偏差–方差权衡、交叉验证，到正则化、决策树、随机森林和梯度提升。
  5. 深度学习：「深度学习入门」。从手写神经网络、PyTorch 到卷积网络、LSTM 和 Transformer，以及深度学习在什么情况下不如简单的方法。
  6. 处理文本数据：「数据获取与文本分析」。用 requests 和 API 获取数据，中文分词、TF-IDF、词典法、主题模型和文本分类。
  7. 存储和查询数据：「SQL 与数据库」。SQL 的查询、连接和窗口函数，以及用 DuckDB 处理内存装不下的数据。
  8. 分析关系数据：「复杂网络分析」。中心性、社区发现、随机图与零模型，以及网络上的传播。
  9. 想把预测模型用来回答“为什么”：因果推断系列的第 13 篇（异质性效应）和第 14 篇（双重机器学习）。

路线四：编程与计算机基础

  1. 「Python 零基础入门」 → 「Python 从入门到精通」。
  2. 数据结构与算法：数据结构与算法入门讲原理，用 C 语言实现常用数据结构是配套代码，两篇对照着读。
  3. 正则表达式：「正则表达式」三篇，从基础语法到 pandas 和中文文本清洗，附速查表。
  4. 命令行与开发环境：命令行入门、Python 环境怎么装。
  5. 其他语言和工具：Java 基础（共三篇）、Vim 常用命令、看懂电脑配置。

路线五：运筹优化

「优化建模从入门到精通」：从决策变量和图解法讲起，经过线性规划、对偶、整数规划建模技巧、网络流、路径排程，到非线性与凸优化、随机与鲁棒优化和启发式算法。需要会一点 Python，不需要统计基础。

之后读「运筹分析」：DEA 效率评价与 Malmquist 指数、综合评价方法（熵权法、TOPSIS、层次分析法、灰色关联）及其局限、库存与排队、离散事件仿真、动态规划与马尔可夫决策过程。做经管实证、要测算效率或构建指数的读者，可以直接读它的前五篇。

  1. 00
    写给完全没学过编程的你

    一套真正从零开始的 Python 入门教程，共 15 篇。不需要任何编程基础，每篇只讲一件事，每个例子都能直接运行。本篇介绍这个系列怎么读、能学到什么。

  2. 01
    安装 Python，写出第一个程序

    一步一步在 Windows（以及 Mac）上安装 Python，认识交互模式和 IDLE 编辑器，写出并保存你的第一个程序。

  3. 02
    print 和变量

    学会用 print 显示各种内容、用注释给代码写备注，理解“变量”就是贴在数据上的名字标签，以及等号在编程里的真正含义。

  4. 03
    数字和计算

    把 Python 当成计算器：加减乘除、整除、取余、乘方、运算顺序，整数和小数的区别，为什么 0.1 + 0.2 不等于 0.3，以及 += 这种简写。

  5. 04
    字符串，处理文字

    文字在 Python 里叫“字符串”。本篇学习字符串的拼接、重复、长度、取出某个字、截取一段，常用的大小写转换与替换，文字和数字之间的转换，以及最好用的 f-string。

  6. 05
    input，和用户对话

    用 input() 让程序向用户提问、接收键盘输入。重点理解“input 拿到的永远是字符串”，学会用 int() 和 float() 转换，并动手写几个能互动的小程序。

  7. 06
    if，让程序做判断

    让程序根据不同情况做不同的事：比较大小、True 和 False、if / else / elif 的写法、缩进的规则，以及用 and、or、not 组合多个条件。

  8. 07
    循环，让程序重复做事

    用 for 循环和 range() 让代码重复执行指定次数，用 while 循环在条件成立时一直重复，用 break 和 continue 控制循环，最后做一个猜数字游戏和九九乘法表。

  9. 08
    列表，一次存很多东西

    一个变量只能存一个数据，列表可以存一整组。本篇学习列表的创建、按编号取值和修改、添加和删除元素、用 for 循环逐个处理，以及求和、排序、拆分文字等常用操作。

  10. 09
    字典，按名字查东西

    字典像一本通讯录，通过“名字”直接查到“内容”。本篇学习字典的创建、查询、添加、修改、删除和遍历，并用它做通讯录、统计词频和管理学生信息。

  11. 10
    函数，把代码打包

    函数就是给一段代码起个名字，想用的时候喊一声名字就行。本篇学习如何定义和调用函数、用参数传入数据、用 return 交回结果、默认参数，以及函数里的变量为什么在外面用不了。

  12. 11
    看懂报错信息

    报错不是失败，而是 Python 在告诉你哪里出了问题。本篇教你从下往上读懂报错信息，认识最常见的十种错误，学会用 print 找问题，以及用 try/except 让程序在出错时不崩溃。

  13. 12
    读写文件

    程序关掉，变量里的数据就没了。本篇学习用 open() 和 with 把数据写进文件、从文件里读出来、在文件末尾追加内容，以及文件放在哪里、中文乱码怎么办，最后让通讯录能保存数据。

  14. 13
    模块，使用别人写好的代码

    不用什么都自己写。本篇学习用 import 导入模块，使用 math 做数学计算、random 生成随机数、datetime 处理日期，把自己的函数放进模块，并简单了解如何用 pip 安装第三方库。

  15. 14
    综合项目，命令行记账本

    把前面学过的变量、输入、判断、循环、列表、字典、函数、异常处理、文件读写和模块全部用上，一步一步做出一个能保存数据的记账本程序。最后聊聊学完之后该往哪里走。

    大数定律与中心极限定理

  4. 03
    遗漏变量的敏感性分析——Oster 的 δ 与 Cinelli–Hazlett 的稳健值

    遗漏变量无法观测，也就无法直接检验。敏感性分析换一个问法：遗漏变量要有多强，才能推翻结论？本篇手写两种最常用的方法。Oster（2019）的方法同时看系数和 R² 的变化：模拟显示只看系数稳定性会误判，而在“可观测与不可观测变量同等重要”的设定下，Oster 的偏误调整估计几乎恢复了真实值。Cinelli 和 Hazlett（2020）的方法用偏 R² 刻画遗漏变量的强度：偏误公式在样本中是精确的恒等式（用一个实际观测到的变量核对，误差为 0），稳健值 RV 给出一个容易解释的数字，并可以与已观测的控制变量的强度比较。

  5. 04
    测量误差——衰减偏误、控制变量的误差与补救办法

    解释变量测得不准，系数就会向 0 偏，偏多少取决于信度；这是内生性的第二个来源，在用代理变量、问卷数据和财务指标的研究中很常见。本篇用模拟逐一核对：衰减偏误等于真实系数乘以信度；控制变量有测量误差时，它没能控制住的混杂会跑进核心变量的系数，偏误方向可以是任意的；被解释变量的测量误差只影响精度、不造成偏误，但非随机的误差例外；用同一变量的第二次测量作工具变量可以纠正衰减偏误，前提是两次测量的误差不相关，误差相关时工具变量同样有偏。

  6. 05
    反向因果与“滞后一期”——为什么滞后解释变量通常不能解决内生性

    “为了缓解反向因果，我们把解释变量滞后一期”几乎出现在每一篇国内实证论文里。本篇用面板模拟说明这个做法什么时候有效、什么时候无效：误差项没有序列相关、只存在同期的反向因果时，滞后一期确实消除了偏误，但估计的是另一个量（滞后一期的效应，被解释变量的持续性缩小了）；误差项或遗漏变量有持续性时（这才是常态），滞后一期几乎没有改善，误差持续性为 0.8 时偏误只减少了不到一半。用滞后一期作工具变量也一样。最后讨论 Granger 检验和“反向回归”为什么不能证明没有反向因果。

  7. 06
    工具变量实务——常见工具变量的风险与“组内均值”工具变量

    工具变量的原理和弱工具变量问题在因果推断系列中已经讲过，本篇讲实务。先梳理实证论文中常见的几类工具变量各自的风险；然后用模拟剖析最常见也最成问题的一种：用“同行业（同地区）其他企业的均值”作工具变量。存在行业层面的共同冲击时它有偏；加入行业固定效应后，它与内生变量之间只剩下机械的负相关，第一阶段系数正好是 −(n−1)、拟合完美，IV 估计与 OLS 完全相同。接着说明过度识别检验通过不能证明工具变量有效：两个工具变量朝同一方向违反排他性时，Hansen J 检验几乎从不拒绝。最后介绍“零第一阶段”检验和一份工具变量的报告清单。

  8. 07
    份额—冲击（Bartik）工具变量

    Bartik 工具变量用“各地区的初始行业结构 × 全国各行业的增长”构造地区层面的外生冲击，是区域经济、劳动和贸易研究中最常用的工具变量之一。近年的研究指出它的识别可以来自两个不同的假设：份额外生（Goldsmith-Pinkham、Sorkin 和 Swift 2020）或冲击外生（Borusyak、Hull 和 Jaravel 2022）。本篇手写 Bartik 估计、Rotemberg 权重（核对“总估计 = 各行业单独估计的加权平均”这个恒等式）和冲击层面的标准误。模拟显示：权重最大的行业的份额与误差相关时，估计从 1.02 降到 0.29，Rotemberg 权重能指出是哪个行业；不同地区因为行业结构相似而误差相关时，常规的稳健标准误使 95% 置信区间只覆盖真实值 72% 的时间，冲击层面的标准误回到 91%。

  9. 08
    不完全有效的工具变量——Conley 近似外生与 Lewbel 异方差工具变量

    排他性约束几乎从来不能严格成立。与其坚持“工具变量完全有效”，不如问：如果它有轻微的直接影响，结论还成立吗？本篇手写 Conley、Hansen 和 Rossi（2012）的两种方法：并集置信区间（UCI）和局部趋于零（LTZ）近似，并核对 LTZ 所依据的恒等式（误差为 0）。模拟中工具变量对结果有 0.05 的直接影响时，普通 IV 的 95% 置信区间覆盖真实值的概率只剩 35%，UCI 在假设的范围包含真实违反程度时覆盖率回到 95% 以上。然后讨论 Lewbel（2012）的异方差工具变量：在它的假设下确实能恢复真实效应，假设不成立时同样有偏，而且这个假设和排他性一样难以检验，不宜作为主要的识别策略。

  10. 09
    非线性模型中的内生性——禁止回归、控制函数与内生性检验

    被解释变量是二元变量或计数变量时，常见的做法是“先用工具变量回归得到拟合值，再把拟合值代入 Probit”。这叫“禁止回归”，结果是不一致的。本篇用模拟比较四种做法在平均边际效应上的表现：忽略内生性的 Probit、禁止回归、线性概率模型的 2SLS 和控制函数法（Rivers–Vuong）。控制函数法最接近真实值；线性概率模型的 2SLS 偏低一成左右；禁止回归在没有内生性时就有偏，有内生性时偏误更大。控制函数法还顺便给出一个稳健的内生性检验，但检验不显著不能说明变量是外生的：样本为 500、内生性较弱（ρ = 0.1）时，它只有 18% 的概率发现内生性。最后把控制函数法用到泊松回归。

  11. 10
    匹配与熵平衡——能处理什么，不能处理什么

    很多论文把倾向得分匹配（PSM）写在“内生性处理”一节里。本篇说明它能处理的只是“可观测变量造成的选择”。先手写熵平衡（Hainmueller 2012）：通过对偶问题求权重，使对照组的协变量均值和方差与处理组完全相同（误差在 1e-8 以内）。然后在两种情形下比较 OLS、PSM 和熵平衡：选择只依赖可观测变量、且结果与协变量是非线性关系时，熵平衡和 PSM 的偏误都比线性回归小，熵平衡的均方根误差最小；存在不可观测的混杂时，三种方法的偏误几乎一样大，匹配得再好也无济于事。最后说明 PSM-DID 为什么比单纯的 PSM 更有说服力。

  12. 11
    实战——一套完整的内生性分析，以及怎样写和怎样回应审稿人

    全系列的收尾：用一份模拟的企业面板（数字化投入对生产率的影响，真实效应 0.2）走完内生性分析的完整流程。混合 OLS 得到 0.97，双向固定效应 0.64，“滞后一期”0.05，用同行业其他企业的均值作工具变量 1.00，都偏离真实值；用地区宽带建设进度作工具变量得到 0.19，95% 置信区间覆盖真实值，Anderson–Rubin 区间和近似外生分析给出了结论能承受的排他性违反程度。最后揭晓数据中埋下的四种内生性来源，并给出论文中内生性一节的写法和回应审稿人的要点。

    系列导读

    实证论文在主回归之后通常有三节：机制分析、异质性分析和稳健性检验，也是审稿意见最集中的地方。本系列共 6 篇：“三步法”中介检验为什么在经济学中不可靠，更可取的写法；中介的敏感性分析、序贯 g 估计和用异质性作为机制证据；调节效应与交互项的解释、分箱估计和非线性模型的交互效应；组间系数差异的检验、置换检验和多重检验校正；稳健性检验应当回答什么问题、规格曲线和随机化推断；最后在一份数据上完成全部分析并讨论写法。每个结论都在真实效应已知的模拟数据上检验。

  2. 01
    机制检验的常见写法及其问题

    实证论文的机制检验最常见的写法是“三步法”：处理影响机制变量、机制变量影响结果、加入机制变量后处理的系数变小。本篇用模拟说明三个问题：机制变量对结果的影响是内生的，即使处理是随机分配的，“加入后系数变小”也可能完全来自混杂，真实的中介效应为 0 时，300 次模拟中逐步法每一次都“发现”了显著的中介；处理本身内生时，第一步也是有偏的；用与结果同时测量、甚至就是结果一部分的变量作机制变量，会得到机械的“中介”。最后给出江艇（2022）建议的做法：在处理可识别的前提下只检验处理对机制变量的影响，机制变量对结果的作用依靠理论和文献论证。

  3. 02
    更严格的机制分析——受控直接效应、敏感性分析与异质性证据

    如果确实要估计机制变量对结果的作用，需要更强的设计或更透明的假设。本篇手写三种方法：一是 Imai、Keele 和 Yamamoto 的中介敏感性分析，先用模拟核对公式（把真实的误差相关系数代入，恰好恢复真实的中介效应 0.2），再看结论在多大的混杂下会被推翻；二是 Acharya、Blackwell 和 Sen 的序贯 g 估计，处理“中间混杂因素”（受处理影响、又影响机制和结果的变量）：同时控制机制变量和中间混杂因素的回归给出 0.31，真实的受控直接效应是 0.42，序贯 g 估计得到 0.44（自助法标准误 0.03）；三是用事先预测的异质性作为机制的证据，以及它的局限。

  4. 03
    调节效应——交互项怎样解释、何时会误导

    调节效应用交互项来估计，看起来简单，但解释上的错误很多。本篇说明：主效应的系数是调节变量取 0 时的效应，中心化只改变主效应、不改变交互项（数值上核对完全一致）；应当报告处理效应随调节变量变化的曲线及其置信区间，而不只是交互项的显著性；线性交互项假设效应随调节变量线性变化，Hainmueller 等的分箱估计可以检查这个假设，模拟中真实效应呈倒 U 形时，线性交互项给出接近 0 的交互系数；Logit 等非线性模型中，交互项的系数不等于概率上的交互效应（Ai 和 Norton 2003），交互项系数为 0 时概率上的交互效应仍然存在。最后强调调节变量必须是处理之前的变量。

  5. 04
    异质性分析——组间差异的检验与多重比较

    异质性分析最常见的错误是：一组显著、另一组不显著，就说“效应只存在于第一组”。本篇用模拟说明，两组的真实效应完全相同、只是样本量不同时，这种情形出现的概率约为一半。正确的做法是直接检验组间差异：全交互模型（与分组回归的系数完全相同，核对差异为 0）、SUEST 的思路，以及国内论文常用的“费舍尔组合检验”（组别标签的置换检验），三种方法的 p 值接近。然后讨论多个异质性维度带来的多重检验问题：效应其实完全同质时，检验 10 个维度至少有一个“显著”的概率约四成，Holm 和 BH 校正把它降回 5% 左右；数据驱动地寻找异质性时，用一半样本发现、另一半样本检验。

  6. 05
    稳健性检验——每一项在排除什么，规格曲线与随机化推断

    稳健性检验常常写成一张长长的表：替换变量、缩尾、剔除样本、改变聚类……全部通过，结论“稳健”。本篇用一份埋有行业—年份冲击的模拟面板说明，这些检验如果没有针对真正的偏误来源，全部通过也说明不了什么：缩尾、换控制变量、剔除样本、换聚类层级都给出差不多的有偏估计，只有加入行业×年份固定效应这一项把估计拉回真实值。然后手写规格曲线：24 种设定中，固定效应的设定决定了估计落在曲线的上半部分还是下半部分，一眼就能看出哪个选择最关键；再用随机化推断（打乱处理组）检验结果是否可能纯属偶然；最后模拟“从很多设定中挑最显著的一个”会使假阳性率升到多少。

    实战——在一份数据上完成三节分析，以及怎样写

    系列的收尾：一份模拟的企业面板（某项科技金融政策对企业创新的影响，真实效应 0.3，通过缓解融资约束起作用），依次完成主回归、机制、异质性和稳健性分析。机制部分只估计政策对两个候选机制变量的影响：融资约束显著缓解；管理效率出现了一个偶然的、方向相反的显著结果（模拟中它其实不受影响），说明机制检验也有多重检验问题；如果用“三步法”，管理效率会被写成某种“遮掩效应”。异质性部分检验事先确定的“基期融资约束”维度，组间差异显著，置换检验一致；另外四个探索性维度在 Holm 校正后都不显著。稳健性部分用规格曲线和随机化推断。最后给出机制、异质性、稳健性三节的写法和常见的表述错误。

  5. 04
    LaLonde（1986）与 Dehejia–Wahba（1999）——观测数据能复现实验的结果吗

    复现方法论文献中最著名的“考试”：用一个随机实验（美国 NSW 就业培训项目）的结果作为标准答案，把实验对照组换成全国住户调查（CPS）中的普通人，检验非实验方法能不能得到同样的答案。实验估计是 1794 美元；直接比较培训者与 CPS 样本得到 −8498 美元，加入人口特征后仍为负，只有控制了培训前两年的收入，回归才接近正确答案。按 Dehejia 和 Wahba 的做法估计倾向得分，发现一万五千多名 CPS 对照中绝大多数与培训者毫无可比性；在共同支撑内做匹配和加权，估计回到 1600～1900 美元附近。最后用“培训前收入的安慰剂检验”、换用 PSID 对照组和多种设定说明：这个成功依赖于培训前收入这一关键变量和样本的选取，Smith 和 Todd 的批评正是针对这一点。

  6. 05
    Card（1995）——用离大学的远近估计教育回报

    复现工具变量最经典的应用之一：用“1966 年家附近是否有四年制大学”作为受教育年数的工具变量，估计教育的收入回报。OLS 估计每多受一年教育工资高 7.5%，第一阶段系数 0.320（F 约 13），工具变量估计 13.2%（标准误 5.5%），与论文和 Wooldridge 教材的数字相同，并用简约式除以第一阶段手工验证。接着讨论这个结果的三个疑点：第一阶段不算强（Anderson–Rubin 置信区间约为 2.9% 到 28%）；工具变量与 IQ 和父母受教育程度相关，在有 IQ 数据的子样本中估计降到 8% 左右；以及“IV 大于 OLS”的几种解释（测量误差、局部平均处理效应），并检查第一阶段在不同家庭背景之间是否不同。

  7. 06
    Angrist 和 Evans（1998）——前两个孩子同性别，母亲还工作吗

    复现“好工具变量”的教科书案例：前两个孩子性别相同的家庭更可能生第三个孩子，而孩子的性别是随机的，因此可以用它估计多生一个孩子对母亲劳动供给的影响。用 1980 年美国人口普查中 254,654 名已婚母亲的数据（与论文样本量相同），验证工具变量与母亲特征无关，手工计算 Wald 估计（第一阶段 6.75 个百分点，多生一个孩子使母亲工作的概率下降约 14 个百分点、每年工作周数减少约 6 周），再用 2SLS 加入控制变量。接着用“两个男孩”“两个女孩”两个工具变量做过度识别检验：按论文的设定（控制第一个孩子的性别）在 1% 水平上拒绝，不控制时不拒绝，原因是两种一男一女的家庭生育数量相同、母亲的工作却不同；并讨论 Rosenzweig 和 Wolpin 等对排他性的质疑。最后估计遵从者在总体中的比例，说明这里的 LATE 是哪一部分人的效应。

  8. 07
    Lee、Moretti 和 Butler（2004）——选民选择政策，还是影响政策

    复现断点回归在政治经济学中最有影响的应用：用美国众议院 1948—1990 年的选举数据，比较民主党以微弱优势赢得和输掉的选区，回答“议员的投票立场是由选民决定（政策趋同），还是由当选者本人决定”。在得票率 48%～52% 的窗口内复现论文表 I 的核心数字（下一届议员的 ADA 得分高 21.28 分，民主党下次再赢的概率高 0.48），并用“当选效应 × 在任优势”分解出两部分，发现几乎全部来自“选择谁”，而非“影响当选者”。再用局部线性回归、三角核和多个带宽重新估计，画出断点图；最后做有效性检验：得票率的分布在 50% 处没有明显的堆积，但上一届的得票率在 50% 处有一个小而显著的跳跃，这正是 Caughey 和 Sekhon（2011）对美国众议院险胜选举的质疑。

  9. 08
    Cheng 和 Hoekstra（2013）——“城堡法”增加了凶杀吗

    复现一篇交错实施的双重差分（DID）论文：2000—2010 年美国 21 个州扩大了“城堡法”（允许在受到威胁时使用致命武力自卫，不必先退让），这会威慑犯罪，还是让冲突升级为凶杀？用 50 个州 11 年的面板数据，复现论文的主要设定（州和地区×年份固定效应、按人口加权、按州聚类），凶杀率上升约 9%（系数 0.086，论文的结论是约 8%），而入室盗窃、抢劫、伤害等犯罪没有下降，即没有威慑效应。再做事件研究，检查法律实施前各年没有预先的趋势；用只以从未实施的州为对照的“干净比较”（Callaway–Sant'Anna 思路）重新估计，总体结果与双向固定效应接近，但分批次看，效应几乎全部来自最早立法的佛罗里达州；最后用随机化推断（随机打乱哪些州、何时立法）计算 p 值，说明 50 个州的样本在推断上需要格外小心。

  10. 09
    Munnell 等（1996）——波士顿的房贷申请中有种族歧视吗

    复现一篇推动了美国金融监管政策的实证研究：1990 年波士顿地区的房贷申请中，黑人申请者被拒的比例（28.3%）是白人（9.3%）的三倍，这是歧视，还是黑人申请者的财务和信用状况更差？用 Stock 和 Watson 教材整理的 2380 份申请数据，从只控制还款收入比开始逐步加入贷款价值比、信用记录、是否被拒绝房贷保险等变量，观察种族差距从 19 个百分点缩小到约 8 个百分点；用线性概率模型、Logit 和 Probit 估计并比较平均边际效应，计算“条件相同的白人和黑人”的预测拒贷率。最后讨论剩余差距能否解释为歧视：用 Oster 的方法计算遗漏变量需要多强才能让差距消失，以及后续研究对数据质量和“结果检验”的争论。

  11. 10
    复现中遇到的问题，以及怎样写一份复现报告

    系列的总结篇。先区分三种“复现”：用原数据原代码得到相同的数字（计算复现）、在原数据上改变设定检查稳健性、在新数据上重做研究，并介绍经济学中复现成功率的研究。然后回顾本系列九篇论文中遇到的所有差异，归纳出七类常见原因：公开数据的舍入、样本的定义、遗漏或不同的控制变量、标准误的聚类层级、估计量的细节、结论依赖少数观测，以及数据中的重复记录。接着给出一套复现的工作流程和一个自动生成“论文数字与复现数字对照表”的小工具（按论文的报告精度判断差异是否超出舍入误差，用 MRW 的表 I 演示），最后给出复现报告的结构和写作要点。

    最大似然估计

    多项选择模型——多项 Logit、条件 Logit 与 IIA

    有序选择模型——有序 Probit 与有序 Logit

    样本选择——Heckman 模型

    只能观察到一部分人的结果（只有工作的人才有工资，只有申请贷款的人才有利率），而这部分人又不是随机的，就会产生样本选择偏差。本篇推导选择偏差的来源和逆米尔斯比率，用 Mroz 数据实现 Heckman 两步法并用自助法计算标准误，复现伍德里奇教材已婚女性工资方程的结果；再用一个已知真实答案的模拟说明选择偏差有多大、Heckman 方法如何修正它，以及为什么没有排除性约束时估计会变得极不稳定。

    随机前沿分析（SFA）用统计模型把偏离前沿的距离分成随机噪声和技术无效率，是与 DEA 并列的效率测算方法。本系列共 5 篇：复合误差模型、最大似然和 JLMS 效率估计；无效率的分布假设、“是否存在无效率”的边界检验和效率的置信区间；无效率的决定因素与两步法的偏误；面板随机前沿模型与异质性、无效率的区分；与 DEA 的比较和全要素生产率的分解。Python 中没有成熟的 SFA 库，所有模型都手写，并用数值积分核对密度和效率公式，在真实参数已知的模拟数据上检验。

  2. 01
    基本模型——复合误差、最大似然与 JLMS 效率估计

    随机前沿分析（SFA）把生产函数的误差分成两部分：对称的随机噪声和只能为正的无效率。本篇从模型出发，手写半正态随机前沿模型的密度函数（用数值卷积核对，误差在 1e-12 量级）、最大似然估计和 Jondrow 等（JLMS）的个体效率估计公式（用数值积分核对后验期望）。在真实参数已知的模拟数据上，最大似然恢复了生产函数的系数和两种误差的方差，平均效率估计得很准，但个体效率的估计与真实效率的秩相关只有 0.65，估计排名前 50 的企业中只有约四分之一真实也在前 50。最后讨论 OLS 残差的“错误偏度”问题：样本小、无效率不明显时，它会让估计的无效率直接变成 0。

  3. 02
    无效率的分布、无效率是否存在的检验与效率的置信区间

    无效率项的分布要由研究者假设。本篇手写指数分布和截断正态分布的随机前沿模型（密度均用数值卷积核对），在同一份数据上比较三种分布：平均效率随分布假设变化，但企业的效率排序几乎不变（秩相关 0.99 以上）。然后讨论“是否存在无效率”的检验：原假设在参数空间的边界上，似然比统计量服从混合卡方分布，用普通的卡方临界值会使检验过于保守，模拟中拒绝率只有 2% 左右，用混合分布的临界值 2.71 回到约 5%。最后实现 Horrace–Schmidt 的效率置信区间，模拟显示覆盖率接近 95%，但区间很宽，大多数企业之间的效率差异在统计上无法区分。

  4. 03
    无效率的决定因素——为什么两步法有偏，一步法怎样做

    研究“什么因素影响效率”时，最常见的做法是先估计 SFA 得到效率，再把效率对影响因素回归。Wang 和 Schmidt（2002）指出这个两步法有两重偏误：第一步忽略了影响因素，若它与投入相关，生产函数的系数就是有偏的；第二步的效率估计向平均值收缩，影响因素的作用被严重低估。本篇手写一步法（让无效率的尺度依赖于影响因素，与生产函数一起用最大似然估计），在 100 次模拟中比较：两步法把影响因素的平均边际效应低估了约三成，资本的系数也偏低（0.37，真实值 0.4）；一步法两者都接近真实值。最后说明 Battese–Coelli（1995）的设定和边际效应的计算。

  5. 04
    面板数据——效率是否随时间变化，异质性与无效率怎样区分

    面板数据让每个企业有多次观测，可以更准确地估计效率，但也带来一个根本的问题：企业之间不随时间变化的差异，到底是“无效率”还是“异质性”（技术、地理、产品的不同）？本篇手写三种面板随机前沿模型：Schmidt–Sickles 固定效应模型、Battese–Coelli（1992）时变衰减模型（面板似然的闭式解用数值积分核对）和 Greene 的“真实固定效应”模型。在两种数据生成过程下比较：无效率持续存在、企业间没有其他异质性时，前两种模型估计得很好，真实固定效应模型把持续的无效率当成了异质性；企业间存在与效率无关的异质性时，结论正好相反。模型的选择取决于对“不随时间变化的差异是什么”的判断，数据本身无法告诉我们。

  6. 05
    SFA 与 DEA 的比较，以及全要素生产率的分解

  2. 01
    路径分析——从回归方程组到协方差结构

    结构方程模型的核心思想是：一组假设的因果关系决定了变量之间的协方差应当是什么样子。本篇从最简单的路径模型讲起：用逐个方程的 OLS 和 semopy 估计同一个模型并对照结果，分解直接效应、间接效应和总效应，验证 Wright 的路径追踪规则；然后手写模型隐含的协方差矩阵和极大似然拟合函数，说明恰好识别的模型为什么总是“完美拟合”、过度识别的模型怎样用 χ² 检验，以及自由度是怎样计算的。

  3. 02
    中介分析——Baron–Kenny、bootstrap 与因果中介的假设

    希腊字母衡量期权价格对各个参数的敏感程度，是期权风险管理的基本工具。本篇推导 delta、gamma、vega、theta 和 rho 的公式并用有限差分核对，验证它们之间的 Black–Scholes 关系；然后模拟一个卖出看涨期权、用股票做 delta 对冲的做市商：对冲误差的标准差随调整频率按 1/√N 下降，平均盈亏接近 0 且与股票的期望收益无关；最后演示用错波动率的代价：实际波动率高于定价和对冲时用的波动率，做市商会系统性地亏损，亏损的大小接近两个波动率下期权价格的差。

  6. 05
    蒙特卡洛定价——方差缩减、奇异期权与美式期权

    蒙特卡洛方法用模拟的风险中性路径计算期权价格，几乎能处理任何收益结构。本篇先用对偶变量和控制变量把欧式期权的估计方差降低一个数量级；然后给亚式期权定价，以有解析解的几何平均亚式期权作为控制变量；给障碍期权定价，说明每日观察与连续观察的差别，并用 Broadie–Glasserman–Kou 修正把两者对上；最后实现 Longstaff–Schwartz 最小二乘方法，给美式看跌期权定价，与二叉树的结果对照。

  7. 06
    隐含波动率、波动率微笑与 Heston 模型

    把市场上的期权价格代入 Black–Scholes 公式反解出的波动率，称为隐含波动率；如果模型正确，所有行权价的隐含波动率应该相同，但实际上它们形成“微笑”或“偏斜”。本篇实现隐含波动率的求解，再用 Heston 随机波动率模型（特征函数定价，并用蒙特卡洛核对）生成价格，说明负的价量相关产生向下倾斜的偏斜、波动率的波动产生微笑；最后用期权价格计算无模型的隐含方差（VIX 的原理），并与 Heston 模型中方差的理论期望值对照。

  1. 00
    系列导读与学习路线

    一套写给做实证研究的人的机器学习入门，共 12 篇：从预测与推断的区别讲起，经过偏差–方差权衡、交叉验证与数据泄漏、岭回归与 Lasso、分类与评价指标、K 近邻与维数灾难，到决策树、随机森林、梯度提升和模型解释，最后用预测股票收益率的实战项目收尾。全部使用 scikit-learn 和随 Python 包安装的真实数据，所有结果都是实际运行的输出。本篇给出路线图、阅读建议和环境准备。

  2. 01
    预测与推断——两种不同的问题

    计量经济学关心系数 β̂ 是否准确，机器学习关心预测值 ŷ 是否准确，这是两种不同的问题。本篇介绍监督学习的基本框架：特征、目标、损失函数、训练集和测试集，用美国老年人的处方药支出数据建立第一个预测模型，并和“永远预测均值”的基准比较；然后用工资数据说明，往模型里加入相关的变量，教育的系数会大幅变化，预测精度却几乎不变——好的预测不等于有意义的系数；最后讨论什么样的问题适合用机器学习，什么样的问题需要因果推断。

  3. 02
    偏差–方差权衡与过拟合

    模型太简单，抓不住数据中的规律，叫欠拟合；模型太复杂，把噪声也当成了规律，叫过拟合。本篇用多项式回归的模拟展示两者：随着模型复杂度上升，训练误差一路下降，测试误差先降后升；把预测误差分解成偏差、方差和不可约误差三部分，用重复抽样直接算出每一部分；说明样本量越大，越能承受复杂的模型；最后在老年人处方药支出的真实数据上，用 K 近邻回归再现同样的 U 形曲线。

  4. 03
    交叉验证与模型选择

    用测试集挑选模型，测试集就不再是“没见过的数据”。本篇介绍训练集、验证集、测试集的三分法和 K 折交叉验证，用网格搜索为 K 近邻回归选择参数；然后讨论交叉验证中最危险的错误——数据泄漏：在 50 个样本、5000 个纯噪声特征的数据上，先用全部数据挑选特征再做交叉验证，准确率高达 96%，正确的做法只有 60% 左右（真实准确率是 50%）；最后说明时间序列为什么不能随机划分，用标普 500 的波动率预测展示随机 K 折交叉验证会把结果夸大多少。

  5. 04
    正则化——岭回归与 Lasso

    特征一多，最小二乘法就容易过拟合。正则化在最小化误差的同时惩罚系数的大小，用一点偏差换取方差的大幅下降。本篇用处方药支出数据构造 192 个特征，在小样本下比较普通最小二乘、岭回归和 Lasso：最小二乘严重过拟合，两种正则化都把测试误差大幅降低；画出系数随惩罚强度变化的路径，说明 Lasso 为什么能把系数压缩到恰好为零；用交叉验证选择惩罚强度；最后用自助法说明 Lasso 选出的变量很不稳定，它的系数也不能直接做因果解释。

  6. 05
    分类——逻辑回归与评价指标

    目标变量是类别时，问题就变成了分类。本篇用 1974 年的婚姻调查数据预测是否有婚外情：先说明为什么不用线性回归而用逻辑回归，然后系统地介绍分类模型的评价——准确率为什么会误导、混淆矩阵、查准率与查全率、阈值的选择、ROC 曲线与 AUC、预测概率的校准；最后用“预测处方药支出最高的 5% 的老人”说明类别不平衡时的特殊问题：一个什么都不做的模型就有 95% 的准确率。

  7. 06
    K 近邻与维数灾难

    K 近邻是最直观的机器学习方法：要预测一个新样本，就找训练集中和它最像的 K 个样本，看它们是什么。它几乎不做任何假设，却在高维数据中遇到了根本性的困难。本篇介绍 K 近邻分类与回归、距离与标准化、K 对决策边界的影响；然后用三个实验说明“维数灾难”：高维空间中，“附近”需要覆盖几乎整个范围，所有点之间的距离变得差不多，往数据里加入无关的特征会让 K 近邻的预测迅速变差，而线性回归几乎不受影响。

  8. 07
    决策树

    决策树用一连串“是或否”的问题把数据分成若干组，每组给出一个预测值。它不需要标准化，能自动处理非线性和交互作用，结果像一张流程图一样容易解释。本篇介绍回归树如何选择分裂点、树的深度如何控制复杂度，用处方药支出数据画出一棵三层的树，用交叉验证和代价复杂度剪枝选择树的大小；也展示决策树最大的弱点：换一个样本，树的结构可能完全不同，单棵树的预测精度通常也不如线性模型。

  9. 08
    Bagging 与随机森林

    单棵决策树方差很大，但把很多棵树的预测平均起来，方差就会大幅下降，这就是 Bagging。随机森林更进一步，每次分裂只在随机挑选的一部分特征中寻找最佳分割，让树与树之间更不相关，平均的效果更好。本篇解释平均为什么能降低方差、相关性为什么会限制这种效果，介绍袋外误差这一“免费”的验证方法，在处方药支出和婚外情数据上比较随机森林与线性模型；最后用一个纯噪声特征说明，随机森林默认的特征重要性有系统性偏差，置换重要性更可靠。

  10. 09
    梯度提升

    随机森林把很多棵独立的深树平均起来，梯度提升则反过来：一棵接一棵地种很小的树，每一棵新树都去拟合前面所有树留下的残差。本篇先用十几行代码亲手实现梯度提升，和 scikit-learn 的结果对照；然后讨论它的三个关键超参数——学习率、树的数量和树的深度，说明为什么学习率越小越好、树太多会过拟合、怎样用提前停止自动决定树的数量；最后在处方药支出和婚外情两份数据上，把本系列介绍过的所有模型放在一起比较。

  11. 10
    理解模型——重要性、部分依赖与因果的界限

    随机森林和梯度提升预测得好，却不像线性回归那样有系数可以读。本篇介绍理解这类模型的常用工具：置换重要性告诉我们哪些特征对预测有帮助，部分依赖图和个体条件期望图告诉我们预测怎样随某个特征变化。然后用两个实验说明这些工具的局限：两个高度相关的特征会互相“分走”重要性；一个对结果毫无作用的变量，只要和遗漏的混杂因素相关，在部分依赖图上就会显示出很强的“效应”。可解释性工具解释的是模型，不是世界。

  12. 11
    实战——预测股票收益率为什么这么难

    系列的最后一篇，用一个完整的项目把前面的内容串起来：用过去的价格信息预测标普 500 的收益率和波动率。按时间顺序滚动评价，以“历史平均收益”为基准，线性回归、岭回归、随机森林和梯度提升预测下一天收益率的样本外 R² 全部在 0 附近甚至为负；而预测未来一个月的波动率，同样的模型却能得到可观的样本外 R²。然后重现三种常见的数据泄漏，看它们能把一个毫无预测能力的模型包装得多么漂亮。最后给出一份机器学习项目的检查清单，并为整个系列做总结。

    写给做数据分析和实证研究的人的深度学习入门，共 8 篇：用 NumPy 手写神经网络和反向传播，PyTorch 的张量、自动求导与训练循环，学习率、优化器、初始化与正则化的对照实验，卷积神经网络，RNN 与 LSTM 以及与 AR 模型的预测比较，表格数据上神经网络与梯度提升的比较和可靠的模型比较方法，最后从头实现注意力机制和一个小 Transformer。所有实验都能在普通笔记本电脑的 CPU 上几分钟内跑完，结论如实报告，包括深度学习不占优的情形。本篇给出路线图和环境准备。

  2. 01
    从逻辑回归到神经网络——用 NumPy 手写前向和反向传播

    神经网络并不神秘：逻辑回归就是只有一个神经元的网络，加一层非线性的隐藏层，就能画出弯曲的决策边界。本篇只用 NumPy，先用梯度下降训练逻辑回归，再写一个两层的神经网络：推导矩阵形式的反向传播，用数值梯度核对解析梯度，在“两个月亮”数据上把测试准确率从 0.86 提高到 0.96；最后说明为什么没有非线性激活函数的多层网络仍然只是一个线性模型。

  3. 02
    PyTorch 基础——张量、自动求导与训练循环

    PyTorch 是目前研究中最常用的深度学习框架。本篇介绍它的三个核心概念：张量（与 NumPy 数组几乎一样，但能记录计算过程）、自动求导（把上一篇手写的反向传播交给框架，并验证两者的梯度完全一致），以及由模型、损失函数、优化器组成的标准训练循环；然后介绍小批量训练、训练与评估模式、模型的保存与加载，以及怎样让结果可以复现。

  4. 03
    训练神经网络——学习率、优化器、初始化与正则化

    神经网络能不能训练好，很大程度上取决于几个“工程”上的选择。本篇用手写数字数据做一组对照实验：学习率太小学不动、太大会发散；动量和 Adam 比普通的随机梯度下降收敛快得多；输入的尺度决定了合适的学习率，标准化时还要小心几乎不变的像素；所有参数初始化为 0 会让隐藏层的神经元永远一模一样；然后在小样本上故意制造过拟合，比较权重衰减、dropout 和早停三种正则化方法的效果。

  5. 04
    卷积神经网络——把图片的结构告诉模型

    多层感知机把图片展开成一串像素，丢掉了“相邻像素相关”这个最重要的信息。卷积神经网络用在整张图片上滑动的小滤波器提取局部特征，参数少得多。本篇手算一次卷积并与 PyTorch 对照，在手写数字数据上比较逻辑回归、多层感知机和一个小型卷积网络（各用 5 个随机数种子），卷积网络在各种样本量下都最好，但在 8×8 的小图片上领先的幅度有限；再把测试图片平移一个像素，说明卷积和池化带来的平移稳健性；最后看看网络学到的滤波器。

  6. 05
    序列模型——RNN、LSTM 与一次诚实的预测比较

    循环神经网络用一个随时间更新的隐藏状态处理序列数据，LSTM 用门控机制缓解了长序列上的梯度消失。本篇先手算 RNN 的递推并与 PyTorch 对照，再做两组预测比较：在 3000 期的门限自回归模拟数据上，LSTM 能学到 AR 模型学不到的非线性，预测误差接近理论下限；在美国 1959–2009 年约 200 个季度的通胀数据上，LSTM 的平均预测误差比 AR(4) 低约 3%，但随随机数种子波动，Diebold–Mariano 检验也不显著，多层感知机则不如 AR(4)。结论是：数据少、信号弱时，深度学习在时间序列预测上没有可靠的优势。

  7. 06
    表格数据——神经网络与梯度提升树，以及怎样可靠地比较两个模型

    经济学和管理学的数据大多是表格：每行一个观测、每列一个变量。在这类数据上，神经网络常常不如梯度提升树。本篇在三个数据集（糖尿病、乳腺癌和一个 Friedman 模拟数据）上用重复的 5 折交叉验证比较线性模型、梯度提升和多层感知机，三个数据集上多层感知机都不是最好的：两个小样本的真实数据上正则化的线性模型最好，即使在关系平滑、样本较多的模拟数据上，默认设置的神经网络也略逊于梯度提升；再说明只用一次随机划分比较模型有多不可靠，以及怎样用配对的方式比较并校正各折之间的相关。

  8. 07
    注意力机制与 Transformer——从头实现一个小模型

    Transformer 是大语言模型的基础结构，核心是注意力机制：序列中的每个位置根据“相关程度”从所有位置汇集信息。本篇手算缩放点积注意力并与 PyTorch 对照，然后从头搭一个两层的小 Transformer，训练它把一串数字倒过来；去掉位置编码以后，同一个模型每个位置的准确率只有 0.29，没有一条序列能全部做对，说明注意力本身不知道顺序；最后画出注意力权重，看模型怎样学会“看向对称的位置”，并简要说明大语言模型与这个小模型的关系。

    综述有哪几种——从叙述性综述到元分析

    元分析中最常被报告也最常被误读的指标是 I²。本篇用 BCG 数据计算 Q、I²（两种常用的定义）、H²、τ 和 τ² 的 Q-profile 置信区间，说明 I² 衡量的是“观测到的差异中有多大比例不是抽样误差”，而不是“效应差异有多大”：同样的真实异质性，研究的样本越大，I² 越高；研究少时 Q 检验几乎检测不到异质性。真正回答“效应在不同情境中差多少”的是 τ 和预测区间：BCG 的平均效应显著，但预测区间跨过了 1。最后介绍亚组分析的做法和陷阱。

    「优化建模」系列讲的是怎样把决策问题写成数学规划并求解；这个系列讲运筹学的另外三块常用内容，共 12 篇：效率与综合评价（DEA 的 CCR、BCC、SBM、非期望产出、超效率、Malmquist 指数与第二阶段回归；熵权法、TOPSIS、层次分析法、灰色关联及其局限），随机系统（库存模型、排队论、离散事件仿真），动态决策（动态规划、马尔可夫决策过程、最优停止与 Q 学习）。所有方法都用 Python 手写，并用独立的方法核对：对偶、几何作图、解析公式、仿真或暴力搜索。本篇给出路线图。

  2. 01
    数据包络分析（上）——CCR 与 BCC 模型

    数据包络分析（DEA）用线性规划从数据中构造“最佳实践前沿”，每个决策单元的效率是它离前沿有多远。本篇从“产出/投入的比值”出发推导 CCR 模型的乘数形式和包络形式，说明两者互为对偶；加上凸性约束得到 BCC 模型，由此分解出纯技术效率和规模效率；再用第二阶段的松弛变量区分“弱有效”和真正的有效，给出每个单元的改进目标。实现全部用 SciPy 的线性规划手写，并用两种独立的方法核对：对偶的两种形式结果相同；两投入的例子与几何作图求出的效率相同。最后在真实效率已知的模拟数据上看 DEA 的表现：排序很准，但效率值系统性偏高。

  3. 02
    数据包络分析（中）——SBM、非期望产出与超效率

    径向 DEA 只按比例压缩投入，算不进松弛变量；含污染等“坏产出”时也不知道怎么处理。本篇手写 Tone 的 SBM 模型（用 Charnes–Cooper 变换化成线性规划，并用直接求解分式规划的结果核对），扩展到含非期望产出的 SBM，以及给有效单元排序的超效率模型（径向的 Andersen–Petersen 和非径向的超效率 SBM）。在模拟的 30 个地区上比较：忽略污染时和计入污染时的效率排序差别很大；把污染当作投入是常见但有问题的做法。最后讨论这些模型在“绿色全要素生产率”研究中的用法和陷阱。

  4. 03
    数据包络分析（下）——Malmquist 指数与效率的第二阶段回归

    有了多年的数据，就可以用 DEA 测算全要素生产率的变化。本篇手写 Malmquist 生产率指数及其“技术效率变化 × 技术进步”分解（在一投入一产出时与生产率之比完全相等，作为核对），再用方向距离函数构造含非期望产出的 Malmquist–Luenberger 指数，展示相邻期前沿下线性规划无解的问题和全局 ML 指数的解决方法。在已知真实技术进步率的模拟面板上，指数能恢复真实参数。第二部分讨论“先算效率、再回归”的两阶段方法：用模拟说明直接对 DEA 效率做 OLS 或 Tobit 回归会低估影响因素的作用，并手写 Simar–Wilson 的截断回归加自助法。

  5. 04
    综合评价（上）——熵权法与 TOPSIS

    “数字经济发展指数”“高质量发展水平”这类综合指数，最常用的做法是熵权法定权重、TOPSIS 或加权求和合成。本篇手写这两种方法，并在“真实发展水平已知”的模拟数据上检验它们：熵权法给的权重取决于指标的偏态程度，而不是指标的信息量，一个几乎全是噪声但分布偏态的指标拿到了第二大的权重；同一总体的不同样本算出的权重差别很大；TOPSIS 存在“排序逆转”。在 200 次模拟中，熵权法并不比等权重好，TOPSIS 不如加权求和，主成分最好。最后给出构建综合指数的建议。

  6. 05
    综合评价（下）——层次分析法、灰色关联与敏感性分析

    层次分析法（AHP）用专家的两两比较确定权重。本篇手写特征向量法、几何平均法和一致性检验，用一致的判断矩阵核对三种算法都能恢复真实权重，再用模拟重新计算随机一致性指标 RI，与 Saaty 的表比较。灰色关联分析在国内论文中常用来判断“哪些因素与结果关系最密切”：模拟显示，两个完全独立的随机游走之间的灰色关联度也普遍在 0.6 以上，排序还随分辨系数和标准化方法改变，它不能替代相关分析或回归。最后用随机权重的蒙特卡洛模拟给综合评价做敏感性分析：每个单元的排名不是一个数，而是一个区间。

  7. 06
    库存（上）——EOQ 的扩展与数据驱动的报童模型

    优化建模系列已经推导过 EOQ 公式和报童模型的临界分位数。本篇接着往下走：EOQ 的成本曲线很平，订货量偏离 50% 成本只增加 8%；数量折扣和允许缺货的 EOQ 用公式求解并用暴力搜索、数值优化核对。报童模型部分讨论需求分布不知道时怎么办：样本平均近似（SAA）与拟合分布的比较；以及一个经常被忽略的问题：缺货时看到的是销量而不是需求，直接用销量估计需求会让订货量逐期下降（螺旋下降），用删失数据的最大似然可以纠正。

  8. 07
    库存（下）——订货策略、服务水平与牛鞭效应

    多期库存的核心问题是“什么时候订、订多少”。本篇写一个通用的周期盘点库存仿真器，用它检验三件事：安全库存的两种服务水平（周期服务水平和满足率）含义不同，80% 的周期服务水平已经对应 93% 的满足率；有固定订货成本时，按每期临界分位数定订货点的经验策略比最优 (s, S) 策略贵 18%，按每个订货周期权衡的经验策略只贵 5%；用移动平均预测加订货至目标水平，订单的方差被放大，放大倍数与 Chen 等（2000）的公式完全一致，这就是供应链中的牛鞭效应。

  9. 08
    排队论——Little 定律、M/M/c 与人员配置

    排队论回答“要多少服务台，顾客才不会等太久”。本篇先用一个通用的多服务台排队仿真（几行代码）逐一核对理论公式：Little 定律、M/M/1、M/G/1 的 Pollaczek–Khinchine 公式、M/M/c 的 Erlang C 公式，全部与仿真一致。然后讨论排队系统的三个反直觉之处：利用率接近 100% 时等待时间急剧上升；服务时间的波动和平均值一样重要（Kingman 公式）；把分开的队伍合并成一队能大幅减少等待。最后用 Erlang C 给呼叫中心排班，并说明平方根配置规则下，系统越大越有规模经济。

  10. 09
    离散事件仿真——从头写一个仿真引擎

    排队公式只适用于简单系统。有优先级、顾客会放弃、到达率随时间变化时，就要用仿真。本篇用不到 50 行 Python 写一个事件驱动的仿真引擎，先配置成 M/M/c 与 Erlang C 公式核对，再模拟一家上午开诊的门诊：急诊优先、普通病人等太久会离开、到达在 9 点达到高峰。然后讲仿真结果的统计分析：一次运行的结果不能当真，要独立重复并给出置信区间；比较两个方案时用共同随机数，同样的计算量下置信区间窄了很多。

  11. 10
    动态规划——贝尔曼方程与逆向归纳

    动态规划把一个多阶段的决策问题拆成一串单阶段的问题，从最后一期往前逐期求解。本篇从最优性原理出发，用四个例子讲清楚“状态、决策、转移、价值函数”怎样定义：多阶段最短路、0-1 背包、设备更新、消费储蓄（吃蛋糕）问题。每个例子都和独立的方法核对：最短路和背包与穷举、整数规划的结果相同，消费储蓄问题与解析解相同。最后讨论“维数灾难”和动态规划与经济学中动态模型的关系。

  12. 11
    马尔可夫决策过程——值迭代、策略迭代与线性规划

    转移是随机的、时间是无限的序贯决策问题，叫马尔可夫决策过程（MDP）。本篇手写三种求解方法：值迭代、策略迭代和线性规划，在一个有固定订货成本的库存问题上核对三者给出相同的价值函数和策略，并比较收敛速度：值迭代要几百次迭代，策略迭代只要几次。然后验证最优策略确实是 (s, S) 形式（Scarf 定理），并看参数变化时 s 和 S 怎样移动。线性规划的对偶变量还有一个直观的含义：各个状态、各个决策被访问的折现频率。

  13. 12
    最优停止——秘书问题、工作搜寻与 Q 学习

    “继续等还是现在接受”是一类常见的决策：招聘、找工作、卖房、行权。本篇先用动态规划精确求解秘书问题，与解析公式和模拟三方核对，得到著名的 1/e 法则；再求解经济学中的 McCall 工作搜寻模型，算出保留工资，看失业救济和耐心怎样影响保留工资和失业时长（用模拟核对平均失业时长等于 1/接受概率）。最后假设求职者不知道工资分布，用 Q 学习从经验中学习：经常遇到的工资水平上，学到的策略与最优策略完全一致，很少遇到的工资水平上则仍有一成左右的决策是错的，这也是强化学习的一般局限。

    选题决定了一篇论文的上限。本篇讨论好的实证选题要同时满足的四个条件（问题重要、能够识别、做得出来、有新贡献），选题的七个常见来源（政策与制度变化、新数据、文献中的争论、令人困惑的现象、理论预测、方法进步、复现与扩展），用 Angrist 和 Pischke 的四个问题和“一页纸研究设计”在动手之前检验一个想法，并用一个虚构的例子演示从模糊的兴趣到可执行的研究设计的过程。最后列出选题中最常见的十个陷阱，以及怎样管理自己的想法库。

  3. 怎样写实证论文的引言和回复审稿意见

    编辑和审稿人往往读完引言就形成了对一篇论文的判断，而一篇论文能否发表，又常常取决于修改阶段的回复信写得好不好。本篇介绍实证论文引言的常用结构（Head 的“引言公式”：吸引注意、研究问题、已有研究、本文的贡献、结构安排），用一个虚构研究的引言逐段示范，列出引言中最常见的毛病；然后介绍回复审稿意见的原则和格式：致编辑的信、逐条回复、同意与不同意时分别怎样写、多位审稿人意见冲突时怎样处理，并给出正反两种回复的对照。

  4. LaTeX 论文排版入门：公式、表格、图和参考文献

    经济学和管理学的英文期刊、越来越多的中文期刊和学位论文都接受或要求 LaTeX 排版。本篇用一个可以直接编译的完整示例（可下载），讲清楚写一篇实证论文需要的 LaTeX：用 XeLaTeX 和 ctex 处理中文，文档结构，编号公式与多行公式，booktabs 三线表与表注、按小数点对齐，并排的子图，用 cleveref 做交叉引用，用 biblatex 管理参考文献（作者–年份格式和国标 GB/T 7714 格式），以及怎样与 Python 自动生成的表格衔接、怎样排查常见的编译错误。

    不讲具体型号，只讲不会过时的原理：一台电脑由哪些部件组成，CPU、内存、硬盘、显卡各自负责什么，核心数、频率、内存容量、固态硬盘这些参数分别影响什么；用一个“厨房”的比喻和存储层次的速度量级图说明为什么数据放在哪里决定了程序有多快；再从做数据分析的角度说明内存不够、硬盘太慢、核心闲置时会出现什么症状，怎样用几行 Python 查看自己电脑的配置，以及按用途而不是按型号选电脑。

Python

  1. 论文里的图怎样画才好：坐标轴、颜色、不确定性与导出

    一张好图让读者三秒钟看懂结论，一张坏图则会误导读者或者被审稿人质疑。本篇用五组“坏图与好图”的对比，讲论文作图最重要的原则：柱状图的纵轴必须从 0 开始，双纵轴可以制造任何想要的“相关”，大样本的散点图要用分箱散点图，系数要画置信区间并说明是哪种区间，颜色要考虑色盲和黑白打印、能直接标注就不用图例；最后说明中文字体、矢量格式、字号与图注的要求，并附一份作图检查清单。所有的图都由文中的代码生成。

  2. Python 环境怎么装：python.org、conda、venv 与 uv 怎么选

    学 Python 的第一道坎往往不是语法，而是环境：装了库却提示找不到、两个项目要求不同版本、教程里的命令在自己电脑上报错。本篇先讲清楚解释器、包、包管理器和虚拟环境四个概念；再分别介绍官方安装包加 venv、conda（Anaconda/Miniforge）、uv 三种方案和怎样选择；然后说明怎样在 VS Code 和 JupyterLab 中使用虚拟环境、打开本站文章附带的 Jupyter 笔记本；最后整理最常见的报错（ModuleNotFoundError、找不到 python 命令、下载太慢、笔记本里装错了环境）和解决办法。
