pandas 入门：表格数据与金融时间序列

pandas 是 Python 中做数据分析最常用的第三方库。如果说 NumPy 擅长的是“一堆数字”的计算，那么 pandas 擅长的就是“一张表”的处理：每一列有名字，每一行有索引（比如日期），可以按条件筛选、分组汇总、合并不同的表，还可以很方便地处理时间序列。

金融数据几乎天然就是表格的形式：每天一行，每只股票一列；或者每笔交易一行，记录时间、代码、价格、数量。pandas 的作者 Wes McKinney 最初就是在一家对冲基金工作时开发了它，所以它对金融数据的支持特别好，比如按交易日对齐、计算收益率、月度汇总、移动平均，这些都只需要一两行代码。

pandas 里最重要的是两个数据结构：

  • Series：一列带索引的数据，可以理解为“带标签的一维数组”；
  • DataFrame：一张表，由多列 Series 组成，每列可以是不同的类型。

pandas 建立在 NumPy 之上，DataFrame 的每一列本质上就是一个 NumPy 数组，所以 NumPy 的很多操作在 pandas 里同样适用。读这篇之前，最好先读 NumPy 入门。

一、安装与导入

pip install pandas
import numpy as np
import pandas as pd    #导入pandas模块，习惯上命名为pd

print(pd.__version__)    #查看pandas版本信息
3.1.1

和 NumPy 一样，pandas 也几乎总是简写为 pd。不同版本之间有一些细微差别，本文的代码在 pandas 2.x 和 3.x 上都可以运行。

二、创建 Series 与 DataFrame

Series

price = pd.Series([10.5, 10.8, 10.6, 11.2], index=["周一", "周二", "周三", "周四"], name="收盘价")
print(price)
print("周三的收盘价：", price["周三"])
周一    10.5
周二    10.8
周三    10.6
周四    11.2
Name: 收盘价, dtype: float64
周三的收盘价： 10.6

和 NumPy 数组相比，Series 多了一个索引（左边那一列），可以用标签而不只是位置来取数据。

DataFrame

最常用的方法是用字典创建，字典的键就是列名：

stocks = pd.DataFrame({
    "代码": ["600519", "000001", "601318", "000858"],
    "名称": ["贵州茅台", "平安银行", "中国平安", "五粮液"],
    "行业": ["白酒", "银行", "保险", "白酒"],
    "市盈率": [28.5, 4.6, 8.9, 18.2],
})
print(stocks)
       代码    名称  行业   市盈率
0  600519  贵州茅台  白酒  28.5
1  000001  平安银行  银行   4.6
2  601318  中国平安  保险   8.9
3  000858   五粮液  白酒  18.2

（这里的市盈率只是随手编的示意数字，不代表真实数据。）

没有指定索引时，pandas 自动用 0、1、2…… 作为行索引。

带日期索引的 DataFrame

金融数据最常见的形式是“日期 × 资产”的价格表。为了让代码在任何电脑上都能运行，这里用 NumPy 的随机数模拟三只股票 2023 年的日收盘价（随机数的用法见 NumPy 入门第十一节）：

rng = np.random.default_rng(2119)    #固定随机种子，保证每次结果相同
dates = pd.bdate_range("2023-01-02", "2023-12-29")    #2023年的工作日
mu = [0.0006, 0.0002, 0.0009]    #三只股票的日均收益率
sigma = [0.018, 0.011, 0.026]    #三只股票的日波动率
daily_ret = rng.normal(mu, sigma, size=(len(dates), 3))

prices = pd.DataFrame(100 * np.exp(daily_ret.cumsum(axis=0)),    #从100元开始累积
                      index=dates, columns=["股票A", "股票B", "股票C"]).round(2)
prices.index.name = "日期"
print(prices.head())
               股票A     股票B     股票C
日期
2023-01-02   97.13  101.13  102.12
2023-01-03   98.63  102.01  102.77
2023-01-04  100.95  100.97  105.07
2023-01-05  103.79  103.13   99.25
2023-01-06  104.12  102.34   99.32

pd.bdate_range 生成工作日（business day）序列，正好对应股票的交易日（真实的交易日还要去掉节假日）。

三、读取与保存数据

实际工作中，数据一般来自文件。pandas 可以读写几乎所有常见的格式：

pd.read_csv("文件名.csv")    #读取CSV文件
pd.read_excel("文件名.xlsx")    #读取Excel文件（需要安装openpyxl）
df.to_csv("文件名.csv")    #保存为CSV文件
df.to_excel("文件名.xlsx")    #保存为Excel文件

把上面的价格表存成 CSV，再读回来：

prices.to_csv("prices.csv", encoding="utf-8-sig")    #utf-8-sig让Excel打开时中文不乱码
df = pd.read_csv("prices.csv", index_col="日期", parse_dates=True)
print(df.index[:3])
DatetimeIndex(['2023-01-02', '2023-01-03', '2023-01-04'],
              dtype='datetime64[us]', name='日期', freq=None)

两个参数很重要：index_col 指定哪一列作为索引，parse_dates=True 把日期从文本转成真正的日期类型。不加的话，日期只是一串字符，后面按月汇总、按日期切片都用不了。

另外，用 Excel 打开 pandas 保存的中文 CSV 经常是乱码，保存时加上 encoding="utf-8-sig" 即可。

五、索引、切片与筛选

pandas 取数据的方法比较多，一开始容易混。常用的是这几种：

df["列名"]    #取一列，得到Series
df[["列1", "列2"]]    #取多列，得到DataFrame
df.loc[行标签, 列标签]    #按标签取
df.iloc[行位置, 列位置]    #按位置取（从0开始）
df[条件]    #按条件筛选行

loc 用的是标签（名字、日期），iloc 用的是位置（第几行、第几列），这是最容易搞混的地方。

print(df.loc["2023-06-01":"2023-06-05", ["股票A", "股票C"]])    #日期切片，两端都包含
print(df.iloc[-1])    #最后一行，即年末的价格
               股票A     股票C

股票B    107.12
股票C    155.28
Name: 2023-12-29 00:00:00, dtype: float64

有了日期索引，可以直接用 "2023-06" 这样的字符串取出 6 月份的所有数据，或者用 "2023-06-01":"2023-06-05" 取一段时间。注意用标签切片时两端都包含，这和 Python 列表的切片不一样。

print(df[df["股票C"] > 155])

六、新增列、排序与缺失值

新增列

列与列之间的计算和 NumPy 数组一样，是逐元素进行的：

stocks["每股收益"] = (50 / stocks["市盈率"]).round(2)    #假设股价都是50元
stocks["估值"] = np.where(stocks["市盈率"] > 15, "偏高", "偏低")

排序

df.sort_values("列名", ascending=False)    #按某一列降序排序
df.sort_index()    #按索引排序
print(stocks.sort_values("市盈率")[["名称", "市盈率"]])

缺失值

真实数据中经常有缺失值，比如停牌的日子没有价格。pandas 用 NaN 表示缺失值：

df.isna()    #判断每个值是否缺失
df.isna().sum()    #每一列缺失值的个数
df.dropna()    #删除有缺失值的行
df.fillna(值)    #用指定的值填充
df.ffill()    #用前一个值填充（前向填充）
halted = df["股票A"].copy()
halted["2023-03-06":"2023-03-08"] = np.nan    #假设股票A停牌了三天
print("缺失值个数：", halted.isna().sum())
print(halted.ffill()["2023-03-03":"2023-03-09"])
缺失值个数： 3
日期
2023-03-03    110.62
2023-03-06    110.62
2023-03-07    110.62
2023-03-08    110.62
2023-03-09    114.77
Name: 股票A, dtype: float64

对股价来说，停牌期间用停牌前的最后一个价格填充（前向填充 ffill）是最常见的做法，因为停牌时价格确实没有变化。但不是所有数据都适合这样填，比如成交量停牌期间应该是 0，而不是前一天的数。

七、分组与合并

分组汇总

groupby 是 pandas 最强大的功能之一：按某一列分组，然后对每一组计算统计量。

print(stocks.groupby("行业")["市盈率"].agg(["count", "mean", "max"]))
    count   mean   max
行业                    
保险      1   8.90   8.9
白酒      2  23.35  28.5
银行      1   4.60   4.6

合并表格

两张表有共同的列时，可以用 merge 合并，类似 Excel 里的 VLOOKUP：

holdings = pd.DataFrame({"代码": ["600519", "601318", "000651"], "持仓股数": [100, 500, 300]})
merged = holdings.merge(stocks[["代码", "名称", "行业"]], on="代码", how="left")
print(merged)
       代码  持仓股数    名称   行业
0  600519   100  贵州茅台   白酒
1  601318   500  中国平安   保险
2  000651   300   NaN  NaN

how="left" 表示保留左边表（持仓表）的所有行。000651 在股票信息表里找不到，名称和行业就是缺失值。合并之后一定要检查有没有这种没匹配上的情况。

另外，pd.concat([df1, df2]) 可以把两张表上下拼起来，适合把多个月份的数据文件合成一张表。

八、时间序列

这部分是 pandas 在金融领域最常用的功能。

收益率：shift 与 pct_change

ret = df.pct_change()    #日收益率 =（今天价格 / 昨天价格）- 1
ret2 = df / df.shift(1) - 1    #和上面完全一样，shift(1)把数据整体往后挪一天
print(ret.head(3).round(4))
print("两种方法相同：", np.allclose(ret.dropna(), ret2.dropna()))
               股票A     股票B     股票C
日期
2023-01-02     NaN     NaN     NaN
2023-01-03  0.0154  0.0087  0.0064
2023-01-04  0.0235 -0.0102  0.0224
两种方法相同： True

第一天没有“昨天”，所以收益率是缺失值。

重采样：从日数据到月数据

monthly_price = df.resample("ME").last()    #每个月最后一个交易日的价格
monthly_ret = monthly_price.pct_change()
print(monthly_ret.head(4).round(4))
               股票A     股票B     股票C
日期
2023-01-31     NaN     NaN     NaN
2023-02-28  0.0469  0.0420 -0.0402
2023-03-31  0.1299 -0.1223  0.1099
2023-04-30 -0.1160  0.1319  0.2175

resample("ME") 表示按月（month end）分组，.last() 取每组的最后一个值。换成 "W" 就是按周，"QE" 是按季度，"YE" 是按年。（pandas 2.2 以前的版本写作 "M"、"Q"、"Y"。）

滚动窗口：移动平均

ma = pd.DataFrame({
    "收盘价": df["股票A"],
    "MA20": df["股票A"].rolling(20).mean(),    #20日均线
    "MA60": df["股票A"].rolling(60).mean(),    #60日均线
})
print(ma.tail(3).round(2))
               收盘价    MA20    MA60
日期
2023-12-27  118.65  117.33  120.33
2023-12-28  113.89  117.05  120.19
2023-12-29  113.44  116.83  120.04

rolling(20) 表示一个长度为 20 的滑动窗口，.mean() 对每个窗口求均值，这就是股票软件里的“20 日均线”。前 19 天的窗口不满 20 天，结果是缺失值。

最后用上面的价格数据，计算几个最常用的收益与风险指标。

九、收益与风险：年化收益率、波动率与夏普比率

ret = df.pct_change().dropna()
summary = pd.DataFrame({
    "全年收益率": df.iloc[-1] / df.iloc[0] - 1,
    "年化波动率": ret.std() * np.sqrt(252),    #一年约252个交易日
})
summary["夏普比率"] = (ret.mean() * 252 - 0.02) / summary["年化波动率"]    #假设无风险利率2%
print(summary.round(3))
     全年收益率  年化波动率   夏普比率
股票A  0.168  0.286  0.601
股票B  0.059  0.183  0.288
股票C  0.521  0.405  1.161
  • 年化波动率：日收益率的标准差乘以 ，衡量价格波动的剧烈程度；
  • 夏普比率：每承担一单位风险，获得多少超额收益（超过无风险利率的部分）。夏普比率越高，收益相对于风险越划算。

股票 C 全年涨了 52%，波动也最大，但夏普比率仍然最高；股票 B 波动最小，但全年只涨了 6%，扣除无风险利率后的超额收益很少，夏普比率最低。

十、最大回撤

最大回撤是指从某个最高点跌到之后最低点的最大跌幅，也就是“最倒霉的时候买入，最多会亏多少”：

running_max = df.cummax()    #截至每一天的历史最高价
drawdown = df / running_max - 1    #当天相对于历史最高价跌了多少
print("最大回撤：")
print(drawdown.min().round(3))
print("\n股票C最大回撤发生在：", drawdown["股票C"].idxmin().date())
最大回撤：
股票A   -0.188
股票B   -0.170
股票C   -0.267
dtype: float64

股票C最大回撤发生在： 2023-02-22

cummax() 是“累计最大值”，idxmin() 返回最小值所在的索引（日期）。几行代码就能算出基金评价中最常用的风险指标之一。

十一、相关系数

print(ret.corr().round(3))
       股票A    股票B    股票C
股票A  1.000 -0.054 -0.025
股票B -0.054  1.000 -0.004
股票C -0.025 -0.004  1.000

因为三只股票是独立模拟的，相关系数都接近 0。真实的股票之间通常是正相关的（同一个市场涨跌），相关系数一般在 0.3 到 0.7 之间。相关性越低，组合起来分散风险的效果越好。

小结

主题 要点
数据结构 Series 是带索引的一列，DataFrame 是由多列组成的表
读写 read_csv 时用 index_col 和 parse_dates；中文 CSV 用 encoding="utf-8-sig" 保存
取数据 loc 按标签、iloc 按位置；条件筛选用 &、|，每个条件加括号
缺失值 isna、dropna、fillna；停牌价格用 ffill 前向填充
分组与合并 groupby().agg() 分组汇总；merge 合并后检查没有匹配上的行
时间序列 pct_change 算收益率；resample 转换频率；rolling 算移动平均
风险指标 年化波动率乘以 ；最大回撤用 cummax 计算

把结果画成图，见 Matplotlib 入门；统计检验、最优化等进一步的计算，见 SciPy 入门。想系统学习用 pandas 清洗数据，可以读「实证研究工作流」第 03 篇。
