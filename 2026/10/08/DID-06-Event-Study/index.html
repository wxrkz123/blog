DID 从入门到精通（06）：事件研究法与平行趋势检验

DID DID进阶
Econometrics
发布日期:   2026-10-08

上一篇的 TWFE 只给出一个数字 ，它回答了“政策平均有多大效果”，但留下了两个问题：

本文是「DID 从入门到精通」系列第 06 篇，完整路线见 系列导读。

  1. 政策效果是怎么随时间演变的？ 是立竿见影，还是逐年增强？是持续存在，还是几年后消失？
  2. 平行趋势可信吗？ 政策实施之前，两组的趋势是不是真的平行？

事件研究法（event study）同时回答这两个问题。它可能是 DID 论文中最重要的一张图，几乎所有审稿人都会要求看。

一、模型

把 TWFE 中的 替换为一组“相对时间”虚拟变量：

  • 是政策实施年份（本例中为 2015）， 是 相对时间（event time）；
  • 是政策前， 是政策后；
  • 表示“处理组在相对时间 时”为 1；
  • **省略 **，即把政策前一年作为基期。

系数怎么解读？

衡量的是：在相对时间 ，处理组与对照组之间的差距，相比于基期（）时的差距，变化了多少。

用均值写出来就更清楚了（单一处理时点、平衡面板、无控制变量时完全成立）：

所以 每一个 都是一个以 为基期的 2×2 DID。事件研究就是把这些 2×2 DID 并排画出来。

  • 的 ：政策实施后第 年的处理效应（动态效应）；
  • 的 ：政策实施前，两组差距相对基期的变化。如果平行趋势成立且没有预期效应，这些系数应该在 0 附近（前期趋势检验 / pre-trend test）。

为什么要省略一期？

因为存在完全共线：所有相对时间虚拟变量之和等于 ，而 已经被个体固定效应吸收了。必须省略至少一期作为参照。

选 是最常见的做法，理由是：它离政策最近，其他因素最少；用它做基期，政策后的系数可以直接解读为“与政策实施前夕相比”。

如果担心存在 预期效应（政策公布在实施之前），比如政策在 2014 年宣布、2015 年实施，那么 已经可能受到影响，此时应该选择 或更早作为基期。

二、数据：逐年增强的政策效应

继续使用第 05 篇的 make_panel 函数，但让政策效应随时间增强：实施当年效应为 1，之后每年增加 0.5，到第 4 年达到 3。政策后 5 年的平均效应仍然是 2。

import numpy as np
import pandas as pd
import pyfixest as pf
# make_panel 函数的定义见第 05 篇

dyn = lambda k: np.where(k >= 0, 1 + 0.5 * k, 0.0)    # 真实的动态效应
df = make_panel(seed=5, effect=dyn)

# 构造相对时间：处理组为 year - 2015；对照组随便给一个值，放进基期即可
df["rel"] = np.where(df.treat == 1, df.year - 2015, -1)

对照组的 rel 取什么值并不重要，只要它落在被省略的基期里——因为对照组的所有虚拟变量都应该是 0。这里统一设为 −1。

四、解读

  • 前期系数（ 到 ）：都在 0 附近，最大的绝对值只有 0.29，且都不显著。没有证据表明政策前两组存在趋势差异。
  • 后期系数（ 到 ）：从 0.81 逐年增加到 2.86，与真实的 1、1.5、2、2.5、3 很接近，清楚地展示了政策效应逐年增强的动态模式。

对比上一篇的静态 TWFE：它只会告诉我们“平均效应约为 2”，而事件研究揭示了效应是 逐渐累积 的——这对政策评估意义重大：如果只看实施后一两年的数据，会严重低估长期效果。

五、前期系数的联合检验

逐个看前期系数是否显著是不够的：4 个系数分别在 5% 水平检验，即使平行趋势完全成立，至少有一个显著的概率也接近 。正确的做法是 联合检验 所有前期系数是否同时为 0：

用 Wald 检验：，除以约束个数 得到 F 统计量。聚类标准误下，分母自由度取 ：

from scipy import stats

names = list(es.coef().index)
pre = [names.index(f"rel::{k}") for k in (-5, -4, -3, -2)]
b = es.coef().values[pre]
V = es._vcov[np.ix_(pre, pre)]           # 前期系数的聚类方差-协方差矩阵
q, G = len(pre), df.prov.nunique()
F = b @ np.linalg.solve(V, b) / q
p = 1 - stats.f.cdf(F, q, G - 1)
print(f"F({q}, {G-1}) = {F:.3f}, p = {p:.3f}")
F(4, 29) = 0.480, p = 0.750

p 值为 0.75，无法拒绝“政策前趋势平行”的原假设。

六、画事件研究图

import matplotlib.pyplot as plt

def plot_event_study(fit, title, truth=None, fname=None):
    t = fit.tidy().copy()
    t["k"] = [int(s.split("::")[1]) for s in t.index]
    base = pd.DataFrame({"Estimate": [0.0], "2.5%": [0.0], "97.5%": [0.0], "k": [-1]})
    t = pd.concat([t, base]).sort_values("k")           # 把基期（系数为 0）补回去

    fig, ax = plt.subplots(figsize=(7, 4))
    ax.axhline(0, color="#52514e", lw=1)
    ax.axvline(-0.5, color="#52514e", lw=1, ls=":")     # 政策实施的分界线
    ax.vlines(t.k, t["2.5%"], t["97.5%"], color="#2a78d6", lw=2)
    ax.plot(t.k, t.Estimate, "o", color="#2a78d6", ms=7, label="估计系数与 95% 置信区间")
    if truth is not None:
        for kk, lab in [(np.arange(-5, 0), "真实效应"), (np.arange(0, 5), None)]:
            ax.plot(kk, truth(kk), "--", color="#eb6834", lw=2, label=lab)
    ax.set_xlabel("相对政策实施的年份（-1 为基期）")
    ax.set_ylabel("处理效应")
    ax.set_xticks(range(t.k.min(), t.k.max() + 1))
    ax.set_title(title, loc="left")
    ax.legend(loc="upper left", frameon=False)
    if fname:
        fig.savefig(fname, dpi=150, bbox_inches="tight")
    return fig

plot_event_study(es, "事件研究图：动态处理效应", truth=dyn)

一张规范的事件研究图应该包括：

  • 横轴为相对时间，纵轴为系数；
  • 每个系数的点估计和置信区间（通常 95%）；
  • 基期（系数为 0）明确标出；
  • 一条水平线表示 0，一条竖线标出政策实施时点；
  • 图注说明基期、标准误聚类层级、控制了哪些固定效应。

如果中文显示为方框，需要设置中文字体，例如 plt.rcParams["font.sans-serif"] = ["SimHei"]（Windows）或 ["Noto Sans CJK SC"]（Linux），并设置 plt.rcParams["axes.unicode_minus"] = False。

七、平行趋势被违背时，事件研究图长什么样？

现在制造一个违背平行趋势的场景：处理组在没有政策时，每年比对照组多增长 0.4。其他设定不变。

bad = make_panel(seed=5, effect=dyn, pretrend=0.4)
bad["rel"] = np.where(bad.treat == 1, bad.year - 2015, -1)
es_bad = pf.feols("y ~ i(rel, ref=-1) | firm + year", data=bad, vcov={"CRV1": "prov"})
print(es_bad.tidy()[["Estimate", "Std. Error", "Pr(>|t|)"]].round(3))
plot_event_study(es_bad, "平行趋势被违背时的事件研究图")

如果此时只跑静态 TWFE，会得到什么？

print("平行趋势成立:", round(pf.feols("y ~ D | firm + year", data=df).coef()["D"], 3))
print("平行趋势违背:", round(pf.feols("y ~ D | firm + year", data=bad).coef()["D"], 3))
平行趋势成立: 2.036
平行趋势违背: 4.036

真实平均效应是 2，违背平行趋势时静态 DID 给出 4.04，高估了一倍，而且仅看这一个数字完全发现不了问题。这就是为什么事件研究图如此重要。

八、常见的错误与注意事项

1. 只看单个系数的显著性。 应做联合检验，或者至少观察前期系数的整体模式（有没有系统性的趋势）。

2. 把“前期系数不显著”当作平行趋势成立的证明。 不显著可能只是因为 检验功效太低（样本小、标准误大）。前期系数虽然不显著，但如果点估计呈现明显的趋势，仍然值得警惕。第 11 篇会详细讨论这个问题，并介绍更好的做法——HonestDiD 敏感性分析。

3. 随意选择基期。 换一个基期，所有系数都会平移。应事先确定基期（一般为 ），如果有预期效应则提前，不要为了让图“好看”而挑选基期。

4. 对照组的相对时间编码错误。 对照组的所有事件虚拟变量必须为 0。如果把对照组的 rel 编码成某个非基期的值，会导致严重错误。

5. 逐点置信区间 vs 一致置信带。 图上每个点的 95% 置信区间是 逐点 的。如果要说“整条曲线”落在某个范围内，需要更宽的 一致置信带（sup-t band，见 Montiel Olea 和 Plagborg-Møller，2019）。

6. 交错 DID 中的事件研究。 当不同个体在不同时间接受处理时，上面的 TWFE 事件研究 可能给出误导性的结果，甚至在平行趋势成立时也会出现虚假的前期趋势。这是第 09、10 篇的主题。

Stata 代码对照

xtset firm year

* 生成相对时间虚拟变量
gen rel = year - 2015 if treat == 1
forvalues k = 5(-1)2 {
    gen pre`k' = (rel == -`k')
}
forvalues k = 0/4 {
    gen post`k' = (rel == `k')
}
* 省略 rel == -1 作为基期；对照组所有虚拟变量为 0

reghdfe y pre5 pre4 pre3 pre2 post0-post4, absorb(firm year) vce(cluster prov)

* 前期系数联合检验
test pre5 pre4 pre3 pre2

* 画图
coefplot, keep(pre* post*) vertical yline(0) xline(4.5) ///
    order(pre5 pre4 pre3 pre2 post0 post1 post2 post3 post4) ///
    ciopts(recast(rcap)) xtitle("相对政策实施年份") ytitle("处理效应")

也可以用因子变量语法一步生成。Stata 的因子变量不允许取负数，需要先把相对时间平移（这里加 6，使 对应 5）：

gen rel_c = cond(treat == 1, year - 2015, -1)
gen rel_s = rel_c + 6
reghdfe y ib5.rel_s, absorb(firm year) vce(cluster prov)

小结

  • 事件研究把 DID 拆成逐期系数，每个 都是一个以 为基期的 2×2 DID。
  • 政策后的系数刻画 动态效应，政策前的系数用于 检验前期趋势。
  • 前期系数应做 联合检验；不显著不等于平行趋势成立。
  • 平行趋势被违背时，事件研究图通常表现为前期系数的系统性趋势，静态 DID 会产生严重偏误。

练习

  1. 把基期改为 重新估计并画图，说明所有系数如何整体平移，以及为什么点估计的“形状”不变。
  2. 修改 make_panel，让处理组在政策前一年就出现 0.5 的预期效应。以 为基期时事件研究图会是什么样？应该如何调整基期？
  3. 用蒙特卡洛模拟估计：在平行趋势成立时，逐个检验 4 个前期系数、“至少有一个显著”的概率是多少？与联合 F 检验的拒绝率比较。
  4. 实现 sup-t 一致置信带（提示：从系数的联合正态分布中模拟最大绝对 t 统计量的分位数），并画在事件研究图上与逐点置信区间对比。
