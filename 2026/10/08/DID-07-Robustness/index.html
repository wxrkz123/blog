DID 从入门到精通（07）：稳健性检验工具箱——安慰剂、PSM-DID 与三重差分

DID 计量经济学 因果推断 Python Stata
Econometrics
发布日期:   2026-10-08

做完基准回归和事件研究后，审稿人通常会问：“你的结果会不会是巧合？会不会是其他因素导致的？”稳健性检验就是用来回答这些问题的。这一篇介绍四种最常用的方法。重要的是理解 每种检验到底在排除哪一种担忧——稳健性检验不是越多越好，而是要有针对性。

检验 排除的担忧
时间安慰剂 政策前就存在的趋势差异被误认为政策效应
随机化安慰剂 结果只是偶然出现的；标准误设定有误
PSM-DID 处理组与对照组在可观测特征上差异过大，导致趋势不同
三重差分 DDD 处理组同期受到了其他冲击

本篇的前两个检验使用第 05 篇的数据（make_panel()，真实效应为 2，基准估计为 1.847，标准误 0.148）。

一、时间安慰剂检验

思路：假装政策提前几年实施。如果在政策真正实施之前就“检测到”了效应，说明两组在政策前就存在趋势差异，基准结果可能是这种趋势造成的。

做法：只保留政策实施 之前 的数据（避免真实效应的干扰），把政策时间人为设定为更早的某一年，重新做 DID。

import numpy as np
import pandas as pd
import pyfixest as pf
# make_panel 函数的定义见第 05 篇

df = make_panel()
pre = df[df.year < 2015].copy()                       # 只用 2010—2014 年的数据
pre["fakeD"] = pre.treat * (pre.year >= 2013)         # 假装 2013 年实施
fk = pf.feols("y ~ fakeD | firm + year", data=pre, vcov={"CRV1": "prov"})
print(fk.tidy().round(3))
             Estimate  Std. Error  t value  Pr(>|t|)   2.5%  97.5%
Coefficient
fakeD          -0.106       0.215   -0.495     0.624 -0.546  0.333

伪政策的系数为 −0.106，远不显著，没有证据表明政策前存在趋势差异。

注意：时间安慰剂和上一篇事件研究的前期系数检验本质上是同一件事，事件研究提供的信息更丰富。如果已经做了事件研究，时间安慰剂可以作为补充。一定要剔除政策后的数据，否则真实效应会“泄漏”到伪处理变量中。

二、随机化安慰剂检验（置换检验）

思路：如果政策真的有效，那么 随机挑选 一批省份作为“伪处理组”，得到的 DID 系数应该集中在 0 附近，而真实的估计值应该落在这个分布的尾部。

做法：

  1. 从 30 个省中随机抽取 12 个作为伪处理组（与真实处理组数量相同）；
  2. 用伪处理组做 DID，记录系数；
  3. 重复 500 次，得到伪系数的分布；
  4. 看真实系数在这个分布中的位置。
rng = np.random.default_rng(0)
provs = df.prov.unique()
obs = pf.feols("y ~ D | firm + year", data=df).coef()["D"]

est = []
for b in range(500):
    fake = rng.choice(provs, 12, replace=False)
    d = df.assign(fD=df.prov.isin(fake).astype(int) * df.post)
    est.append(pf.feols("y ~ fD | firm + year", data=d).coef()["fD"])
est = np.array(est)

print(f"伪系数均值 {est.mean():.3f}，标准差 {est.std():.3f}")
print(f"|伪系数| ≥ |真实系数| 的比例：{(np.abs(est) >= abs(obs)).mean():.3f}")
伪系数均值 0.005，标准差 0.387
|伪系数| ≥ |真实系数| 的比例：0.000

500 次随机分配中，没有一次的伪系数绝对值超过真实估计值 1.85，置换 p 值 < 1/500 = 0.002。伪系数的均值为 0.005，非常接近 0，说明估计方法本身没有系统性偏误。

这个检验的统计学含义是 随机化推断（randomization inference）：在“政策对任何个体都没有效果”的精确原假设下，处理组的标签可以随意交换，真实估计值应该和随机分配得到的估计值没有区别。它的优点是 不依赖于标准误的计算方式，在聚类数很少时尤其有用（第 08 篇会进一步讨论）。

两点注意：

  • 置换应该在 处理分配的层级 上进行。政策在省份层面分配，就应该置换省份，而不是置换企业；
  • 你可能注意到伪系数的标准差（0.387）比基准回归的聚类标准误（0.148）大得多。这是因为部分伪处理组中包含了真正的处理省，把真实效应也“带”进了伪系数的分布。置换检验检验的是“对所有个体效应都为零”的原假设，在这个原假设下进行比较，结论仍然有效。

三、PSM-DID：当趋势依赖于可观测特征

问题：DID 允许处理组和对照组在 水平 上不同，但如果两组在某些特征上差异很大，而这些特征又会影响 增长速度，平行趋势就可能不成立。

例如：试点政策更倾向于选择规模大的企业，而规模大的企业本来就增长更快。这时直接做 DID，会把“大企业本来就更快的增长”算作政策效应。

思路：先用倾向得分匹配（PSM）为每个处理组企业找一个特征相似的对照组企业，然后在匹配后的样本上做 DID。这样，平行趋势只需要在“特征相似的企业之间”成立，即 条件平行趋势。

模拟一个需要 PSM 的场景

rng = np.random.default_rng(3)
N = 2000
x1 = rng.normal(0, 1, N)              # 例如企业规模
x2 = rng.normal(0, 1, N)              # 例如企业年龄
# 进入处理组的概率依赖于 x1、x2
ps_true = 1 / (1 + np.exp(-(-0.5 + 1.2 * x1 + 0.8 * x2)))
treat = (rng.uniform(size=N) < ps_true).astype(int)
alpha = rng.normal(0, 2, N) + 2 * x1

rows = []
for t in range(2):
    # 关键：x1 越大的企业，本身增长越快（趋势依赖于可观测变量）
    y = alpha + 1.0 * t + 1.5 * x1 * t + 2.0 * treat * t + rng.normal(0, 1, N)
    rows.append(pd.DataFrame({"id": np.arange(N), "t": t, "treat": treat,
                              "x1": x1, "x2": x2, "y": y}))
pp = pd.concat(rows)
pp["D"] = pp.treat * pp.t

naive = pf.feols("y ~ D | id + t", data=pp, vcov={"CRV1": "id"})
print("直接 DID:", round(naive.coef()["D"], 3))
直接 DID: 3.238

真实效应是 2，直接 DID 得到 3.24，**高估了 60%**。原因是处理组的 x1 平均更大，而 x1 大的企业本来就增长更快。

方法 A：加入“协变量 × 时间”

第 04 篇讲过，如果知道是哪个变量导致了趋势差异，可以直接加入它与时间的交互项：

ctrl = pf.feols("y ~ D + x1:t | id + t", data=pp, vcov={"CRV1": "id"})
print("DID + x1×t:", round(ctrl.coef()["D"], 3))
DID + x1×t: 1.959

方法 B：PSM-DID

from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import NearestNeighbors

# 1. 用政策前的特征估计倾向得分
cs = pp[pp.t == 0].copy()
lr = LogisticRegression().fit(cs[["x1", "x2"]], cs.treat)
cs["ps"] = lr.predict_proba(cs[["x1", "x2"]])[:, 1]

# 2. 1:1 最近邻匹配，有放回，卡尺 = 0.25 倍倾向得分标准差
tr, co = cs[cs.treat == 1], cs[cs.treat == 0]
nn = NearestNeighbors(n_neighbors=1).fit(co[["ps"]])
dist, idx = nn.kneighbors(tr[["ps"]])
caliper = 0.25 * cs.ps.std()
keep = dist[:, 0] <= caliper
matched_ids = np.concatenate([tr.id.values[keep], co.id.values[idx[keep, 0]]])
w = pd.Series(matched_ids).value_counts()      # 有放回匹配：被多次匹配的对照组企业权重更大
print("保留处理组企业:", keep.sum(), "/", len(tr), "；用到的对照组企业:", len(set(co.id.values[idx[keep, 0]])))

# 3. 在匹配样本上做（加权）DID
m = pp[pp.id.isin(w.index)].copy()
m["w"] = m.id.map(w)
psm = pf.feols("y ~ D | id + t", data=m, weights="w", vcov={"CRV1": "id"})
print("PSM-DID:", round(psm.coef()["D"], 3), "标准误", round(psm.se()["D"], 3))
保留处理组企业: 823 / 824 ；用到的对照组企业: 383
PSM-DID: 2.042 标准误 0.183

PSM-DID 的估计值为 2.04，接近真实值 2。

一定要做平衡性检验

匹配之后，需要检查处理组与对照组在协变量上是否已经平衡。常用指标是 标准化均值差（SMD），一般要求匹配后 |SMD| < 0.1：

$$
\text{SMD} = \frac{\bar{x}{\text{处理}} - \bar{x}{\text{对照}}}{\sqrt{(s^2_{\text{处理}} + s^2_{\text{对照}})/2}}
$$

mc = cs[cs.id.isin(w.index)].copy()
mc["w"] = mc.id.map(w)
for v in ["x1", "x2"]:
    sd_pool = np.sqrt((tr[v].var() + co[v].var()) / 2)
    before = (tr[v].mean() - co[v].mean()) / sd_pool
    trm, com = mc[mc.treat == 1], mc[mc.treat == 0]
    after = (trm[v].mean() - np.average(com[v], weights=com.w)) / sd_pool
    print(f"{v}: 匹配前 SMD = {before:.3f}，匹配后 SMD = {after:.3f}")
x1: 匹配前 SMD = 0.944，匹配后 SMD = -0.009
x2: 匹配前 SMD = 0.589，匹配后 SMD = 0.043

匹配前两组差异很大（x1 的 SMD 接近 1），匹配后基本平衡。

PSM-DID 的局限

  • 只能处理可观测变量导致的趋势差异。如果趋势差异来自不可观测因素，PSM 无能为力。
  • 只能用政策前的协变量匹配。用政策后的变量匹配会引入坏控制问题。
  • 不要逐年匹配。有的论文每一年重新匹配一次，导致每年的对照组都不同，面板结构被破坏，DID 失去意义。
  • 结果对匹配方法敏感（近邻数、卡尺、是否有放回），应报告多种设定。
  • 更系统的做法是第 11 篇介绍的 双重稳健 DID（Sant’Anna 和 Zhao，2020），它同时利用回归调整和倾向得分，只要两者之一设定正确即可得到一致估计。

四、三重差分（DDD）

问题：处理组在政策实施的同时，可能还受到了 其他冲击。比如试点省份在同一年还推出了另一项地方性的扶持政策，DID 会把两项政策的效应混在一起。

思路：如果政策只针对处理组中的 一部分个体（比如环保政策只针对高污染行业），那么处理组内部的“非目标个体”同样受到了其他冲击，但没有受到目标政策的影响。用它们再做一次差分，就能把其他冲击消掉。

设定

假设某项环保限产政策在 12 个试点省实施，只针对高污染行业。但试点省同期还实施了另一项政策，使 所有行业 的产出都提高了 1.5。我们关心的是环保政策对高污染企业产出的影响（真实效应为 −2）。

$$
Y_{it} = \alpha_i + \lambda_t + \beta_1 (\text{TP}_i \times \text{Post}_t) + \beta_2 (\text{High}_i \times \text{Post}_t) + \beta_3 (\text{TP}_i \times \text{High}_i \times \text{Post}t) + \varepsilon{it}
$$

其中 TP 表示试点省，High 表示高污染行业。$\beta_3$ 就是 DDD 估计值。

rng = np.random.default_rng(5)
P, F = 30, 40
prov = np.repeat(np.arange(P), F)
firm = np.arange(P * F)
tp = np.isin(prov, rng.choice(P, 12, replace=False)).astype(int)   # 是否试点省
high = rng.integers(0, 2, P * F)                                     # 是否高污染行业
a = rng.normal(0, 2, P * F) + 2 * tp + 1.5 * high

rows = []
for t in range(2):
    other = 1.5 * tp * t      # 试点省同期的另一项政策，影响所有行业
    y = (a + 1.0 * t + 0.8 * high * t + other
         - 2.0 * tp * high * t                       # 环保政策的真实效应 = -2
         + rng.normal(0, 1, P * F) + rng.normal(0, .5, P)[prov])
    rows.append(pd.DataFrame({"firm": firm, "prov": prov, "t": t,
                              "tp": tp, "high": high, "y": y}))
dd = pd.concat(rows)

# 只用高污染企业做 DID
d1 = pf.feols("y ~ tp:t | firm + t", data=dd[dd.high == 1], vcov={"CRV1": "prov"})
print("DID（仅高污染企业）:", round(d1.coef()["tp:t"], 3))

# 三重差分
d3 = pf.feols("y ~ tp:t:high + tp:t + high:t | firm + t", data=dd, vcov={"CRV1": "prov"})
print(d3.tidy()[["Estimate", "Std. Error"]].round(3))
DID（仅高污染企业）: -0.497
             Estimate  Std. Error
Coefficient
tp:t            1.368       0.294
high:t          0.718       0.099
tp:t:high      -1.866       0.156
  • 只用高污染企业做 DID，估计值为 −0.50：真实效应 −2 被同期的另一项政策（+1.5）抵消了大部分；
  • 三重差分的估计值为 −1.87，接近真实值 −2；
  • 系数 tp:t = 1.37 正好捕捉了那项“其他政策”对试点省所有企业的影响（真实值 1.5）。

DDD 的识别假设

一个常见的误解是 DDD 需要“两个平行趋势”都成立。实际上，Olden 和 Møen（2022）指出，DDD 只需要 一个 假设：

在没有政策的情况下，试点省内“高污染 − 低污染”的趋势差 与 非试点省内“高污染 − 低污染”的趋势差 相同。

这比 DID 的平行趋势更弱：允许试点省整体有不同的趋势（被低污染企业捕捉），也允许高污染行业整体有不同的趋势（被非试点省捕捉）。DDD 也可以写成两个 DID 之差：

$$
\hat\beta_{\text{DDD}} = \hat\beta_{\text{DID}}^{\text{高污染}} - \hat\beta_{\text{DID}}^{\text{低污染}}
$$

注意事项

  • 做 DDD 时，回归中必须包含所有的低阶交互项（tp:t、high:t 以及被固定效应吸收的 tp:high 等），否则 $\beta_3$ 的解释会出错；
  • 第三重差分的维度应有经济学上的合理性：非目标群体必须确实不受政策影响，又确实受到了同样的其他冲击。

五、其他常见的稳健性检验

除了以上四种，实证论文中还经常看到以下检验，每一种都对应一种具体的担忧：

检验 针对的担忧
排除同期其他政策（控制或剔除受其他政策影响的样本） 同期政策混淆
剔除直辖市、省会城市等特殊样本 特殊个体驱动结果
更换对照组（如只用邻近地区） 对照组可比性
剔除邻近处理组的对照个体 溢出效应（违背 SUTVA）
剔除政策前一年（$k=-1$）或改用宣布时间 预期效应
更换被解释变量的度量方式 测量误差
加入更细的固定效应（行业 × 年份、地区 × 年份） 更细层面的共同冲击
缩尾或剔除极端值 极端值驱动结果

原则是：先想清楚可能的威胁是什么，再选择针对性的检验，而不是把所有检验都堆上去。

Stata 代码对照

* ---------- 时间安慰剂
preserve
keep if year < 2015
gen fakeD = treat * (year >= 2013)
reghdfe y fakeD, absorb(firm year) vce(cluster prov)
restore

* ---------- 随机化安慰剂（省份层面置换）
* ritest（ssc install ritest）：置换的是省份层面不变的 treat，交互项在命令中现算
ritest treat _b[c.treat#c.post], reps(500) cluster(prov) seed(123): ///
    reghdfe y c.treat#c.post, absorb(firm year) vce(cluster prov)

* ---------- PSM-DID（ssc install psmatch2）
* 用基期数据估计倾向得分并匹配
psmatch2 treat x1 x2 if t == 0, logit neighbor(1) caliper(0.05) common
pstest x1 x2, both              // 平衡性检验
* 将匹配权重 _weight 合并回面板后做加权 DID
bysort id (t): replace _weight = _weight[1]
reghdfe y D [aw=_weight] if _weight != ., absorb(id t) vce(cluster id)

* ---------- 三重差分
reghdfe y c.tp#c.t#c.high c.tp#c.t c.high#c.t, absorb(firm t) vce(cluster prov)

注意 ritest 的 cluster() 选项指定的是 置换的层级，这里是在省份层面打乱处理状态。

小结

  • 稳健性检验要有针对性：先识别威胁，再选择检验。
  • 时间安慰剂：检验政策前的趋势差异，只能用政策前数据。
  • 随机化安慰剂：在处理分配的层级上置换，同时也是一种不依赖标准误的推断方法。
  • PSM-DID：处理可观测特征导致的趋势差异，用基期特征匹配，必须做平衡性检验。
  • 三重差分：处理处理组同期受到的其他冲击，只需要一个“趋势差之差”为零的假设。
