DID 从入门到精通（04）：用回归估计 DID——交互项、控制变量与聚类标准误

DID 计量经济学 因果推断 Python Stata
Econometrics
发布日期:   2026-10-08

前三篇都在讲概念，这一篇开始动手。我们会用同一份数据，依次用 四格表手算、交互项回归、一阶差分、固定效应回归 四种方法估计 DID，验证它们给出完全相同的点估计；然后讨论实践中最常被问到的两个问题：控制变量要不要加、怎么加？标准误为什么要聚类？

数据：一个省份试点政策

为了能和“真实答案”对照，我们使用模拟数据。设定如下：

  • 30 个省份，每个省 40 家企业，共 1200 家企业；
  • 随机抽取 10 个省作为某项创新政策的试点省（处理组）；
  • 两期数据：政策前（2017 年）和政策后（2019 年）；
  • 结果变量 $y$：企业研发投入（百万元）；
  • 真实政策效应为 2。

为了让数据更像现实，我们加入了几个“麻烦”：

  • 试点省的企业本来就比非试点省高 4 左右（水平差异，DID 可以处理）；
  • 存在所有企业共同的时间趋势（+3，DID 可以处理）；
  • 每个省每年有一个共同的随机冲击（导致同一省内企业的误差相关，这会影响标准误）。
import numpy as np
import pandas as pd

rng = np.random.default_rng(2024)
n_prov, firms_per_prov = 30, 40
prov = np.repeat(np.arange(n_prov), firms_per_prov)
firm = np.arange(n_prov * firms_per_prov)
treat_prov = rng.choice(n_prov, 10, replace=False)
treat = np.isin(prov, treat_prov).astype(int)

prov_effect = rng.normal(0, 2, n_prov)[prov]           # 省份层面的固定差异
firm_effect = rng.normal(0, 3, len(firm)) + 4 * treat  # 试点省企业本来就更高
size = rng.normal(5, 1, len(firm))                      # 企业规模（对数），不随时间变

rows = []
for post in (0, 1):
    shock = rng.normal(0, 1, n_prov)[prov]              # 省份-年份冲击（造成组内相关）
    y = (10 + prov_effect + firm_effect + 0.8 * size
         + 3 * post                                      # 共同时间趋势
         + 2 * treat * post                              # 真实处理效应 = 2
         + shock + rng.normal(0, 2, len(firm)))
    rows.append(pd.DataFrame({"firm": firm, "prov": prov, "treat": treat,
                              "post": post, "size": size, "y": y}))
df = pd.concat(rows, ignore_index=True)
df.to_csv("did_2x2.csv", index=False)
print(df.head())

数据是标准的 长格式（long format） 面板：每行是一个“企业-时期”，共 2400 行。

方法一：四格表

tab = df.groupby(["treat", "post"]).y.mean().unstack()
print(tab.round(3))
did = (tab.loc[1, 1] - tab.loc[1, 0]) - (tab.loc[0, 1] - tab.loc[0, 0])
print("手算 DID:", round(did, 3))
print("前后对比(只看处理组):", round(tab.loc[1, 1] - tab.loc[1, 0], 3))
print("截面对比(只看政策后):", round(tab.loc[1, 1] - tab.loc[0, 1], 3))

和第 02 篇的结论一样：前后对比（4.84）混入了共同时间趋势，截面对比（5.33）混入了组间水平差异，都严重高估了真实效应 2。DID 给出 1.73，离真实值近得多，剩下的差距是抽样误差。

方法二：交互项回归

$$
y_{it} = \beta_0 + \beta_1 , \text{treat}_i + \beta_2 , \text{post}_t + \beta_3 , \text{treat}_i \times \text{post}t + \varepsilon{it}
$$

在 statsmodels 的公式语法里，treat * post 会自动展开为 treat + post + treat:post：

import statsmodels.formula.api as smf

m1 = smf.ols("y ~ treat * post", data=df).fit()
print(f"coef={m1.params['treat:post']:.3f}, se={m1.bse['treat:post']:.3f}")
coef=1.728, se=0.361

交互项系数 1.728，与四格表 完全相同。但这里的标准误 0.361 是有问题的，后面专门讨论。

方法三：一阶差分

在两期面板中，还可以先对每个企业做前后差分 $\Delta y_i = y_{i2} - y_{i1}$，然后把 $\Delta y_i$ 对 $\text{treat}_i$ 回归：

$$
\Delta y_i = \gamma_0 + \gamma_1 , \text{treat}_i + \Delta \varepsilon_i
$$

差分消掉了企业固定效应，$\gamma_1$ 就是“处理组的平均变化 − 对照组的平均变化”，正是 DID。

wide = df.pivot(index="firm", columns="post", values="y")
wide.columns = ["y0", "y1"]
wide["dy"] = wide.y1 - wide.y0
wide = wide.join(df.groupby("firm")[["treat", "prov"]].first())

fd = smf.ols("dy ~ treat", data=wide).fit(cov_type="cluster", cov_kwds={"groups": wide["prov"]})
print(f"一阶差分: coef={fd.params['treat']:.3f}, se={fd.bse['treat']:.3f}")
一阶差分: coef=1.728, se=0.686

方法四：双向固定效应回归

$$
y_{it} = \alpha_i + \lambda_t + \tau , D_{it} + \varepsilon_{it}, \qquad D_{it} = \text{treat}_i \times \text{post}_t
$$

用 pyfixest（Python 版的 fixest，语法和 Stata 的 reghdfe 很像），竖线 | 后面写需要吸收的固定效应：

import pyfixest as pf

fit = pf.feols("y ~ treat:post | firm + post", data=df, vcov={"CRV1": "prov"})
fit.summary()

四种方法给出 完全相同的点估计 1.728。这不是巧合：在两期平衡面板中，它们在代数上是等价的。

控制变量：加还是不加？

很多初学者的第一反应是“控制变量越多越好”。在 DID 里，这个直觉经常是错的。

不随时间变化的控制变量：没有作用

我们的数据里有一个企业规模变量 size，它在两期之间不变。把它加进交互项回归：

m2 = smf.ols("y ~ treat * post", data=df).fit(cov_type="cluster", cov_kwds={"groups": df["prov"]})
m3 = smf.ols("y ~ treat * post + size", data=df).fit(cov_type="cluster", cov_kwds={"groups": df["prov"]})
for name, m in [("不加控制", m2), ("加 size", m3)]:
    print(f"{name}: coef={m.params['treat:post']:.3f}, se={m.bse['treat:post']:.3f}")
不加控制: coef=1.728, se=0.686
加 size: coef=1.728, se=0.686

系数和标准误都没变。原因很简单：DID 的第一次差分已经把所有 不随时间变化 的个体特征消掉了，包括可观测的 size 和不可观测的企业文化、管理能力等。在固定效应回归里，这类变量会被个体固定效应完全吸收，软件会直接把它删掉。

允许趋势依赖于协变量：变量 × 时间

真正有用的做法是：如果你担心 不同特征的企业有不同的增长趋势（比如大企业本来就增长更快），而处理组和对照组在这个特征上分布不同，那么平行趋势可能只在“控制了这个特征之后”才成立。这时应该加入 协变量与时间的交互项：

m4 = smf.ols("y ~ treat * post + size * post", data=df).fit(cov_type="cluster", cov_kwds={"groups": df["prov"]})
print(m4.params.round(3))
Intercept     10.356
treat          3.620
post           3.111
treat:post     1.728
size           0.765
size:post      0.001
dtype: float64

size:post 接近 0，说明在我们的数据里大小企业的增长趋势没有差异（模拟时确实没有设定），所以 DID 估计值不变。在真实数据里，这一项可能很重要。这种“条件平行趋势”的思想会在第 07 篇（PSM-DID）和第 11 篇（双重稳健 DID）中进一步展开。

坏控制变量：千万别加

被政策影响的变量不能作为控制变量。比如研究试点政策对企业研发投入的影响，如果控制了“政策后的企业利润”，而利润本身也受政策影响，就会产生偏误——你把政策效应的一部分“控制掉”了。这类变量叫作 坏控制（bad control）。

经验法则：

  • 尽量使用 政策前（基期）的协变量值，或者不随时间变化的特征；
  • 如果必须使用随时间变化的控制变量，要论证它不受政策影响；
  • 加入控制变量前后系数变化很大，往往说明存在问题，而不是“结果更准确了”。

标准误：为什么必须聚类

回到刚才那个问题。同样的点估计 1.728，普通 OLS 给出的标准误是 0.361，聚类到省份后变成 0.686，几乎翻了一倍：

方法 系数 标准误 p 值
OLS 普通标准误 1.728 0.361 0.0000
省份聚类标准误 1.728 0.686 0.0118

哪个是对的？

普通 OLS 标准误假设每个观测值的误差项 相互独立。但在我们的数据里，每个省每年有一个共同冲击 shock，同一个省的 40 家企业同时受到这个冲击，它们的误差项高度相关。这意味着：40 家企业提供的有效信息远少于 40 个独立观测。

更关键的是：政策是在省份层面分配的。真正有多少“独立的实验单位”？只有 30 个省，其中 10 个处理省。把 1200 家企业当作 1200 个独立样本，会严重低估不确定性。

这就是 Bertrand、Duflo 和 Mullainathan（2004）那篇著名论文的核心发现：他们在美国州级数据中随机生成“假政策”，用普通标准误做 DID，结果高达 45% 的假政策显示出 5% 水平的显著效应——而正确的比例应该是 5%。第 08 篇会用模拟重现这个结果。

聚类到哪一层？

一个实用的原则（Abadie 等，2023）：

聚类层级应该与处理分配的层级一致。

  • 政策在省份层面分配 → 聚类到省份；
  • 政策在城市层面分配 → 聚类到城市；
  • 政策在企业层面分配（比如某些企业被选入试点名单）→ 聚类到企业。

如果处理分配层级上的聚类数太少（比如只有 6 个省、其中 2 个处理省），聚类标准误本身也不可靠，需要用 wild cluster bootstrap 或随机化推断，这些放到第 08 篇讲。

小细节：z 分布还是 t 分布

你可能注意到，statsmodels 和 pyfixest 给出的标准误都是 0.686，但 p 值不同：statsmodels 是 0.0118，pyfixest 是 0.018。这是因为：

  • statsmodels 的 cov_type="cluster" 默认用 正态分布 计算 p 值；
  • pyfixest 和 Stata 默认用 自由度为 $G-1$ 的 t 分布（$G$ 为聚类数，这里是 29）。

聚类数不多时 t 分布更保守，也更合理。在 statsmodels 中可以加上 use_t=True：

smf.ols("y ~ treat * post", data=df).fit(
    cov_type="cluster", cov_kwds={"groups": df["prov"]}, use_t=True
)

Stata 代码对照

import delimited "did_2x2.csv", clear

* 四格表
table treat post, statistic(mean y)

* 交互项回归
reg y i.treat##i.post, vce(cluster prov)

* 手动生成交互项
gen treat_post = treat * post
reg y treat post treat_post, vce(cluster prov)

* 固定效应回归
xtset firm post
xtreg y treat_post i.post, fe vce(cluster prov)

* reghdfe（推荐，速度快，支持多维固定效应）
reghdfe y treat_post, absorb(firm post) vce(cluster prov)

* 允许趋势依赖于协变量
reghdfe y treat_post c.size#i.post, absorb(firm post) vce(cluster prov)

注意 Stata 的 reg 和 reghdfe 在聚类时默认使用 $t(G-1)$ 分布，结果与 pyfixest 一致。

估计结果怎么解读

最终我们报告：

试点政策使企业研发投入平均增加 1.73 百万元（省份聚类标准误 0.69，95% 置信区间 [0.33, 3.13]），在 5% 水平上显著。

真实效应 2 落在置信区间内。注意解读时的几个要点：

  • 这是 ATT：试点省企业的平均效应，不一定能外推到非试点省；
  • 它依赖于 平行趋势：两期数据无法检验，需要更多政策前时期（下一篇）；
  • 置信区间较宽：只有 10 个处理省，信息有限。

小结

  • 四格表、交互项回归、一阶差分、双向固定效应在 2×2 平衡面板中给出 完全相同的点估计。
  • 不随时间变化的控制变量在 DID 中不起作用；担心趋势异质性时应加入“协变量 × 时间”；不要控制受政策影响的变量。
  • 标准误必须考虑组内相关，聚类层级与处理分配层级一致。
  • 聚类数不多时用 $t(G-1)$ 分布计算 p 值。
