DID 从入门到精通（05）：多期 DID 与双向固定效应模型

DID DID进阶
Econometrics
发布日期:   2026-10-08

现实中的面板数据很少只有两期。一项 2015 年实施的政策，我们往往拥有 2010—2019 年十年的数据。多期数据带来了两个好处：一是 估计更精确，二是 可以观察政策前多年的趋势，从而评估平行趋势是否可信。这一篇讨论多期 DID 的标准模型——双向固定效应模型（Two-Way Fixed Effects，TWFE）。

本文是「DID 从入门到精通」系列第 05 篇，完整路线见 系列导读。

本篇只讨论 所有处理组在同一时间接受处理 的情形（有时叫“标准 DID”或“单一时点 DID”）。政策分批实施的“交错 DID”会在第 09、10 篇专门讨论，那里 TWFE 会出问题。

一、模型

  • ：个体固定效应，每个个体一个截距，吸收所有不随时间变化的个体特征；
  • ：时间固定效应，每期一个截距，吸收所有个体共同面对的时间冲击；
  • ：处理变量，处理组在政策后为 1；
  • ：处理效应。

和 2×2 版本相比，这个模型做了两点推广：时间从 2 期变成了 期； 允许每一期有各自的共同冲击，而不只是“前”和“后”两个水平。

二、数据

继续使用省份试点的设定，但扩展为 10 年面板：

  • 30 个省，每省 20 家企业，共 600 家企业；
  • 12 个省为试点省，政策于 2015 年实施；
  • 2010—2019 年，共 6000 个观测；
  • 共同时间趋势是一个随机游走（每年的宏观冲击不同）；
  • 省份-年份层面有随机冲击；
  • 真实效应为 2，且不随时间变化。
import numpy as np
import pandas as pd

def make_panel(seed=7, effect=lambda k: 2.0 * (k >= 0), pretrend=0.0):
    """effect: 以“距政策实施年数 k”为参数的处理效应函数；pretrend: 处理组额外的线性趋势"""
    rng = np.random.default_rng(seed)
    n_prov, fpp = 30, 20
    years = np.arange(2010, 2020)
    prov = np.repeat(np.arange(n_prov), fpp)
    firm = np.arange(n_prov * fpp)
    treat_prov = rng.choice(n_prov, 12, replace=False)
    treat = np.isin(prov, treat_prov).astype(int)
    alpha = rng.normal(0, 3, len(firm)) + 3 * treat                  # 个体固定效应
    gamma = dict(zip(years, np.cumsum(rng.normal(0.5, 0.8, len(years)))))  # 共同时间冲击
    out = []
    for t in years:
        k = t - 2015
        shock = rng.normal(0, 0.6, n_prov)[prov]                     # 省份-年份冲击
        y = (alpha + gamma[t] + treat * effect(k) + pretrend * treat * (t - 2015)
             + shock + rng.normal(0, 1.5, len(firm)))
        out.append(pd.DataFrame({"firm": firm, "prov": prov, "year": t, "treat": treat,
                                 "post": int(t >= 2015), "y": y}))
    df = pd.concat(out, ignore_index=True)
    df["D"] = df.treat * df.post
    return df

df = make_panel()
print(df.head())

这个 make_panel 函数在后面几篇会反复使用，通过 effect 和 pretrend 参数可以生成动态效应、平行趋势被违背等不同场景。

三、四种等价的估计方法

方法一：LSDV（最小二乘虚拟变量法）

最直接的办法是把 600 个企业虚拟变量和 10 个年份虚拟变量全部放进回归：

import statsmodels.formula.api as smf

lsdv = smf.ols("y ~ D + C(firm) + C(year)", data=df).fit(
    cov_type="cluster", cov_kwds={"groups": df["prov"]})
print(f"LSDV      : {lsdv.params['D']:.4f} ({lsdv.bse['D']:.4f})")
LSDV      : 1.8474 (0.1564)

LSDV 概念清晰，但当个体很多（几万家企业）时，要估计几万个虚拟变量系数，计算非常慢，内存也吃不消。

方法二：组内变换（双向去均值）

根据 Frisch-Waugh-Lovell 定理，我们可以先把 和 中能被固定效应解释的部分“去掉”，再用残差对残差回归，得到的 与 LSDV 完全相同。对于 平衡面板，双向固定效应的去除方式很简单：

即减去个体均值、减去时期均值、再加回总均值。对 做同样的变换，然后：

d = df.copy()
for v in ["y", "D"]:
    d[v + "_dm"] = (d[v] - d.groupby("firm")[v].transform("mean")
                    - d.groupby("year")[v].transform("mean") + d[v].mean())
w = smf.ols("y_dm ~ D_dm - 1", data=d).fit()
print(f"双向去均值: {w.params['D_dm']:.4f}")
双向去均值: 1.8474

这个公式值得记住：TWFE 估计量就是用“双向去均值后的 ”作为权重，对“双向去均值后的 ”做加权平均。第 09 篇会看到，正是这个权重在交错 DID 中可能变成负数。

注意：上面的简单去均值公式只对 平衡面板 成立。非平衡面板需要迭代去均值（交替对个体和时间去均值直到收敛），pyfixest、reghdfe 等软件内部就是这样做的。

方法三：linearmodels 的 PanelOLS

from linearmodels.panel import PanelOLS

p = df.set_index(["firm", "year"])    # 必须设置 (个体, 时间) 两级索引
lm = PanelOLS.from_formula("y ~ D + EntityEffects + TimeEffects", data=p).fit(
    cov_type="clustered", clusters=p["prov"])
print(f"PanelOLS  : {lm.params['D']:.4f} ({lm.std_errors['D']:.4f})")
PanelOLS  : 1.8474 (0.1538)

方法四：pyfixest（推荐）

import pyfixest as pf

fit = pf.feols("y ~ D | firm + year", data=df, vcov={"CRV1": "prov"})
print(f"pyfixest  : {fit.coef()['D']:.4f} ({fit.se()['D']:.4f})")
pyfixest  : 1.8474 (0.1484)

pyfixest 的语法和 R 的 fixest、Stata 的 reghdfe 几乎一样，处理百万级观测、多维固定效应都很快，后面的文章都主要用它。

再验证一次：四格均值

m = df.groupby(["treat", "post"]).y.mean().unstack()
print(f"四格均值DID: {(m.loc[1,1]-m.loc[1,0]) - (m.loc[0,1]-m.loc[0,0]):.4f}")
四格均值DID: 1.8474

在 平衡面板 + 所有处理组同时开始处理 的情况下，TWFE 估计量等于“政策后均值 − 政策前均值”的 2×2 DID。也就是说，多期 TWFE 本质上是把政策前所有年份合并成“前”，政策后所有年份合并成“后”，再做一次 2×2 DID。

四、为什么标准误不一样？

点估计完全相同，但标准误在 0.148 到 0.156 之间：

方法 点估计 聚类标准误
LSDV（statsmodels） 1.8474 0.1564
PanelOLS（linearmodels） 1.8474 0.1538
pyfixest 1.8474 0.1484

差别来自 小样本自由度调整 的方式不同。聚类标准误通常会乘以一个调整因子：

关键在于 算多少个参数：

  • LSDV 把 600 个企业虚拟变量都算进 ，调整因子最大；
  • pyfixest 和 reghdfe 默认认为 嵌套在聚类变量内的固定效应 不应计入 （企业嵌套在省份内），调整因子最小；
  • linearmodels 介于两者之间。

聚类数较多时这些差别可以忽略。写论文时只需说明使用的软件和设定，保证可复现即可。

五、解读：τ 是什么样的平均效应？

如果处理效应不随时间变化（如本例）， 就是这个常数效应的估计。

如果处理效应随时间变化（比如政策效果逐年增强），在 单一处理时点的平衡面板 中，由于 TWFE 等价于“后期均值 − 前期均值”的 DID， 估计的是 政策后各期 ATT 的简单平均，仍然有清晰的解释。但我们看不到效应的动态变化——这是下一篇事件研究要解决的问题。

六、加入更多固定效应：灵活但要小心

TWFE 的一个优点是可以很方便地加入更细的固定效应，来控制更复杂的共同冲击。

行业 × 年份固定效应

如果担心不同行业受到不同的年度冲击（比如某年房地产行业整体下行），可以加入行业 × 年份固定效应，即只在 同一行业、同一年份 的企业之间做比较：

rng = np.random.default_rng(0)
df["ind"] = rng.integers(0, 10, df.firm.nunique())[df.firm]   # 随机给每家企业分配一个行业
fit_ind = pf.feols("y ~ D | firm + ind^year", data=df, vcov={"CRV1": "prov"})
print(f"行业×年份FE: {fit_ind.coef()['D']:.4f} ({fit_ind.se()['D']:.4f})")
行业×年份FE: 1.8863 (0.1468)

ind^year 表示行业和年份的交互固定效应（Stata 中写 absorb(firm ind#year)）。

陷阱一：固定效应把处理变量吸收掉

如果政策在省份层面实施，就 不能 加入省份 × 年份固定效应。因为 在同一省同一年内完全相同，会被省份 × 年份固定效应完全吸收，回归无法识别：

pf.feols("y ~ D | firm + prov^year", data=df)
ValueError: All variables are collinear. Maybe your model specification introduces multicollinearity? ...

一般原则：固定效应的维度不能比处理变化的维度更细。

陷阱二：组别线性趋势会吸收动态效应

有些论文为了“控制可能存在的趋势差异”，会加入省份 × 线性时间趋势：

这看起来很稳健，实际上有风险。我们分别在常数效应和 逐年增强的动态效应（真实平均效应同样是 2）下比较：

df["t"] = df.year - 2010
f1 = pf.feols("y ~ D + C(prov):t | firm + year", data=df, vcov={"CRV1": "prov"})
print("常数效应 + 省份趋势:", round(f1.coef()["D"], 4), round(f1.se()["D"], 4))

dyn = make_panel(seed=5, effect=lambda k: np.where(k >= 0, 1 + 0.5 * k, 0.0))
dyn["t"] = dyn.year - 2010
print("动态效应 TWFE      :", round(pf.feols("y ~ D | firm + year", data=dyn).coef()["D"], 4))
print("动态效应 + 省份趋势:", round(pf.feols("y ~ D + C(prov):t | firm + year", data=dyn).coef()["D"], 4))
常数效应 + 省份趋势: 1.3347 0.3035
动态效应 TWFE      : 2.0361
动态效应 + 省份趋势: 0.9342

两个问题：

  1. 即使效应是常数，加入省份趋势后标准误也翻了一倍（0.148 → 0.304），点估计偏离真值更远——因为趋势要用有限的数据去估计，消耗了大量信息；
  2. 当效应逐年增强时，政策后的效应增长被误认为是“省份本来的趋势”，估计值从 2.04 被压低到 0.93。

Wolfers（2006）在研究离婚法改革时就指出了这一问题。更好的做法是：用事件研究检查政策前是否真的存在趋势差异（下一篇），如果存在，考虑第 11 篇介绍的 HonestDiD 敏感性分析，而不是机械地加入线性趋势。

Stata 代码对照

* 读入数据后
xtset firm year

* 传统固定效应
xtreg y D i.year, fe vce(cluster prov)

* reghdfe（推荐）
reghdfe y D, absorb(firm year) vce(cluster prov)

* 行业 × 年份固定效应
reghdfe y D, absorb(firm ind#year) vce(cluster prov)

* 省份线性趋势（谨慎使用）
reghdfe y D, absorb(firm year prov#c.year) vce(cluster prov)

小结

  • 多期 DID 的标准模型是双向固定效应：。
  • LSDV、双向去均值、PanelOLS、pyfixest、reghdfe 给出完全相同的点估计；标准误的细微差别来自自由度调整。
  • 单一处理时点的平衡面板中，TWFE 等价于“前期均值 vs 后期均值”的 2×2 DID。
  • 加入固定效应时，维度不能比处理变化的维度更细；加入组别线性趋势会降低精度，并可能吸收动态处理效应。

练习

  1. 随机删除 10% 的观测，把 make_panel 的数据变成非平衡面板，比较“简单双向去均值”与 pyfixest 的估计结果，解释为什么不再相同。
  2. 用 effect=lambda k: np.where(k >= 0, 1 + 0.5 * k, 0.0) 生成动态效应数据，验证静态 TWFE 估计值等于“政策后均值 − 政策前均值”的 2×2 DID。
  3. 设想政策在城市层面实施，数据为企业层面面板。以下固定效应中哪些可以加入、哪些不行：企业、年份、行业 × 年份、城市 × 年份、省份 × 年份？说明理由。
  4. 查阅 pyfixest 文档中关于小样本调整 ssc 的说明，尝试复现 LSDV 的聚类标准误 0.1564。
