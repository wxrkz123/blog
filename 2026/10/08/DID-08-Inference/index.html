DID 从入门到精通（08）：统计推断——聚类标准误、少聚类问题与 Wild Bootstrap

DID 计量经济学 因果推断 Python Stata
Econometrics
发布日期:   2026-10-08

点估计告诉我们“效应有多大”，标准误告诉我们“这个估计有多可信”。在 DID 中，标准误出错的情况远比点估计出错更常见，而且更隐蔽：一个本来不显著的结果，可能仅仅因为标准误算错了就变得“高度显著”。这一篇专门讨论 DID 的统计推断。

问题的来源：误差项不独立

普通 OLS 标准误假设每个观测值的误差项相互独立、方差相同。DID 数据几乎总是违背这个假设，主要有两种相关：

1. 组内相关（cross-sectional correlation）：同一个省的企业在同一年受到共同冲击（地方经济波动、地方政策），它们的误差项是相关的。

2. 序列相关（serial correlation）：同一个企业（或同一个省）的误差项在不同年份之间相关。今年业绩好的企业，明年大概率也不会太差。

DID 对这两种相关特别敏感，原因在于 处理变量 $D_{it}$ 本身也是高度相关的：它在同一个省内完全相同，在时间上又是“前面全是 0、后面全是 1”的形式，序列相关性极强。误差项和解释变量都高度相关时，普通标准误会严重低估真实的抽样波动。

聚类稳健标准误

解决办法是 聚类稳健标准误（cluster-robust standard errors）。把观测值分成 $G$ 个聚类（比如省份），允许聚类内部任意相关，只假设聚类之间独立。方差估计为：

$$
\hat{V}{\text{CR}}(\hat\beta) = (X’X)^{-1} \left( \sum{g=1}^{G} X_g’ \hat{u}_g \hat{u}_g’ X_g \right) (X’X)^{-1}
$$

其中 $X_g$ 和 $\hat u_g$ 是第 $g$ 个聚类的解释变量矩阵和残差向量。中间的“肉”允许同一个聚类内所有观测值（跨个体、跨时间）的残差任意相关。

注意：聚类的 **渐近理论依赖于聚类数 $G \to \infty$**，而不是观测值个数 $N \to \infty$。如果只有十几个聚类，即使有几百万个观测，聚类标准误也可能不可靠。

蒙特卡洛模拟：错误的标准误有多危险

Bertrand、Duflo 和 Mullainathan（2004）的做法很巧妙：在真实数据中随机生成 假政策（真实效应为 0），然后看 DID 有多大比例“显著”。如果标准误正确，5% 水平下应该只有约 5% 的假政策显著。

我们用模拟数据重现这个实验：

  • 30 个省，每省 20 家企业，10 年，12 个省在第 5 年起“受到处理”；
  • 真实效应为 0；
  • 误差项包括：企业固定效应、省份-年份层面的 AR(1) 冲击（$\rho=0.8$）、企业层面的 AR(1) 冲击（$\rho=0.8$）、独立噪声。
import numpy as np
import pandas as pd
import pyfixest as pf

def ar1(rng, n, T, rho, sd):
    """生成 n 条长度为 T 的平稳 AR(1) 序列"""
    e = np.zeros((n, T))
    e[:, 0] = rng.normal(0, sd / np.sqrt(1 - rho**2), n)
    for t in range(1, T):
        e[:, t] = rho * e[:, t - 1] + rng.normal(0, sd, n)
    return e

def sim(rng, P=30, n_treat=12, F=20, T=10, rho=0.8):
    prov = np.repeat(np.arange(P), F)
    N = P * F
    tp = np.isin(prov, rng.choice(P, n_treat, replace=False)).astype(int)
    pe = ar1(rng, P, T, rho, 0.5)[prov]          # 省份-年份层面的序列相关冲击
    fe = ar1(rng, N, T, rho, 0.5)                 # 企业层面的序列相关冲击
    y = rng.normal(0, 2, N)[:, None] + pe + fe + rng.normal(0, 1, (N, T))   # 真实效应 = 0
    df = pd.DataFrame({"firm": np.repeat(np.arange(N), T), "prov": np.repeat(prov, T),
                       "year": np.tile(np.arange(T), N), "y": y.ravel()})
    df["D"] = np.repeat(tp, T) * (df.year >= T // 2)
    return df

def run(P, n_treat, reps, boot=False, seed=1):
    """返回各种标准误在 5% 水平下的拒绝率（真实效应为 0，正确的拒绝率应为 5%）"""
    rng = np.random.default_rng(seed)
    rej = {"iid": 0, "firm": 0, "prov": 0, "collapse": 0, "wild": 0}
    for r in range(reps):
        df = sim(rng, P=P, n_treat=n_treat)
        rej["iid"] += pf.feols("y ~ D | firm + year", data=df, vcov="iid").pvalue()["D"] < .05
        rej["firm"] += pf.feols("y ~ D | firm + year", data=df, vcov={"CRV1": "firm"}).pvalue()["D"] < .05
        fp = pf.feols("y ~ D | firm + year", data=df, vcov={"CRV1": "prov"})
        rej["prov"] += fp.pvalue()["D"] < .05
        # Bertrand 等（2004）的“压缩为前后两期”
        c = (df.assign(post=(df.year >= 5).astype(int))
               .groupby(["firm", "prov", "post"], as_index=False)
               .agg(y=("y", "mean"), D=("D", "max")))
        rej["collapse"] += pf.feols("y ~ D | firm + post", data=c, vcov={"CRV1": "prov"}).pvalue()["D"] < .05
        if boot:
            wb = fp.wildboottest(param="D", reps=999, seed=r, weights_type="webb")
            rej["wild"] += float(wb["Pr(>|t|)"]) < .05
    return {k: round(float(v) / reps, 3) for k, v in rej.items()}

print(run(30, 12, 300))
{'iid': 0.673, 'firm': 0.53, 'prov': 0.053, 'collapse': 0.053, 'wild': 0.0}

（wild 一项在这次运行中没有计算，所以显示为 0。）

标准误 拒绝率（应为 5%）
普通 OLS（iid） 67.3%
聚类到企业 53.0%
聚类到省份 5.3%
压缩为两期 + 省份聚类 5.3%

结果非常惊人：

  • 普通 OLS 标准误下，三分之二的假政策是“显著”的。 如果你用错了标准误，你的“显著结果”有很大概率是假的。
  • 聚类到企业也不够：它处理了企业层面的序列相关，但忽略了同一个省份内企业之间的共同冲击，拒绝率仍然超过 50%。
  • 聚类到省份（处理分配的层级）后，拒绝率回到 5% 左右。

这再次印证了第 04 篇的原则：聚类层级应该与处理分配的层级一致，因为它同时容纳了组内相关和序列相关。

Bertrand 等人的其他解决方案

Bertrand 等人还比较了几种方法，其中“压缩为前后两期”（collapse）简单有效：把每个个体的数据分别在政策前、政策后取平均，变成 2×2 的面板，再做 DID。这样序列相关的问题就不复存在了。它在单一处理时点时很好用，但在交错 DID 中操作起来比较麻烦。

聚类太少：聚类标准误也会失效

聚类标准误的理论依赖于“聚类数足够多”。实践中常见的困境是：

  • 政策在省级实施，但只有 3 个试点省；
  • 研究某一个国家的政策，用其他几个国家作对照；
  • 只有一个城市实施了某项改革。

MacKinnon 和 Webb（2017）证明，真正重要的不是总聚类数，而是处理组的聚类数（以及处理组与对照组聚类数的平衡程度）。即使总聚类数有 50 个，如果其中只有 2 个是处理组，聚类标准误也会严重低估不确定性。

我们用两组模拟来看：

print("8 个省，3 个处理省 :", run(8, 3, 300, boot=True, seed=2))
print("20 个省，2 个处理省:", run(20, 2, 300, boot=True, seed=3))
8 个省，3 个处理省 : {'iid': 0.643, 'firm': 0.52, 'prov': 0.06, 'collapse': 0.06, 'wild': 0.057}
20 个省，2 个处理省: {'iid': 0.637, 'firm': 0.537, 'prov': 0.283, 'collapse': 0.283, 'wild': 0.0}

（带 wild bootstrap 的模拟比较慢，每组需要几分钟。）

设定 省份聚类 Wild bootstrap
30 省，12 个处理省 5.3% —
8 省，3 个处理省 6.0% 5.7%
20 省，2 个处理省 28.3% 0.0%
  • 8 个省、3 个处理省时，聚类标准误（用 $t(G-1)$ 分布）基本还能接受；
  • 20 个省但 只有 2 个处理省 时，聚类标准误的拒绝率高达 28%，即使总聚类数并不算少；
  • Wild cluster bootstrap 在 3 个处理省时表现良好，但在只有 2 个处理省时又走向了另一个极端——几乎从不拒绝（过于保守）。这与 MacKinnon 和 Webb（2017, 2018）的理论结果一致：处理聚类极少时，没有哪种基于聚类的方法是完美的。

Wild Cluster Bootstrap

Wild cluster bootstrap 是目前少聚类情况下最常用的推断方法（Cameron、Gelbach 和 Miller，2008）。它的基本步骤（以施加原假设的 WCR 版本为例）：

  1. 在原假设 $H_0: \tau = 0$ 下估计受约束模型，得到残差 $\tilde u_{it}$；
  2. 对每个聚类 $g$ 独立抽取一个随机权重 $v_g$（Rademacher 分布：以各 1/2 的概率取 ±1；或 Webb 的 6 点分布）；
  3. 构造自助样本 $y^*_{it} = \tilde{y}{it} + v_g \tilde{u}{it}$，同一聚类内所有观测使用同一个权重，从而保留聚类内的相关结构；
  4. 用自助样本重新估计，计算聚类 t 统计量 $t^*_b$；
  5. 重复 $B$ 次，p 值 = $|t^*_b| \geq |\hat{t}|$ 的比例。

聚类数很少时（少于 12 个左右），Rademacher 权重只能产生 $2^G$ 种不同的组合，推荐使用 Webb 权重。

看一个具体的例子：20 个省、2 个处理省，真实效应为 0：

df_few = sim(np.random.default_rng(12), P=20, n_treat=2)
fit = pf.feols("y ~ D | firm + year", data=df_few, vcov={"CRV1": "prov"})
print(fit.tidy().round(4))

wb = fit.wildboottest(param="D", reps=9999, seed=1, weights_type="webb")
print("wild bootstrap p 值:", round(float(wb["Pr(>|t|)"]), 4))
             Estimate  Std. Error  t value  Pr(>|t|)    2.5%   97.5%
Coefficient
D              0.8502      0.1958   4.3418    0.0004  0.4403   1.26
wild bootstrap p 值: 0.1649

聚类标准误给出 p = 0.0004，“高度显著”；wild bootstrap 给出 p = 0.165，不显著。真实效应是 0，聚类标准误在这里给出了一个假阳性结果。

随机化推断

另一种思路是第 07 篇介绍过的 随机化推断（randomization inference）。它不依赖于大样本近似，而是直接利用“处理是如何分配的”：

  • 原假设：政策对所有个体都没有效果（精确原假设）；
  • 在原假设下，任意交换处理组和对照组的标签，结果不应该改变；
  • 枚举（或随机抽取）所有可能的处理分配方式，计算每种分配下的估计值，构成原假设下的分布；
  • p 值 = 分布中绝对值不小于真实估计值的比例。

20 个省中选 2 个作为处理省，一共只有 $\binom{20}{2} = 190$ 种分配方式，可以全部枚举：

import itertools

treated = sorted(int(x) for x in df_few.loc[df_few.D == 1, "prov"].unique())
df_few["post"] = (df_few.year >= 5).astype(int)
obs = pf.feols("y ~ D | firm + year", data=df_few).coef()["D"]

null = []
for combo in itertools.combinations(range(20), 2):
    d = df_few.assign(fD=df_few.prov.isin(combo).astype(int) * df_few.post)
    null.append(pf.feols("y ~ fD | firm + year", data=d).coef()["fD"])
null = np.array(null)
p_ri = (np.abs(null) >= abs(obs) - 1e-12).mean()
print(f"真实处理省 {treated}，分配方式 {len(null)} 种，随机化推断 p 值 = {p_ri:.3f}")
真实处理省 [5, 11]，分配方式 190 种，随机化推断 p 值 = 0.068

随机化推断的 p 值为 0.068，同样没有在 5% 水平上拒绝原假设。

我们还用模拟检验了随机化推断在“20 省、2 个处理省”设定下的表现：300 次模拟中拒绝率为 3.0%，接近名义水平 5%（略保守是因为 p 值只能取 1/190 的整数倍）。

随机化推断的局限：

  • 它检验的是“对所有个体效应都为零”的 精确原假设，不是“平均效应为零”；
  • 它要求处理分配在聚类之间是 可交换的。如果处理省份和对照省份在规模、波动性上差异很大，可交换性可能不成立（Rokicki 等，2018）；
  • 处理聚类太少时，p 值的最小可能值受限。只有 1 个处理省、20 个省时，最小 p 值为 1/20 = 0.05，永远无法在 5% 水平以下拒绝。

实用指南

情形 建议
处理分配层级的聚类数较多（≥ 40 左右），处理组与对照组比较平衡 聚类到该层级，使用 $t(G-1)$ 分布
聚类数较少，或处理聚类较少（例如 < 10） 同时报告 wild cluster bootstrap（Webb 权重）和随机化推断
只有 1—2 个处理聚类 常规推断方法都不可靠，考虑合成控制法，或 Conley 和 Taber（2011）的方法；结论要非常谨慎
不确定聚类层级 选择更粗的层级通常更安全，但聚类数会减少；以处理分配层级为准

另外还有两点值得一提：

  • 双向聚类：如果担心同一年不同省之间也存在相关（比如全国性冲击在不同省份有不同影响），可以同时按省份和年份聚类（vcov={"CRV1": "prov+year"}）。但年份数通常很少，双向聚类不一定更好。
  • CR2 偏差修正：Bell 和 McCaffrey（2002）提出的 CR2 方差估计量配合 Imbens 和 Kolesár（2016）的自由度修正，在聚类数较少时比 CR1 表现更好。

Stata 代码对照

* 不同层级的聚类
reghdfe y D, absorb(firm year) vce(robust)          // 只处理异方差：不推荐
reghdfe y D, absorb(firm year) vce(cluster firm)    // 聚类到企业
reghdfe y D, absorb(firm year) vce(cluster prov)    // 聚类到省份（处理层级）
reghdfe y D, absorb(firm year) vce(cluster prov year)   // 双向聚类

* Wild cluster bootstrap（ssc install boottest）
reghdfe y D, absorb(firm year) vce(cluster prov)
boottest D, cluster(prov) reps(9999) weight(webb) seed(42)

* 随机化推断（ssc install ritest）
ritest treat _b[c.treat#c.post], reps(1000) cluster(prov) seed(42): ///
    reghdfe y c.treat#c.post, absorb(firm year) vce(cluster prov)

boottest 是 Roodman 等人（2019）开发的，速度极快，是 Stata 中做 wild bootstrap 的标准工具。

小结

  • DID 中处理变量和误差项都高度相关，普通标准误会严重低估不确定性，**假阳性率可能超过 60%**。
  • 聚类层级应与处理分配层级一致，它同时容纳了组内相关和序列相关。
  • 聚类标准误要求聚类数足够多，尤其是处理组的聚类数。只有少数几个处理聚类时，聚类标准误会过度拒绝。
  • 少聚类时应使用 wild cluster bootstrap（Webb 权重）和 随机化推断，并对结论保持谨慎。

到这里，“标准 DID”的内容就全部讲完了。下一篇进入近年来 DID 方法论最重要的话题：政策分批实施时，TWFE 为什么会出错。
