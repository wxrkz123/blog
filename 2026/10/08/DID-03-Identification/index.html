DID 从入门到精通（03）：2×2 DID 的识别——平行趋势与三个关键假设

DID DID基础
Econometrics
发布日期:   2026-10-08

上一篇用加减法算出了 DID。这一篇我们回答两个更根本的问题：DID 到底在估计什么？凭什么能估计出来？ 搞清楚这两点，后面所有的扩展（多期、交错、事件研究）都只是在这个框架上加东西。

本文是「DID 从入门到精通」系列第 03 篇，完整路线见 系列导读。

一、设定

考虑最简单的情形：

  • 两个组：处理组 $D_i = 1$，对照组 $D_i = 0$；
  • 两个时期：$t = 1$（政策前），$t = 2$（政策后）；
  • 只有处理组在 $t = 2$ 受到政策影响。

每个个体在每期有两个潜在结果：$Y_{it}(1)$ 和 $Y_{it}(0)$。观测到的结果是：

$$Y_{it} = \begin{cases} Y_{it}(1), & D_i = 1 \text{ 且 } t = 2 \\ Y_{it}(0), & \text{其他情况} \end{cases}$$

我们想估计的目标参数是 政策后处理组的平均处理效应：

$$\text{ATT} = E\left[Y_{i2}(1) - Y_{i2}(0) \mid D_i = 1\right]$$

其中 $E[Y_{i2}(1) \mid D_i = 1]$ 可以直接从数据中算出来（就是处理组政策后的均值），难点在于 $E[Y_{i2}(0) \mid D_i = 1]$——处理组如果没有受到政策影响，政策后会是什么样。这个反事实是观测不到的，DID 的全部任务就是合理地构造它。

二、三个识别假设

假设 1：无预期效应（No Anticipation）

$$Y_{i1}(1) = Y_{i1}(0) \quad \text{对处理组成立}$$

含义：政策实施之前，处理组的结果不受政策影响。这样，处理组在 $t=1$ 观测到的 $Y_{i1}$ 就是 $Y_{i1}(0)$。

什么时候会违背？当政策提前被宣布、人们提前调整行为时。比如：

  • 宣布明年开征房产税，今年就出现抛售潮；
  • 宣布下季度上调最低工资，企业提前裁员或提前涨薪；
  • 企业得知自己将被纳入某个试点名单，提前调整财务报表。

应对方法：把“处理开始时间”定义为 政策宣布时间 而不是实施时间，或者在事件研究中允许若干期的预期效应。

假设 2：平行趋势（Parallel Trends）

$$E\left[Y_{i2}(0) - Y_{i1}(0) \mid D_i = 1\right] = E\left[Y_{i2}(0) - Y_{i1}(0) \mid D_i = 0\right]$$

含义：如果没有政策，处理组和对照组的结果会以相同的幅度变化。

这是 DID 最核心的假设。注意它说的是 变化量 相同，而不是 水平 相同。处理组可以比对照组高很多或低很多，只要“没有政策时的增长幅度”一样就行。

假设 3：SUTVA（稳定单位处理值假设）

SUTVA 包含两层意思：

  1. 无溢出效应：一个个体的潜在结果不受其他个体是否受处理的影响。对照组不能被政策间接影响。
  2. 处理的一致性：处理组内部接受的“处理”是同一种东西，不存在多个版本。

什么时候会违背？

  • 某省实施环保限产，污染企业迁到隔壁省（对照组），对照组的污染上升——DID 会 高估 减排效果；
  • 某市开通高铁，周边城市的人口和资本被吸走——对照组受到负面影响；
  • 新泽西提高最低工资，部分工人跑到宾夕法尼亚找工作——对照组劳动力供给增加。

应对方法：选择地理上距离较远的对照组、剔除邻近地区作为稳健性检验，或者直接把溢出效应作为研究对象来估计。

三、证明：在这三个假设下，DID 估计的就是 ATT

DID 的总体版本（estimand）是：

$$\tau^{\text{DID}} = \left(E[Y_{i2} \mid D_i=1] - E[Y_{i1} \mid D_i=1]\right) - \left(E[Y_{i2} \mid D_i=0] - E[Y_{i1} \mid D_i=0]\right)$$

逐项代入潜在结果：

  • 处理组政策后观测到的是 $Y(1)$：$E[Y_{i2} \mid D_i=1] = E[Y_{i2}(1) \mid D_i=1]$；
  • 由 无预期效应，处理组政策前观测到的是 $Y(0)$：$E[Y_{i1} \mid D_i=1] = E[Y_{i1}(0) \mid D_i=1]$；
  • 对照组两期观测到的都是 $Y(0)$。

于是：

$$\tau^{\text{DID}} = E[Y_{i2}(1) - Y_{i1}(0) \mid D_i=1] - E[Y_{i2}(0) - Y_{i1}(0) \mid D_i=0]$$

在第一项中加一项、减一项 $E[Y_{i2}(0) \mid D_i=1]$：

$$\tau^{\text{DID}} = \underbrace{E[Y_{i2}(1) - Y_{i2}(0) \mid D_i=1]}_{\text{ATT}} + \underbrace{E[Y_{i2}(0) - Y_{i1}(0) \mid D_i=1] - E[Y_{i2}(0) - Y_{i1}(0) \mid D_i=0]}_{\text{趋势差异（平行趋势下为 0）}}$$

由 平行趋势，第二项为零，所以 $\tau^{\text{DID}} = \text{ATT}$。证毕。

这个推导非常重要，它清楚地告诉我们：

DID 估计值 = ATT + 两组在没有政策时的趋势差异。

如果平行趋势不成立，DID 的偏差 恰好等于 两组的趋势差。这和上一篇“简单均值差 = ATT + 选择偏差”是同一个结构，只不过 DID 把“水平上的选择偏差”换成了“趋势上的选择偏差”，后者通常小得多。

四、一张图看懂反事实

下面这张图用的是我们后面几篇会反复使用的模拟数据：30 个省份，其中 10 个省在 2018 年成为某项创新政策的试点，结果变量是企业的研发投入（百万元）。真实的政策效应设定为 2。

  • 蓝线：对照组（非试点省企业）从 14.15 涨到 17.26，涨了 3.11；
  • 橙色实线：处理组（试点省企业）从 17.75 涨到 22.59，涨了 4.84；
  • 橙色虚线：处理组的反事实——在平行趋势假设下，如果没有试点，处理组也应该涨 3.11，到达 20.86；
  • 实际值 22.59 与反事实 20.86 之间的距离就是 DID 估计值 1.73。

注意处理组和对照组在政策前就差了 3.6，这完全没关系——DID 不要求两组水平相同。

估计值 1.73 和真实值 2 之间的差距来自抽样误差：只有 10 个试点省，省份层面的随机冲击无法完全平均掉。第 04 篇会给出这个估计的标准误和置信区间，第 08 篇会专门讨论这种“处理组只有少数几个省”带来的推断问题。

五、平行趋势允许什么、不允许什么

允许的：

  • 两组在结果水平上有任意差异；
  • 存在不随时间变化的不可观测混淆因素（企业文化、地理位置、管理者能力……），只要它们对结果的影响不随时间变化；
  • 存在影响所有个体的共同时间冲击（宏观经济周期、全国性政策）。

不允许的：

  • 两组本来就有不同的增长趋势。比如东部沿海省份本来就比中西部增长快，如果试点恰好集中在东部，DID 会把“本来就更快的增长”算作政策效应。
  • 存在与处理相关的、随时间变化的混淆因素。比如试点省份同期还实施了另一项产业政策。
  • 阿申费尔特沉降（Ashenfelter’s Dip）。Ashenfelter（1978）发现，参加培训项目的人在参加前一段时间收入往往会异常下降（正是因为收入下降了才去参加培训）。用这个“低谷”作为基期，即使培训无效，收入也会因为均值回归而反弹，DID 会高估效果。
  • 政策选择基于对未来趋势的预期。如果地方政府恰恰选择了“预计未来增长会放缓”的地区实施扶持政策，平行趋势就被违背了。

六、平行趋势依赖于函数形式

一个经常被忽视的问题：平行趋势在水平值上成立，在对数值上通常就不成立，反之亦然。

举个例子。假设没有政策时，对照组收入从 10 涨到 12（涨 2，即 20%），处理组从 20 涨到 24（涨 4，也是 20%）：

  • 用 对数 衡量：两组都涨了约 18.2%（$\ln 1.2 \approx 0.182$），平行趋势成立；
  • 用 水平 衡量：对照组涨 2，处理组涨 4，平行趋势不成立。

所以选择用水平还是对数做 DID，不是一个无关紧要的技术细节，而是 在选择相信哪个版本的平行趋势。一般来说：

  • 如果你认为没有政策时两组会以 相同的百分比 增长，用对数；
  • 如果你认为会以 相同的绝对量 增长，用水平。

Roth 和 Sant’Anna（2023）严格证明了：除非处理组和对照组的潜在结果分布满足很强的条件（例如处理是随机分配的），否则平行趋势不可能对所有单调变换同时成立。

七、平行趋势无法被检验

平行趋势说的是 政策后 处理组的反事实变化，这个反事实永远观测不到，因此平行趋势 本身无法被检验。

我们能做的只是检验它的一个“可观测的推论”：如果政策前若干期两组的趋势是平行的，那么政策后继续平行的可信度就更高。 这就是后面第 06 篇要讲的事件研究和“平行趋势检验”。但要记住，政策前趋势平行 既不是平行趋势的必要条件，也不是充分条件——第 11 篇会专门讨论这种检验的局限。

八、DID 的回归表达

实践中，我们几乎总是用回归来做 DID，因为回归能顺便给出标准误、方便加入控制变量。最基本的回归是：

$$Y_{it} = \beta_0 + \beta_1 \, \text{Treat}_i + \beta_2 \, \text{Post}_t + \beta_3 \, (\text{Treat}_i \times \text{Post}_t) + \varepsilon_{it}$$

其中 $\text{Treat}_i$ 表示是否属于处理组，$\text{Post}_t$ 表示是否为政策后时期。

这个回归包含四个参数，而数据正好有四个格子，所以它是一个 饱和模型，四个系数和四个格子均值一一对应：

$\text{Post}=0$ $\text{Post}=1$
$\text{Treat}=0$ $\beta_0$ $\beta_0 + \beta_2$
$\text{Treat}=1$ $\beta_0 + \beta_1$ $\beta_0 + \beta_1 + \beta_2 + \beta_3$

把这四个格子代入 DID 公式：

$$\left[(\beta_0 + \beta_1 + \beta_2 + \beta_3) - (\beta_0 + \beta_1)\right] - \left[(\beta_0 + \beta_2) - \beta_0\right] = \beta_3$$

交互项系数 $\beta_3$ 就是 DID 估计值，与四格表手算的结果完全相同。其他系数的含义：

  • $\beta_0$：对照组政策前的均值；
  • $\beta_1$：政策前两组的水平差异（选择偏差的体现）；
  • $\beta_2$：对照组的前后变化（共同时间趋势）。

在面板数据中，我们还可以写成 双向固定效应（TWFE）的形式：

$$Y_{it} = \alpha_i + \lambda_t + \tau D_{it} + \varepsilon_{it}, \qquad D_{it} = \text{Treat}_i \times \text{Post}_t$$

个体固定效应 $\alpha_i$ 比 $\beta_0 + \beta_1 \text{Treat}_i$ 更灵活（每个个体都有自己的截距），时间固定效应 $\lambda_t$ 吸收了 $\beta_2 \text{Post}_t$。在 2×2 的平衡面板中，$\hat{\tau}$ 与 $\hat{\beta}_3$ 在数值上完全相同。这个 TWFE 形式会在第 05 篇推广到多期，也会在第 09 篇暴露出它的问题。

小结

  • DID 的目标参数是 ATT，关键是构造处理组的反事实 $E[Y_{i2}(0) \mid D_i=1]$。
  • 三个识别假设：无预期效应、平行趋势、SUTVA。
  • DID 估计值 = ATT + 两组的趋势差异；平行趋势不成立时，偏差等于趋势差。
  • 平行趋势只要求“变化量相同”，不要求“水平相同”；但它依赖于函数形式（水平 vs 对数）。
  • 平行趋势本身无法检验，只能通过政策前的趋势间接评估其可信度。
  • 回归 $Y = \beta_0 + \beta_1 \text{Treat} + \beta_2 \text{Post} + \beta_3 \text{Treat} \times \text{Post}$ 中的 $\beta_3$ 就是 DID。

练习

  1. 仿照本文的证明推导：如果无预期效应不成立，即 $Y_{i1}(1) \neq Y_{i1}(0)$，DID 估计值等于什么？偏误的方向取决于什么？
  2. 构造一个数值例子，使平行趋势在水平值上成立、在对数值上不成立，分别计算两种 DID 并解释差异。
  3. 用第 04 篇的数据跑回归 y ~ treat * post，逐一验证四个系数与四个格子均值之间的对应关系。
  4. 设想一个可能出现“阿申费尔特沉降”的实际场景，说明它会让 DID 高估还是低估，以及如何在数据中发现它。
