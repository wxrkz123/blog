DID 从入门到精通（01）：因果推断基础——潜在结果与选择偏差

DID 计量经济学 因果推断
Econometrics
发布日期:   2026-10-08

在正式进入 DID 之前，我们需要先回答一个更基本的问题：什么叫“因果效应”？为什么直接比较两组人的平均值不行？ 这一篇介绍因果推断中最常用的语言——潜在结果框架（Potential Outcomes Framework，也叫 Rubin 因果模型）。后面所有关于 DID 的讨论，都会用这套语言来表述。

一个看起来很有说服力的统计

假设某地政府推出了一个免费的职业技能培训项目，一年后你拿到了数据：

  • 参加培训的人，平均年收入 60.9 千元；
  • 没参加培训的人，平均年收入 46.6 千元。

差了约 14.3 千元，能说“培训让收入提高了 14.3 千元”吗？

稍微想一想就会发现问题：主动报名培训的人，可能本来就更有上进心、学习能力更强。即使没有这个培训，他们的收入也可能更高。我们看到的 14.3 千元里，有多少是培训的功劳，有多少是“本来就不一样”？

要把这件事说清楚，需要一套严格的语言。

潜在结果：每个人都有两个“平行世界”

对每个人 $i$，设想两种状态：

  • $Y_i(1)$：如果 $i$ 参加培训，他的收入是多少；
  • $Y_i(0)$：如果 $i$ 不参加培训，他的收入是多少。

这两个量叫作 潜在结果（potential outcomes）。对个体 $i$ 来说，培训的 因果效应 定义为：

$$
\tau_i = Y_i(1) - Y_i(0)
$$

问题在于：任何一个人，我们只能观测到其中一个潜在结果。参加了培训的人，我们看不到他“没参加”时的收入；没参加的人，我们看不到他“参加了”会怎样。用 $D_i \in {0, 1}$ 表示是否参加，我们实际观测到的是：

$$
Y_i = D_i , Y_i(1) + (1 - D_i) , Y_i(0)
$$

这就是 Holland（1986）所说的 因果推断的根本问题（Fundamental Problem of Causal Inference）：个体层面的因果效应永远无法直接观测。因果推断的全部工作，本质上都是在 想办法合理地“填补”那个看不到的潜在结果，这个看不到的结果叫作 反事实（counterfactual）。

我们关心的几个平均效应

既然个体效应看不到，我们退而求其次，关心群体的平均效应：

平均处理效应（ATE）——如果让所有人都参加培训，平均能提高多少：

$$
\text{ATE} = E[Y_i(1) - Y_i(0)]
$$

处理组的平均处理效应（ATT）——对那些实际参加了培训的人来说，培训平均带来了多少：

$$
\text{ATT} = E[Y_i(1) - Y_i(0) \mid D_i = 1]
$$

在政策评估里，ATT 往往是更自然的问题：“这项政策对 受到政策影响的 那些地区/企业，到底起了多大作用？”DID 识别的正是 ATT，这一点后面会反复出现。

简单均值对比 = ATT + 选择偏差

现在回到那个 14.3 千元。简单均值对比是：

$$
E[Y_i \mid D_i = 1] - E[Y_i \mid D_i = 0]
$$

利用观测规则，处理组观测到的是 $Y(1)$，对照组观测到的是 $Y(0)$：

$$
= E[Y_i(1) \mid D_i = 1] - E[Y_i(0) \mid D_i = 0]
$$

在中间加一项再减一项 $E[Y_i(0) \mid D_i = 1]$（处理组 如果没参加 时的平均收入，这是一个看不到的反事实）：

$$
= \underbrace{E[Y_i(1) - Y_i(0) \mid D_i = 1]}{\text{ATT}} ; + ; \underbrace{E[Y_i(0) \mid D_i = 1] - E[Y_i(0) \mid D_i = 0]}{\text{选择偏差}}
$$

这是因果推断里最重要的一个等式。它告诉我们：

简单均值差 = 真正的处理效应 + 两组人“本来就不一样”的部分。

选择偏差的含义很具体：即使都不参加培训，参加者和不参加者的收入本来就差多少。如果有能力的人更倾向于报名，这一项就是正的，简单对比会 高估 培训效果。

用模拟数据亲眼看看选择偏差

模拟的好处是：我们可以“上帝视角”同时生成两个潜在结果，从而知道真实答案。

import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
n = 10_000
ability = rng.normal(0, 1, n)                     # 不可观测的能力
y0 = 50 + 8 * ability + rng.normal(0, 5, n)      # 不参加培训时的收入（千元）
tau = 5                                          # 培训的真实效果
y1 = y0 + tau
# 能力越高越倾向于参加培训（自选择）
d = (ability + rng.normal(0, 1, n) > 0.5).astype(int)
y = np.where(d == 1, y1, y0)                     # 现实中只能看到其中一个
df = pd.DataFrame({"D": d, "Y": y, "Y0": y0, "Y1": y1})

naive = df.loc[df.D == 1, "Y"].mean() - df.loc[df.D == 0, "Y"].mean()
att = (df.Y1 - df.Y0)[df.D == 1].mean()
sel = df.loc[df.D == 1, "Y0"].mean() - df.loc[df.D == 0, "Y0"].mean()
print(f"处理组比例: {df.D.mean():.3f}")
print(f"朴素均值差: {naive:.2f}")
print(f"真实 ATT : {att:.2f}")
print(f"选择偏差  : {sel:.2f}")
print(f"ATT + 偏差: {att + sel:.2f}")

输出：

处理组比例: 0.363
朴素均值差: 14.29
真实 ATT : 5.00
选择偏差  : 9.29
ATT + 偏差: 14.29

培训真实效果只有 5 千元，但简单对比得到 14.29 千元——将近三分之二是选择偏差。而且注意：在真实数据里，你只有 D 和 Y 两列，Y0、Y1 是看不到的，你根本没法算出这 9.29 的偏差有多大。

怎样消除选择偏差？几条思路

既然问题出在“两组人本来就不一样”，消除偏差就有几种策略：

1. 随机实验（RCT）。如果是否参加培训由抛硬币决定，那么 $D$ 和潜在结果独立，$E[Y(0) \mid D=1] = E[Y(0) \mid D=0]$，选择偏差为零。这是因果推断的“黄金标准”，但在政策评估中往往不可行——你不能随机决定哪个省实施新税法。

2. 控制可观测变量（回归、匹配）。如果能观测到所有影响参与决策和结果的变量（比如能力），就可以在“能力相同”的人之间比较。问题是，能力、偏好、企业家精神这些东西通常 观测不到。

3. 利用时间维度：前后对比。看同一批人参加培训前后的收入变化。这消除了“人与人之间固定不变的差异”（能力高的人一直高），但又引入了新问题：这一年里收入本来就会涨（经济增长、物价上涨、工作经验积累），你没法区分是培训的作用还是时间的作用。

4. 双重差分（DID）。把 2 和 3 结合起来：

  • 用 前后对比 消除个体间固定不变的差异；
  • 再用 对照组的前后变化 扣掉同期共同的时间趋势。

两次相减，所以叫“双重差分”。它不要求两组人一样（允许参加者能力更高），只要求 如果没有培训，两组人的收入会以相同的速度变化——这就是大名鼎鼎的 平行趋势假设。

5. 其他准实验方法：工具变量（IV）、断点回归（RDD）、合成控制法（SCM）等，各有适用场景，本系列不展开。

一张对比表

方法 消除了什么 依赖什么假设
截面对比（处理组 vs 对照组） 共同时间趋势 两组本来一样（无选择偏差）
前后对比（处理组自己） 个体固定差异 没有时间趋势
双重差分 个体固定差异 + 共同时间趋势 平行趋势

DID 的优势在于：它的假设比前两种 弱得多。两组人可以在水平上差很多，世界可以一直在变，只要“变化的速度”一样就行。

小结

  • 个体因果效应 $Y_i(1) - Y_i(0)$ 永远无法直接观测，因果推断的核心是构造可信的 反事实。
  • 简单均值对比 = ATT + 选择偏差。只要两组人“本来就不一样”，简单对比就是有偏的。
  • DID 同时利用个体维度和时间维度，在 平行趋势 假设下识别 ATT。
