DID 从入门到精通（09）：交错 DID 的陷阱——Goodman-Bacon 分解与负权重

DID 计量经济学 因果推断 Python Stata 交错DID
Econometrics
发布日期:   2026-10-08

到目前为止，我们讨论的都是 所有处理组同时接受处理 的情形。但现实中的政策常常是 分批推开 的：

  • 低碳城市试点：2010 年第一批、2012 年第二批、2017 年第三批；
  • 自由贸易试验区：2013 年上海，2015 年广东、天津、福建，2017 年再增 7 个……；
  • 美国各州在不同年份通过各自的最低工资法、医保扩张、大麻合法化。

这种设计叫作 交错 DID（staggered DID）或 多时点 DID。过去几十年，研究者的标准做法是直接跑双向固定效应回归：

$$
Y_{it} = \alpha_i + \lambda_t + \tau D_{it} + \varepsilon_{it}
$$

其中 $D_{it}$ 表示个体 $i$ 在 $t$ 期是否已经接受处理。大家默认 $\hat\tau$ 是“平均处理效应”。2018 年以后的一系列论文证明：这个默认是错的。当处理效应在不同批次之间或随时间变化时，$\hat\tau$ 可能远离任何有意义的平均效应，甚至符号相反。

记号

  • $G_i$：个体 $i$ 首次接受处理的时期（处理批次，cohort）。从未接受处理的个体记 $G_i = \infty$（代码中记为 0）。
  • 处理是 吸收型 的：一旦接受处理，之后一直处于处理状态，$D_{it} = \mathbb{1}[t \geq G_i]$。
  • $\text{ATT}(g, t) = E[Y_t(g) - Y_t(\infty) \mid G = g]$：第 $g$ 批在 $t$ 期的平均处理效应。这是交错 DID 中最基本的“积木”。
  • 相对时间 $e = t - g$。

模拟数据

import numpy as np
import pandas as pd
import pyfixest as pf

def make_staggered(seed=1, cohorts={2013: 0.3, 2016: 0.3, 0: 0.4}, effect="dynamic",
                   n=1200, years=range(2010, 2020), noise=1.0):
    """cohorts: {首次处理年份: 占比}，0 表示从未处理。
    effect: 'const' 常数效应 2；'dynamic' 处理当年为 1、之后每年 +0.6；
            'hetero' 早批效应 4、晚批效应 1；'dyn_het' 动态且批次间不同"""
    rng = np.random.default_rng(seed)
    years = np.array(list(years))
    g = rng.choice(list(cohorts), size=n, p=list(cohorts.values()))
    alpha = rng.normal(0, 2, n) + 0.5 * (g == 2013) - 0.5 * (g == 2016)
    lam = dict(zip(years, np.cumsum(rng.normal(0.3, 0.5, len(years)))))
    rows = []
    for t in years:
        e = np.where(g > 0, t - g, -999)
        treated = (g > 0) & (t >= g)
        if effect == "const":
            tau = np.where(treated, 2.0, 0.0)
        elif effect == "dynamic":
            tau = np.where(treated, 1.0 + 0.6 * e, 0.0)
        elif effect == "dyn_het":
            tau = np.where(treated, np.where(g == 2013, 1.5 + 0.8 * e, 0.5 + 0.3 * e), 0.0)
        elif effect == "hetero":
            tau = np.where(treated, np.where(g == 2013, 4.0, 1.0), 0.0)
        y = alpha + lam[t] + tau + rng.normal(0, noise, n)
        rows.append(pd.DataFrame({"id": np.arange(n), "year": t, "g": g, "D": treated.astype(int),
                                  "rel": e, "tau": tau, "y": y}))
    return pd.concat(rows, ignore_index=True)

默认设定：1200 个个体，2010—2019 年；30% 在 2013 年接受处理（早批），30% 在 2016 年接受处理（晚批），40% 从未接受处理。注意 平行趋势和无预期效应都严格成立，唯一变化的是处理效应的形式。

TWFE 什么时候对、什么时候错

for eff in ["const", "dynamic", "hetero"]:
    df = make_staggered(effect=eff)
    b = pf.feols("y ~ D | id + year", data=df, vcov={"CRV1": "id"}).coef()["D"]
    att = df.loc[df.D == 1, "tau"].mean()
    print(f"{eff:8s} TWFE={b:.3f}  真实ATT(处理后单元平均)={att:.3f}")
const    TWFE=1.993  真实ATT(处理后单元平均)=2.000
dynamic  TWFE=1.874  真实ATT(处理后单元平均)=2.470
hetero   TWFE=2.358  真实ATT(处理后单元平均)=2.901

这里的“真实 ATT”是所有处理后观测的处理效应的简单平均，也就是我们直觉上希望 TWFE 估计的东西。

  • 常数效应：TWFE 几乎完美（1.993 vs 2.000）；
  • 动态效应（效应随处理时间增长）：TWFE 低估了 24%；
  • 批次异质效应（早批效应大、晚批效应小）：TWFE 低估了 19%。

样本量很大、噪声很小，这些差距 不是抽样误差，而是 TWFE 估计量本身的偏误。为了看清问题出在哪，需要把 TWFE 拆开。

Goodman-Bacon 分解

Goodman-Bacon（2021）证明：在平衡面板、吸收型二元处理的情况下，TWFE 估计量是数据中所有 2×2 DID 比较的加权平均。以我们的三组数据（早批 $E$、晚批 $L$、从未处理 $U$）为例，一共有三类比较：

比较类型 处理组 对照组 时间窗口
① 处理组 vs 从未处理组 $E$ 或 $L$ $U$ 全部年份
② 早批 vs 晚批（晚批作对照） $E$ $L$（尚未处理） $L$ 处理之前
③ 晚批 vs 早批（早批作对照） $L$ $E$（已经处理） $E$ 处理之后

第 ① 类和第 ② 类都是“干净”的比较：对照组在比较窗口内没有接受处理。第 ③ 类是问题所在：它用 已经接受处理 的早批作为晚批的对照组。

为什么这是问题？在窗口内，早批一直处于处理状态，它的结果变化 = 共同时间趋势 + 早批处理效应的变化。如果处理效应是常数，后一项为零，用早批作对照没问题；但如果早批的处理效应在逐年增长，这个增长就会被当成“共同趋势”从晚批的变化中减掉，导致第 ③ 类比较的估计值偏低，甚至为负。

Goodman-Bacon 把这类比较称为“被禁止的比较”（forbidden comparison）。

权重从何而来

每个 2×2 比较的权重取决于两个因素：

  1. 参与比较的两组的 样本量；
  2. 两组处理变量在比较窗口内的 方差——处理状态在窗口中间切换的比较权重最大，在窗口边缘切换的权重小。

一个重要推论是：在样本期中间附近接受处理的批次，获得的权重最大。这与政策重要性或经济意义毫无关系，纯粹是方差最小化的副产品。

手写分解

下面的函数实现了 Goodman-Bacon（2021）的分解公式（平衡面板，吸收型处理，可包含从未处理组）：

def twfe_resid_D(df):
    """平衡面板下 D 的双向去均值残差"""
    D = df.D
    return D - df.groupby("id").D.transform("mean") - df.groupby("year").D.transform("mean") + D.mean()

def bacon(df, y="y"):
    years = np.sort(df.year.unique())
    N = df.id.nunique()
    sizes = df.groupby("g").id.nunique() / N                       # 各组样本占比
    Dbar = {k: (years >= k).mean() for k in sizes.index if k != 0} # 各批次处于处理状态的时期占比
    VD = (twfe_resid_D(df) ** 2).mean()                            # 去均值后 D 的方差
    gm = df.groupby(["g", "year"])[y].mean().unstack()

    def did(kt, kc, pre, post):
        return ((gm.loc[kt, post].mean() - gm.loc[kt, pre].mean())
                - (gm.loc[kc, post].mean() - gm.loc[kc, pre].mean()))

    out, timing = [], sorted(Dbar)
    for k in timing:                                  # ① 处理组 vs 从未处理组
        if 0 in sizes.index:
            nk, nu = sizes[k], sizes[0]; nku = nk / (nk + nu)
            s = (nk + nu) ** 2 * nku * (1 - nku) * Dbar[k] * (1 - Dbar[k]) / VD
            out.append(("处理组 vs 从未处理组", k, 0, did(k, 0, years[years < k], years[years >= k]), s))
    for i, k in enumerate(timing):                    # k 为早批，l 为晚批
        for l in timing[i + 1:]:
            nk, nl = sizes[k], sizes[l]; nkl = nk / (nk + nl); Dk, Dl = Dbar[k], Dbar[l]
            s_k = (((nk + nl) * (1 - Dl)) ** 2 * nkl * (1 - nkl)
                   * ((Dk - Dl) / (1 - Dl)) * ((1 - Dk) / (1 - Dl)) / VD)
            s_l = (((nk + nl) * Dk) ** 2 * nkl * (1 - nkl)
                   * (Dl / Dk) * ((Dk - Dl) / Dk) / VD)
            win = years[years < l]                    # ② 早批 vs 晚批：晚批处理之前
            out.append(("早处理组 vs 晚处理组（晚组作对照）", k, l, did(k, l, win[win < k], win[win >= k]), s_k))
            win = years[years >= k]                   # ③ 晚批 vs 早批：早批处理之后
            out.append(("晚处理组 vs 早处理组（早组作对照）", l, k, did(l, k, win[win < l], win[win >= l]), s_l))
    return pd.DataFrame(out, columns=["type", "treated", "control", "estimate", "weight"])

加权平均 精确等于 TWFE 估计值 1.8743，验证了分解的正确性。

逐行解读：

  • 第 0、1 行：两个批次分别与从未处理组比较，估计值 2.86 和 1.84 都是正的、合理的（早批被观察的处理后时间更长，动态效应累积更多，所以更大）。这两类比较共占 75% 的权重。
  • 第 2 行：早批 vs 晚批（窗口为 2010—2015，晚批尚未处理），估计值 1.66，也是合理的。
  • 第 3 行：晚批 vs 早批（窗口为 2013—2019，早批已经处理），估计值 −0.271。所有个体的真实处理效应都是正的，这个比较却给出负数——因为早批的效应在 2016 年后继续增长（从 2.8 增长到 4.6），这个增长被当作“共同趋势”从晚批的变化中扣掉了。

正是这 14.3% 权重的负估计值，把 TWFE 拉低到 1.87。

极端情形：没有从未处理组

当所有个体最终都接受处理（没有从未处理组）时，问题会更严重。假设一半个体在 2012 年、另一半在 2016 年接受处理：

df2 = make_staggered(cohorts={2012: 0.5, 2016: 0.5}, effect="dynamic", seed=2)
b2 = pf.feols("y ~ D | id + year", data=df2, vcov={"CRV1": "id"}).coef()["D"]
print("TWFE:", round(b2, 3), "  真实 ATT:", round(df2.loc[df2.D == 1, "tau"].mean(), 3))
print(bacon(df2).round(3).to_string())

真实平均效应为 2.70，TWFE 只有 0.32，偏误接近 90%。分解显示，“被禁止的比较”拿到了 三分之二的权重，而且它的估计值是负的。如果效应增长得更快，TWFE 完全可能给出 负的、显著的 估计——政策明明对每个人都有正效应，回归却告诉你政策有害。

另一个视角：负权重

de Chaisemartin 和 D’Haultfœuille（2020）从另一个角度刻画了同一个问题。他们证明，在平行趋势下：

$$
\hat\tau_{\text{TWFE}} \xrightarrow{p} \sum_{(g,t):, t \geq g} w_{g,t} \cdot \text{ATT}(g,t), \qquad w_{g,t} \propto \sum_{i \in g} \ddot{D}_{it}
$$

其中 $\ddot{D}{it}$ 是第 05 篇中 $D{it}$ 的双向去均值残差。权重之和为 1，但 某些权重可能是负的。

for name, d in [("有从未处理组", df), ("无从未处理组", df2)]:
    d = d.copy()
    d["eps"] = twfe_resid_D(d)
    tr = d[d.D == 1]
    w = tr.eps / tr.eps.sum()                         # 每个处理后观测的权重
    cell = tr.assign(w=w).groupby(["g", "year"]).w.sum()
    print(f"{name}：负权重的 (g,t) 格子 {(cell < 0).sum()} / {len(cell)}，负权重之和 {cell[cell < 0].sum():.3f}")

print(cell.unstack().round(3))   # 无从未处理组时，每个 (g,t) 的权重

没有从未处理组时，早批在 2016 年之后的 4 个格子都是负权重（合计 −0.667）。直觉是：2016 年后早批被当成了晚批的对照组，它的处理效应越大，TWFE 估计值就越小。

负权重的含义很严重：即使 每一个 $\text{ATT}(g,t)$ 都是正的，加权和也可能是负的。TWFE 估计量甚至不满足“如果所有人的效应都为正，估计值也为正”这一最基本的要求。

在“有从未处理组”的数据中，这一次没有出现负权重，但权重分配仍然不均匀，也不等于各格子的样本占比，所以 TWFE 估计的仍然不是我们想要的 ATT。

事件研究版本的 TWFE 也有问题

你可能会想：既然静态 TWFE 有问题，那用第 06 篇的事件研究（把 $D_{it}$ 拆成相对时间虚拟变量）是不是就没事了？

Sun 和 Abraham（2021）证明：也不一定。当处理效应在不同批次之间存在异质性时，TWFE 事件研究中某一期的系数 $\hat\beta_k$ 会被 其他相对时期的效应“污染”，甚至会在平行趋势完全成立的情况下，制造出虚假的前期趋势。下一篇会用模拟数据清楚地展示这一点。

什么时候可以继续用 TWFE？

  • 所有处理组同时接受处理（非交错）：TWFE 没问题（第 05 篇）；
  • 处理效应在批次间和时间上都是常数：TWFE 没问题，但这个假设通常很难论证；
  • 存在大量从未处理的个体，且早批与晚批之间的比较权重很小：偏误可能不大，可以用 Bacon 分解诊断。

否则，应使用下一篇介绍的 异质性稳健估计量。在当前的审稿环境下，即使你最终坚持使用 TWFE，也几乎一定会被要求报告这些新估计量作为稳健性检验。

Stata 代码对照

* Goodman-Bacon 分解（ssc install bacondecomp），要求平衡面板
xtset id year
bacondecomp y D, ddetail

* de Chaisemartin & D'Haultfœuille 权重（ssc install twowayfeweights）
twowayfeweights y id year D, type(feTR)

twowayfeweights 会报告负权重的个数与总和，以及 TWFE 系数在“所有 ATT 同号”的情况下仍可能符号相反所需的最小异质性程度。

小结

  • 交错 DID 中，TWFE 估计量是所有 2×2 DID 的加权平均（Goodman-Bacon 分解），其中包括 用已处理组作为对照组 的“被禁止的比较”。
  • 当处理效应随时间变化或在批次间不同时，被禁止的比较会产生偏误；没有从未处理组时问题尤为严重。
  • 等价地，TWFE 是各 $\text{ATT}(g,t)$ 的加权平均，但 权重可能为负，导致估计值甚至可能与所有真实效应符号相反。
  • 平行趋势成立 不足以 保证 TWFE 给出有意义的估计，还需要处理效应同质。
