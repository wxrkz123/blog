DID 从入门到精通（00）：系列导读与学习路线

DID 计量经济学 因果推断
Econometrics
发布日期:   2026-10-08

这是「DID 从入门到精通」系列的导读篇。整个系列共 12 篇，从“相关不等于因果”这个最朴素的问题讲起，一路走到交错 DID、异质性稳健估计量、HonestDiD 敏感性分析这些近五年的前沿方法。目标不是背公式、套命令，而是让你真正理解 DID 在识别什么、凭什么能识别、什么时候会失效、失效了怎么办。

为什么要专门学 DID

打开任何一本经济学、金融学、管理学期刊，双重差分几乎都是出镜率最高的因果识别方法之一：

  • 某地实施最低工资上调，就业到底减少了没有？
  • “营改增”、研发费用加计扣除等税收政策，有没有提高企业投资和创新？
  • 某城市被列为低碳试点，当地企业的排放、生产率怎么变化？
  • 一家公司被纳入融资融券标的，它的股价信息效率有没有提高？

这类问题有一个共同结构：一部分个体在某个时点受到了政策冲击，另一部分没有。DID 的思路非常直观——用没有受冲击的那组“同期变化了多少”，去推算受冲击那组“如果没受冲击会变化多少”，两者之差就是政策效应。

但“直观”不等于“简单”。2018 年以后，计量经济学界对 DID 进行了一次大规模的反思：Goodman-Bacon、de Chaisemartin 与 D’Haultfœuille、Callaway 与 Sant’Anna、Sun 与 Abraham、Borusyak 等人陆续证明，在政策分批实施（交错 DID）且效应随时间或群体变化时，我们用了几十年的双向固定效应回归可能给出严重偏误甚至符号相反的结果。这意味着很多“标准做法”需要更新。本系列会把这一段方法论的演进完整讲清楚。

学习路线建议

如果你是完全的初学者：按顺序读 01 → 04，每篇的代码都亲手跑一遍。不需要一开始就理解所有公式，先把“四格表减法”这个直觉牢牢抓住。

**如果你已经会跑 reghdfe**：可以从 05 开始，重点看 06（事件研究的规范做法）和 08（标准误到底该聚类到哪一层）。

如果你在写论文、政策是分批实施的：直接读 09 和 10。如果你的回归是 reghdfe y treat_post, absorb(id year) 而政策实施时间不一样，那么这两篇对你来说是必读的。

前置知识

  • 统计学：期望、方差、条件期望、假设检验、置信区间。
  • 计量经济学：最小二乘回归、虚拟变量、交互项、标准误的含义。看过伍德里奇《计量经济学导论》前 7 章就足够。
  • 编程：会用 pandas 读写数据、会跑一个简单的回归即可。本博客的「Python 从入门到精通」系列可以作为补充。

代码与软件

系列中的代码 以 Python 为主、Stata 作对照。所有 Python 代码我都在本地跑通，文中给出的数字就是真实运行结果（使用模拟数据，固定了随机种子，你运行后应得到相同或非常接近的数字）。

Python 环境

pip install numpy pandas matplotlib statsmodels scikit-learn scipy
pip install linearmodels      # 面板数据模型
pip install pyfixest          # 高维固定效应回归，语法接近 R 的 fixest / Stata 的 reghdfe
pip install differences       # Callaway & Sant'Anna 估计量
pip install wildboottest      # wild cluster bootstrap（pyfixest 会调用）

本系列使用的版本：pandas 3.0、statsmodels 0.15、pyfixest 0.60、linearmodels 7.0、differences 0.3。

一个贯穿全系列的符号约定

为了避免在不同文章里来回切换记号，这里先统一一下：

符号 含义
$i$ 个体（企业、个人、城市……）
$t$ 时间（年、季度……）
$Y_{it}$ 个体 $i$ 在 $t$ 期的观测结果
$D_{it}$ 处理状态，受政策影响为 1，否则为 0
$Y_{it}(1),\ Y_{it}(0)$ 潜在结果：接受处理 / 不接受处理时的结果
$G_i$ 个体 $i$ 首次受处理的时期（“处理批次”或 cohort），从未处理记为 $\infty$ 或 0
$\tau$ 处理效应
ATT 处理组的平均处理效应（Average Treatment effect on the Treated）
