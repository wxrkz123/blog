DID 从入门到精通（10）：异质性稳健估计量——CS、SA、插补法、did2s 与 Stacked DID

DID DID高级
Econometrics
发布日期:   2026-10-08

上一篇我们看到，交错 DID 中 TWFE 的问题出在两个地方：用已处理组作对照，以及 由回归自动决定、可能为负的权重。这一篇介绍的所有新方法，本质上都遵循同一个思路：

本文是「DID 从入门到精通」系列第 10 篇，完整路线见 系列导读。

第一步，只用“干净”的对照组，估计每一个批次、每一期的处理效应 ；第二步，按照研究者明确指定的权重，把它们加总成想要的汇总指标。

不同方法的差别主要在于：用谁做对照组、怎么估计反事实、怎么加总。

一、数据：动态且批次异质的处理效应

使用第 09 篇的 make_staggered 函数，但让处理效应 既随时间增长、又在批次间不同：早批（2013 年）处理当年效应 1.5、之后每年 +0.8；晚批（2016 年）处理当年效应 0.5、之后每年 +0.3。平行趋势和无预期效应严格成立。

import numpy as np
import pandas as pd
import pyfixest as pf
# make_staggered 函数的定义见第 09 篇

df = make_staggered(effect="dyn_het")      # 2013 批 351 个、2016 批 355 个、从未处理 494 个
truth_e = df[df.D == 1].groupby("rel").tau.mean()
print("真实 ATT（处理后观测平均）:", round(df.loc[df.D == 1, "tau"].mean(), 3))
print("各批次真实效应:", df[df.D == 1].groupby("g").tau.mean().round(3).to_dict())
print("按相对时间的真实效应:", truth_e.round(3).to_dict())

注意按相对时间的真实效应在 处突然跳升：因为晚批只被观察到处理后第 3 年（2019 年）， 只有早批的数据，而早批效应更大。这是 样本构成变化，在解读事件研究图时要特别小心。

  • 静态 TWFE 为 1.71，而真实 ATT 为 2.82，**低估了 39%**；
  • 更糟糕的是 TWFE 事件研究： 的系数约为 0.8—0.95，看起来存在明显的 前期趋势。但我们知道平行趋势是严格成立的！这就是 Sun 和 Abraham（2021）指出的 污染问题：批次间效应异质时，TWFE 事件研究的每个系数都是不同批次、不同相对时期效应的混合，会把处理后的效应“漏”到处理前的系数里。

如果你在实际研究中看到了这样一张图，很可能会错误地认为平行趋势不成立而放弃研究。下面看新方法的表现。

二、方法一：Callaway 和 Sant’Anna（2021）

思路

CS 估计量直接估计每一个 。对批次 、时期 ，它就是一个 2×2 DID：

  • 处理组：批次 ；
  • 对照组 ：从未处理组（never-treated），或 在 期仍未处理的组（not-yet-treated）；
  • 基期：批次 处理前的最后一期 。

由于对照组在比较窗口内从未接受处理，完全避免了“被禁止的比较”。

得到所有 后，按需要加总：

  • 简单加总：所有处理后 按批次规模加权平均，对应“整体 ATT”；
  • 按相对时间加总（事件研究）：，权重为在相对时间 可观测的各批次的规模占比；
  • 按批次加总：每个批次处理后各期的平均效应；
  • 按日历时间加总：每个日历年份所有已处理批次的平均效应。

CS 方法还支持加入协变量（通过回归调整、逆概率加权或双重稳健方法，见第 11 篇），允许平行趋势只在控制协变量后成立。

用从未处理组还是尚未处理组？

  • 从未处理组：对照组固定，解释清晰；但要求从未处理组与处理组可比——永远不接受处理的个体可能本身就很特殊。
  • 尚未处理组：样本更多、更有效率，而且晚批与早批通常更相似；但要求 不存在预期效应（尚未处理的个体不会因为预期到将来要被处理而提前改变行为）。

如果没有从未处理组，只能用尚未处理组。

三、方法二：Sun 和 Abraham（2021）

思路

Sun-Abraham 估计量是对 TWFE 事件研究的直接修正，叫作 交互加权估计量（interaction-weighted estimator，IW）：

  1. 在回归中加入 批次 × 相对时间 的完全交互，而不是只有相对时间虚拟变量：

以从未处理组（或最后一个接受处理的批次）作为对照组。每个 就是一个干净的 。
2. 按各批次的样本占比加权，得到每个相对时间的效应：

Python 实现

sa = df.copy()
for c in (2013, 2016):
    sa[f"rel_{c}"] = np.where(sa.g == c, sa.rel, -1)     # 其他批次和从未处理组放进基期
f_sa = pf.feols("y ~ i(rel_2013, ref=-1) + i(rel_2016, ref=-1) | id + year",
                data=sa, vcov={"CRV1": "id"})
co = f_sa.coef()
shares = df[df.g > 0].groupby("g").id.nunique()

sa_e = {}
for e in range(-6, 7):
    parts, ws = [], []
    for c in (2013, 2016):
        name = f"rel_{c}::{e}"
        if name in co.index:
            parts.append(co[name]); ws.append(shares[c])
    sa_e[e] = 0.0 if e == -1 else float(np.average(parts, weights=ws))
print({k: round(v, 3) for k, v in sa_e.items()})
{-6: 0.101, -5: 0.142, -4: -0.01, -3: 0.103, -2: 0.058, -1: 0.0, 0: 1.083, 1: 1.573, 2: 2.137, 3: 2.74, 4: 4.833, 5: 5.525, 6: 6.346}

结果与 CS 的事件研究 完全相同。这不是巧合：当使用从未处理组作对照、不加协变量时，Sun-Abraham 估计量与 CS 估计量（universal 基期）在数值上等价。

在实际研究中，pyfixest 还提供了 pf.event_study(..., estimator="saturated")，可以直接估计饱和的批次 × 相对时间模型。

四、方法三：插补法（Borusyak、Jaravel 和 Spiess，2024）

思路

插补法（imputation）的逻辑极其直观：

  1. 只用未处理的观测（从未处理组的全部观测 + 处理组在处理之前的观测）估计双向固定效应模型：

  1. 用估计出的 插补 每个处理后观测的反事实 ；
  2. 每个处理后观测的效应估计为 ；
  3. 按需要加总（整体平均、按相对时间平均……）。

因为第一步完全没有用到处理后的观测，处理效应的任何异质性都不会污染反事实的估计。BJS 证明，在误差项同方差、无序列相关时，插补法是所有线性无偏估计量中 最有效 的。

Python 实现（手写）

untr = df[df.D == 0]                                       # 只用未处理的观测
m0 = pf.feols("y ~ 1 | id + year", data=untr)
fe = m0.fixef()
fid = {int(float(k)): v for k, v in fe["C(id)"].items()}
fyr = {int(float(k)): v for k, v in fe["C(year)"].items()}

tr = df[df.D == 1].copy()
tr["y0hat"] = tr.id.map(fid) + tr.year.map(fyr)            # 插补反事实
tr["tau_hat"] = tr.y - tr.y0hat
print("插补法 ATT:", round(tr.tau_hat.mean(), 3))
imp_e = tr.groupby("rel").tau_hat.mean()
print("插补法按相对时间:", imp_e.round(3).to_dict())
插补法 ATT: 2.837
插补法按相对时间: {0: 1.013, 1: 1.52, 2: 2.099, 3: 2.686, 4: 4.803, 5: 5.495, 6: 6.316}

整体 ATT 为 2.84，非常接近真实值 2.82。插补法和 CS 的结果略有不同，因为插补法用了 所有 处理前时期来估计个体固定效应（而 CS 只用 期作为基期），也用了尚未处理组的信息，因此通常更有效率；代价是它要求平行趋势在 所有 时期都成立，而 CS 只要求处理后的时期成立。

手写插补法很简单，但标准误的计算比较复杂（需要考虑第一步估计的不确定性）。实践中推荐使用 Stata 的 did_imputation 或下面的 did2s。

五、方法四：did2s（Gardner，2022）

Gardner 的两阶段 DID 与插补法在点估计上 完全相同，只是表达成两阶段回归的形式：

  1. 第一阶段：用未处理观测估计 和 ；
  2. 第二阶段：用 对处理变量回归（静态）或对相对时间虚拟变量回归（动态）。

pyfixest 内置了 did2s，并给出了考虑第一阶段估计误差的正确标准误：

d2 = df.assign(rel2=np.where(df.g > 0, df.rel, -1).astype(float))
g2 = pf.did2s(d2, yname="y", first_stage="~ 0 | id + year",
              second_stage="~ D", treatment="D", cluster="id")
print(g2.tidy().round(3))

六、方法五：Stacked DID

思路

Stacked DID（Cengiz 等，2019）的思路是“化交错为标准”：

  1. 对每个处理批次 ，构造一个 子实验（sub-experiment）：包含批次 的所有个体，以及在一个时间窗口（如 ）内 始终未被处理 的干净对照组；
  2. 把所有子实验的数据 堆叠 在一起；
  3. 用 子实验 × 个体 和 子实验 × 时间 固定效应跑 TWFE。

由于每个子实验内部都是一个标准的单一时点 DID，不存在“已处理组作对照”的问题。

stacks = []
for c in (2013, 2016):
    win = (df.year >= c - 3) & (df.year <= c + 3)
    s = df[win & ((df.g == c) | (df.g == 0))].copy()       # 本批次 + 从未处理组
    s["stk"] = c
    stacks.append(s)
st = pd.concat(stacks)
st["id_s"] = st.stk.astype(str) + "_" + st.id.astype(str)
st["yr_s"] = st.stk.astype(str) + "_" + st.year.astype(str)
st["Dst"] = ((st.g == st.stk) & (st.year >= st.stk)).astype(int)

fs = pf.feols("y ~ Dst | id_s + yr_s", data=st, vcov={"CRV1": "id"})
print("Stacked DID:", round(fs.coef()["Dst"], 3), "标准误", round(fs.se()["Dst"], 3))
Stacked DID: 1.832 标准误 0.041

1.83 看起来和真实 ATT 2.82 差了很多，但这 不是偏误，而是估计的目标不同：Stacked DID 只看每个批次处理后 0—3 年的效应。在这个窗口内，真实效应的平均值是 1.82，Stacked DID 估计得非常准确。

还要注意：传统 Stacked DID 隐含的权重取决于各子实验中处理组与对照组的样本比例。Wing、Freedman 和 Hollingsworth（2024）指出这可能导致估计量不等于任何“自然”的平均效应，并提出了加权的 Stacked DID 来修正。同一个对照个体出现在多个子实验中，所以标准误应在原始个体层面聚类（如上面代码所示）。

七、其他方法

  • de Chaisemartin 和 D’Haultfœuille（2020, 2024）：did_multiplegt_dyn 估计量，比较“状态发生变化的个体”与“状态未变化的个体”，可以处理 非吸收型处理（处理可以开开关关）和 非二元处理。目前主要有 Stata 和 R 实现。
  • Wooldridge（2021）扩展 TWFE（ETWFE）：在 TWFE 中加入完全的“批次 × 时间”交互项。他证明，经过这样的扩展，TWFE 也能给出与插补法相同的点估计。这说明问题不在于“TWFE”本身，而在于 模型设定过于严格（假设所有批次、所有时期的效应都相同）。Stata 中可用 jwdid 实现。

实践建议：

  1. 先画出处理时点分布：有多少批次？各批次多大？有没有从未处理组？（pyfixest 的 pf.panelview 可以画处理状态热力图。）
  2. 不要只报告 TWFE。至少报告一种异质性稳健估计量（CS 和插补法最常用），最好同时报告两种，并与 TWFE 对比。
  3. 明确你的估计目标：整体 ATT、动态效应、还是某个批次的效应？不同汇总方式回答不同的问题。
  4. 事件研究图要用新方法画，并注意样本构成随相对时间的变化（可以只报告所有批次都能观测到的相对时间区间，即 平衡事件时间）。
  5. 如果几种方法结果相近，说明 TWFE 的偏误不大，结论更可信；如果差异很大，应以新方法为准，并解释原因（通常是效应的动态或异质性）。

gen rel = year - g if g > 0
gen never = (g == 0)
forvalues k = 6(-1)2 {
    gen lead`k' = (rel == -`k')
}
forvalues k = 0/6 {
    gen lag`k' = (rel == `k')
}
eventstudyinteract y lead6-lead2 lag0-lag6, cohort(g) control_cohort(never) ///
    absorb(id year) vce(cluster id)

gen g_imp = g if g > 0                            // 从未处理组为缺失值

did2s y, first_stage(id year) second_stage(D) treatment(D) cluster(id)

did_multiplegt_dyn y id year D, effects(6) placebo(5) cluster(id)

小结

  • 异质性稳健估计量的共同思路：只用干净对照估计 ，再按明确的权重加总。
  • CS：逐个估计 ，对照组可选从未处理或尚未处理，支持协变量与双重稳健。
  • SA：在 TWFE 事件研究中加入批次 × 相对时间交互，再按批次规模加权。
  • 插补法 / did2s：用未处理观测估计反事实，效率最高，但要求所有时期平行趋势成立；处理前系数不能直接当作趋势检验。
  • Stacked DID：把交错设计拆成多个标准 DID 再堆叠，估计的是窗口内的效应。
  • TWFE 事件研究在批次异质时会产生 虚假的前期趋势，事件研究图应使用新方法绘制。

练习

  1. 在本文数据中加入一个 2018 年的第三批次，重新估计 CS（从未处理组、尚未处理组两种对照）与插补法，比较结果。
  2. 只保留所有批次都能观测到的相对时间（平衡事件时间，例如 ），重画事件研究图，并与全样本结果对比。
  3. 只用四个格子均值手算 CS 的 ，验证它与 differences 包的结果一致。
  4. 查阅 Wing、Freedman 和 Hollingsworth（2024），为本文的 Stacked DID 加上他们建议的权重，比较加权前后的估计值。
