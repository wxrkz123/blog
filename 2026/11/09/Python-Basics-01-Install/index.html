Python 零基础入门（01）：安装 Python，写出第一个程序

Python Python零基础
Python
发布日期:   2026-11-09

这一篇的目标很简单：在你的电脑上装好 Python，然后让电脑对你说一声“你好”。

先弄清楚：“安装 Python”是在装什么？

你写的 Python 代码，电脑本身是看不懂的。需要一个“翻译”把它翻译给电脑听，这个翻译程序就叫 Python 解释器。

“安装 Python”，就是把这个翻译请到你的电脑上。装好之后，你写的每一行代码，它都会帮你翻译并执行。

在 Windows 上安装

第 1 步：下载

  1. 打开 Python 官网的 Windows 下载页：https://www.python.org/downloads/windows/
  2. 找到最新的稳定版（Stable Releases）下面的 **Windows installer (64-bit)**，点击下载。

最近 Python 官方还推出了一个新工具 Python install manager（Python 安装管理器），下载页最上面可能会优先推荐它。两种方式都可以，本文以更直观的 Windows installer 为例。如果你下载的是安装管理器，装好后打开“命令提示符”，输入 py install 3.14 即可安装 Python 3.14。

第 2 步：安装（最重要的一步！）

双击下载好的安装程序，会出现一个窗口。先别急着点安装！ 请看窗口最下面：

  • ✅ **一定要勾选 Add python.exe to PATH**（把 Python 添加到环境变量）

然后再点击 Install Now（立即安装），等它装完，看到 “Setup was successful” 就可以关掉了。

为什么要勾选这个？ 不勾的话，你在命令行里输入 python，电脑会说“找不到这个命令”。这是新手安装失败最常见的原因。如果你已经装好了但忘了勾，最简单的办法是：重新运行安装程序，选择 Uninstall（卸载），再重新安装一次，这次记得勾上。

第 3 步：检查是否安装成功

  1. 按键盘上的 Win 键（键盘左下角有 Windows 图标的那个键），输入 cmd，回车。会打开一个黑色窗口，叫做命令提示符。
  2. 在里面输入下面这行，然后按回车：
python --version

如果看到类似这样的结果，就说明安装成功了（数字可能和这里不一样，没关系）：

Python 3.14.0

如果显示“不是内部或外部命令”，说明第 2 步没有勾选 Add python.exe to PATH，请按上面的方法重装。

如果弹出了 Microsoft Store（微软应用商店），也说明 Python 没有被正确添加到 PATH，同样重装一次即可。

在 Mac 上安装

  1. 打开 https://www.python.org/downloads/macos/，下载最新稳定版的 macOS 64-bit universal2 installer（文件名以 .pkg 结尾）。
  2. 双击安装，一路点“继续”即可。
  3. 打开“终端”（在启动台里搜索“终端”或 Terminal），输入：
python3 --version

看到 Python 3.x.x 就成功了。

Mac 用户注意：Mac 上的命令是 python3，不是 python。后面文章中凡是让你在命令行输入 python 的地方，你都要输入 python3。

第一种玩法：交互模式

装好之后，我们先来“和 Python 聊聊天”。

在命令提示符（Mac 是终端）里输入 python（Mac 输入 python3），回车。你会看到几行英文，最后一行是三个大于号：

>>>

这个 >>> 叫做提示符，意思是：“我准备好了，请输入代码”。这种模式叫做交互模式：你输入一行，Python 马上回答一行。

试着输入 1 + 1，回车：

>>> 1 + 1
2

Python 马上告诉你答案是 2。再试试：

>>> 100 * 3
300
>>> print("Hello, World!")
Hello, World!

注意：

  • >>> 是 Python 自己显示的，你不用输入它，只需要输入后面的内容；
  • 没有 >>> 的那一行，是 Python 给你的回答。

想退出交互模式，输入 exit() 然后回车，或者直接关掉窗口。

交互模式很适合做简单的试验，但它有个缺点：关掉窗口，代码就没了。要写真正的程序，我们需要把代码保存在文件里。

第二种玩法：用 IDLE 写程序

安装 Python 时，会顺便安装一个简单的代码编辑器，叫做 IDLE。我们用它来写第一个程序。

打开 IDLE

  • Windows：按 Win 键，输入 IDLE，点击出现的 “IDLE (Python 3.x)”。
  • Mac：打开“应用程序”文件夹，进入 “Python 3.x” 文件夹，双击 IDLE。

打开后看到的窗口里也有 >>>，这其实就是刚才的交互模式。

新建一个文件

  1. 点击菜单 File → New File，会打开一个新的空白窗口。
  2. 在这个新窗口里输入下面三行代码：
print("你好，世界！")
print("这是我的第一个 Python 程序")
print("1 + 2 =", 1 + 2)
  1. 点击 File → Save（或按 Ctrl + S），保存文件。建议在桌面上新建一个文件夹叫 python学习，把文件保存在里面，文件名叫 hello（IDLE 会自动加上 .py 后缀，变成 hello.py）。

.py 是 Python 代码文件的后缀名，就像 Word 文档是 .docx、图片是 .jpg 一样。

运行程序

点击菜单 Run → Run Module，或者直接按键盘上的 F5。

刚才那个带 >>> 的窗口会显示运行结果：

你好，世界！
这是我的第一个 Python 程序
1 + 2 = 3

🎉 恭喜你！你已经写出并运行了人生中的第一个程序！

理解这三行代码

  • print(...) 的意思是“把括号里的内容显示到屏幕上”。print 是英文“打印”的意思。
  • "你好，世界！" 两边的双引号，表示这是一段文字。Python 会原样显示引号里面的内容（引号本身不显示）。
  • 第三行 print("1 + 2 =", 1 + 2) 里，括号中有两样东西，用逗号隔开：
    • 第一样 "1 + 2 =" 带引号，是文字，原样显示；
    • 第二样 1 + 2 没有引号，是一个算式，Python 会先算出结果 3 再显示；
    • 两样东西之间，print 会自动加一个空格。

程序是从上往下，一行一行执行的。 所以屏幕上的三行结果，顺序和代码的顺序一致。

动手试试

在 hello.py 里继续添加几行，保存后按 F5 运行：

print("我的名字是：小明")
print("我今年", 18, "岁")
print("一天有", 24 * 60, "分钟")

运行结果：

我的名字是：小明
我今年 18 岁
一天有 1440 分钟

把“小明”换成你自己的名字，把 18 换成你的年龄，再运行一次吧。

关于编辑器：以后可以换成 VS Code

IDLE 简单、免安装，非常适合刚入门。等你学完前几篇、写的代码越来越多时，可以换成更强大的编辑器，最常用的是免费的 VS Code（https://code.visualstudio.com/），安装后再装一个名为 “Python” 的扩展即可。

不过现在不用着急，本系列用 IDLE 就完全够了。

新手常见错误

1. 用了中文的括号或引号

print（"你好"）      ← 错误：括号是中文的
print(“你好”)        ← 错误：引号是中文的
print("你好")        ← 正确

代码里的符号必须用英文输入法输入。引号里面的文字可以是中文，这没问题。

一个小技巧：写代码时把输入法切换到英文模式，只在需要输入中文文字时再切换。

2. 拼错了 print

Print("你好")    ← 错误：P 不能大写
pirnt("你好")    ← 错误：字母顺序错了

Python 是区分大小写的，print 必须全部小写。

3. 在命令提示符里直接写代码

如果你在黑色的命令提示符窗口（没有 >>> 的时候）里直接输入 print("你好")，会报错，因为那个窗口只认识系统命令，不认识 Python 代码。要先输入 python 进入交互模式（出现 >>>），或者用 IDLE。

4. 在交互模式里输入 python

反过来，如果已经在 >>> 后面了，再输入 python --version 也会出错。看清楚当前是在哪个窗口里：

  • 有 >>>：可以写 Python 代码；
  • 没有 >>>（显示类似 C:\Users\你的名字>）：只能输入系统命令，比如 python。

小结

  • 安装 Python 就是安装“翻译程序”（解释器），Windows 上安装时**一定要勾选 Add python.exe to PATH**。
  • 在命令行输入 python --version 可以检查是否安装成功。
  • 交互模式（>>>）：输入一行、执行一行，适合做小试验。
  • IDLE：新建文件 → 写代码 → 保存为 .py → 按 F5 运行。
  • print(...) 把括号里的内容显示到屏幕上；用逗号可以一次显示多样东西。
  • 代码里的符号必须是英文符号，print 必须小写。

练习

练习 1：写一个程序，运行后显示下面三行：

*
**
***
点击查看答案 
print("*")
print("**")
print("***")
*
**
***

练习 2：用 print 算出一年有多少小时（一年按 365 天算），显示成 一年有 8760 小时。

点击查看答案 
print("一年有", 365 * 24, "小时")
一年有 8760 小时

在 Python 里，乘号是 *（星号），不是 ×。下一篇会详细介绍。

练习 3：下面的代码有 3 处错误，你能找出来吗？

Print（"今天天气真好"）
点击查看答案
  1. Print 的 P 应该小写：print；
  2. 左括号 （ 是中文括号，应该是英文的 (；
  3. 右括号 ） 也是中文括号，应该是英文的 )。

正确写法：

print("今天天气真好")
今天天气真好
