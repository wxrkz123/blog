Java 基础（一）：从 C 到 Java——环境、语法与数组

编程 Java

文章字数:   2790 字

这是我学 Java 时整理的笔记，写给已经学过 C 语言的人，共三篇：

  1. 从 C 到 Java——环境、语法与数组（本篇）
  2. 面向对象（上）——类、对象与封装
  3. 面向对象（下）——继承、抽象类、接口与多态

学 Java 之前最好学过 C，至少学到结构体。指针、算法、数据结构掌握得不好也没关系，这几篇主要介绍基础，对 C 语言的要求不高。很多地方会和 C 对比着讲。

安装 JDK 和 IDE

写 Java 程序需要安装 JDK（Java Development Kit，Java 开发工具包）。建议安装长期支持（LTS）版本，例如 JDK 21，可以从 Oracle 或 Adoptium（免费的 OpenJDK 发行版）下载。Windows 下载 .msi 或 .exe 安装包，Mac 下载 .dmg 或 .pkg。

现在的安装包一般会自动配置好环境。如果命令行找不到 java，需要手动设置环境变量（以 Windows 为例）：

  • 新建系统变量 JAVA_HOME，值为 JDK 的安装路径，例如 C:\Program Files\Java\jdk-21；
  • 在系统变量 Path 中添加 %JAVA_HOME%\bin。

早期的教程还会让你设置 CLASSPATH，添加 dt.jar、tools.jar 和 jre\bin。从 JDK 9 开始这两个文件已经不存在了，JDK 11 起也不再有单独的 jre 目录，这些设置都不需要了。

安装完成后，打开命令行验证：

java -version
javac -version

写代码推荐使用 JetBrains 的 IntelliJ IDEA（社区版免费）。本文的截图来自 IntelliJ IDEA 2021。

Java 程序是怎样运行的

C 语言的源代码经过编译，直接生成某个平台（比如 Windows）上的可执行文件（.exe）。Java 则多了一层：源代码先被编译成字节码（.class 文件），再由 Java 虚拟机（JVM）执行。

Java C
编译结果 .class 字节码文件 平台相关的可执行文件（如 Windows 的 .exe）
运行条件 需要安装 Java 运行环境（JVM） 不需要额外的运行环境
跨平台 同一个 .class 文件可以在任何装有 JVM 的系统上运行 要在每个平台上分别编译

三个容易混淆的名词：

  • JVM（Java Virtual Machine）：Java 虚拟机，负责执行字节码；
  • JRE（Java Runtime Environment）：Java 运行环境，包括 JVM 和标准类库，只运行程序时需要；
  • JDK（Java Development Kit）：开发工具包，包括 JRE 和编译器 javac 等开发工具。写程序需要 JDK。

在命令行中编译和运行：

命令 作用
javac Main.java 把 Main.java 编译成 Main.class
java Main 运行 Main.class（不写扩展名）
java Main.java 直接运行单个源文件（JDK 11 起支持，内部先编译再运行）

项目结构与 package

package（包）相当于文件夹，用来组织 Java 代码。包名通常是公司域名倒过来写，比如 com.microsoft.demo，对应 src/com/microsoft/demo/ 这个目录。分包的目的是让代码结构清晰，便于维护和扩展，也避免不同人写的同名类发生冲突。

在 IntelliJ IDEA 中新建一个项目，会看到这些内容：

名称 作用
.idea 文件夹 项目的配置信息，由 IDE 自动维护
.iml 文件 模块文件，记录模块的路径、依赖等信息
src 文件夹 源代码（.java 文件）和配置文件都放在这里
out 文件夹 编译生成的 .class 文件
External Libraries 项目用到的外部库，包括 JDK 本身
Scratches and Consoles 临时文件，用来快速试验代码，不属于项目

项目视图中，默认会把只有一个子包的包合并显示（例如 com.microsoft.demo 显示成一行）：

在项目视图的设置（齿轮图标）中取消勾选 Compact Middle Packages，就会按层级逐级显示：

第一个程序

package com.microsoft.demo;          // 这个类所在的包，必须和文件所在的目录一致

// 公共类的类名必须和文件名相同（这里文件名是 Main.java），按惯例首字母大写
public class Main {

    // main 方法是程序的入口，写法是固定的
    public static void main(String[] args) {
        System.out.println("Hello");               // 打印一行
        int result = sum(1, 2);                    // 调用方法，和 C 里调用函数一样
        System.out.println("result = " + result);
    }

    // Java 里的“函数”叫方法，必须写在类里面
    public static int sum(int a, int b) {
        return a + b;
    }
}

运行结果：

Hello
result = 3

和 C 相比，最大的不同是：Java 的所有代码都必须写在类里面，即使只是一个 main 方法。类是什么，下一篇会详细讲。

IntelliJ IDEA 的两个常用技巧：

  • 输入 psvm 再按 Tab，自动生成 main 方法；输入 sout 再按 Tab，生成 System.out.println();；soutv 打印离光标最近的变量。
  • 写了一个方法调用（比如 sum(1, 2)），按 Ctrl + Alt + V，自动生成接收返回值的变量。

注释和文档

Java 有三种注释：

// 单行注释

/*
 * 多行注释
 */

/**
 * 文档注释：会被 javadoc 工具提取，生成 HTML 格式的 API 文档。
 * @param a 第一个加数
 * @param b 第二个加数
 * @return 两数之和
 */
public static int sum(int a, int b) {
    return a + b;
}

前两种和 C 一样。文档注释写在类和方法的前面，用 @param、@return 等标签说明参数和返回值。在 IntelliJ IDEA 中，把光标放在方法名上按 Ctrl + Q，就能看到它的文档注释。

字符串

C 语言没有专门的字符串类型，字符串就是以 '\0' 结尾的字符数组：

char a[3] = {'a', 'b', 'c'};          // 只是 3 个字符，没有 '\0'，不是合法的字符串
char b[] = {'a', 'b', 'c', '\0'};     // 字符串 "abc"
char c[] = "abc";                     // 同上，编译器自动在末尾加 '\0'

'\0' 是 C 判断字符串在哪里结束的唯一依据。如果忘了它，printf、strlen 这些函数会一直往后读，越界访问内存。

Java 有专门的字符串类 String：

String s1 = "Hello World!";
String s2 = new String("Hello World!");

System.out.println(s1.length());              // 长度：12
System.out.println(s1.concat(" Bye"));        // 连接：Hello World! Bye
System.out.println(s1 + " Bye");              // 用 + 连接，更常用
System.out.println(s1.equals(s2));            // 比较内容：true
System.out.println(s1 == s2);                 // 比较是不是同一个对象：false

Java 的字符串为什么不需要 '\0'？ 因为 String 对象自己记录了长度，不需要靠一个结束符来判断字符串在哪里结束。访问字符串时，Java 会检查下标是否越界，越界就抛出异常，而不会像 C 那样悄悄地读到别的内存。

注意最后两行：比较两个字符串的内容要用 equals，== 比较的是两个变量是否指向同一个对象。

类型转换

不同类型的数值一起运算时，会先自动转换成同一种类型，转换的方向是从“范围小”到“范围大”：

byte, short, char → int → long → float → double

这叫自动类型转换（隐式转换），不会丢失数据（long 转 float 可能损失精度）。反方向的转换需要强制类型转换，可能丢失数据：

int i = 100;
double d = i;              // 自动转换：100.0
double x = 3.99;
int j = (int) x;           // 强制转换：直接截掉小数部分，得到 3
System.out.println(7 / 2);         // 两个 int 相除，结果是 int：3
System.out.println(7 / 2.0);       // 有一个是 double，结果是 double：3.5

import 与 API 文档

import 的作用类似于 C 的 #include，用来使用其他包里的类：

import java.util.Arrays;       // 导入一个类
import java.util.*;            // 导入 java.util 包里的所有类

两种情况不需要 import：同一个包里的类；java.lang 包里的类（如 String、System、Math），它们会被自动导入。

常用的包：

包名 用途
java.lang 最基础的类：String、Math、System、包装类等，自动导入
java.util 工具类：集合（ArrayList、HashMap）、Arrays、Scanner、Random
java.io 输入输出：文件、数据流、序列化
java.math 高精度计算：BigInteger、BigDecimal
java.text 格式化文本、日期和数字
java.time 日期和时间（JDK 8 起）

完整的 API 文档见 Java SE 21 API 文档。

数组

Java 和 C 定义数组的方式对比：

方式 Java C
定义并初始化 int[] arr = {1, 2, 3}; int arr[] = {1, 2, 3};
指定长度 int[] arr = new int[5]; int arr[5];

Java 习惯把 [] 写在类型后面，表示“arr 的类型是 int 数组”。用 new 创建的数组，元素会自动初始化为 0（数值）、false（布尔）或 null（对象），不会像 C 的局部数组那样是随机值。

和 C 一样，数组的长度在创建后就固定了，不能扩容。需要可变长度时，用 java.util.ArrayList。

注意：数组的长度是 length 属性，不带括号；字符串的长度是 length() 方法，带括号。

String str = "abc";
int[] arr = {1, 2, 3};
System.out.println(str.length());   // 3
System.out.println(arr.length);     // 3

遍历数组可以用普通的 for 循环，也可以用增强 for 循环：

int[] scores = {90, 85, 77};

for (int i = 0; i < scores.length; i++) {      // 普通 for：i 是下标
    System.out.println(scores[i]);
}

for (int score : scores) {                      // 增强 for：score 依次是每个元素的值
    System.out.println(score);
}

增强 for 循环中的变量是元素本身，不是下标。写成 for (int i : scores) { System.out.println(scores[i]); } 是常见的错误：它会把元素值 90 当作下标，抛出数组越界异常。

Arrays 工具类

java.util.Arrays 提供了操作数组的常用方法：

import java.util.Arrays;

public class ArraysDemo {
    public static void main(String[] args) {
        int[] arr = {1, 2, 3, 6, 7, 8, 111, 1111, 112, 1235, 123};
        Arrays.sort(arr);                                  // 排序（从小到大）
        System.out.println(Arrays.toString(arr));          // 把数组转成字符串打印

        int index = Arrays.binarySearch(arr, 6);           // 二分查找，数组必须先排好序
        System.out.println("6 的下标是 " + index);

        int[] a = {1, 2, 3};
        int[] b = {1, 2, 3};
        System.out.println("a == b：" + (a == b));                 // 是不是同一个数组对象
        System.out.println("Arrays.equals：" + Arrays.equals(a, b)); // 元素是否依次相等
    }
}

运行结果：

[1, 2, 3, 6, 7, 8, 111, 112, 123, 1111, 1235]
6 的下标是 3
a == b：false
Arrays.equals：true

直接 System.out.println(arr) 打印的是数组对象的类型和哈希码（类似 [I@1b6d3586），要打印元素用 Arrays.toString。

方法与重载

Java 的方法相当于 C 的函数：一组语句的集合，完成一个功能。区别是方法必须定义在类里面。前面例子中的方法都带有 static，表示它属于类本身，可以直接调用；不带 static 的方法要通过对象调用，下一篇会讲。

C 语言里，两个函数不能同名。Java 允许重载（overload）：方法名相同，只要参数的个数或类型不同就可以。调用时，编译器根据参数自动选择合适的版本。

public class OverloadDemo {
    public static void main(String[] args) {
        int sum = sum(1, 2);
        double value = sum(1.2, 3.4);
        int sum3 = sum(1, 2, 3);
        System.out.println("sum = " + sum);
        System.out.println("value = " + value);
        System.out.println("sum3 = " + sum3);
    }

    public static int sum(int x, int y) {
        return x + y;
    }

    public static double sum(double x, double y) {
        return x + y;
    }

    public static int sum(int x, int y, int z) {
        return x + y + z;
    }
}

运行结果：

sum = 3
value = 4.6
sum3 = 6

只有返回值类型不同、参数完全相同的两个方法，不构成重载，编译会报错。

基础语法到这里就差不多了。Java 真正和 C 不同的地方是面向对象，下一篇从“类和对象”讲起。
