## 🛠️ 技术栈

- 静态站点生成：Hexo 6
- 主题：Matery（Material Design 风格、响应式）
- 托管：GitHub Pages
- 部署：GitHub Actions 自动构建（源码在本仓库的 `source` 分支）

## 📁 关于这个仓库

- **`main` 分支**：自动生成的静态网页，GitHub Pages 从这里发布。**请不要直接修改**，每次部署都会被覆盖。
- **`source` 分支**：博客的 Hexo 源码（文章、配置、主题）。修改并推送到这个分支后，GitHub Actions 会自动构建并发布到 `main`。
