关于这个网站

这里是外星人k总（wxrkz123）的个人博客，2021 年 3 月开通。开博客的初衷是把学编程时的笔记记下来、分享出去（第一篇文章里写了原因）。现在主要写四方面的内容：编程（Python、C、Java、数据结构）、计量经济学（回归分析、因果推断、时间序列与实证研究方法）、运筹优化，以及量化投资与金融数据分析。

专栏：成体系的系列教程

  • Python 零基础入门：写给完全没学过编程的人，每篇只讲一件事，最后做一个记账本小项目。
  • Python 从入门到精通：已经会写 Python，想弄懂对象模型、描述符、元类、asyncio 和性能优化。
  • 统计学基础：概率与推断：计量和机器学习的地基：分布、中心极限定理、标准误、置信区间与假设检验，重点讲清楚这些概念最容易被误解的地方，以及 p 值怎样被误用。
  • 计量经济学基础：回归分析：做实证研究的入门课：系数怎么解释、标准误怎么选、回归什么时候会出错。
  • 内生性：从诊断到识别：内生性的来源与偏误方向、固定效应的边界、敏感性分析、测量误差、“滞后一期”的误区、工具变量实务与 Bartik、近似外生、控制函数、匹配与熵平衡，以及论文中内生性一节的写法。
  • 机制、异质性与稳健性：三步法中介检验的问题与更可取的写法、中介敏感性分析、调节效应与交互项、组间差异检验与多重检验、稳健性检验与规格曲线。
  • 经典论文复现：用公开的原始数据逐表复现九篇经典实证论文（Mankiw–Romer–Weil、Bertrand–Mullainathan、STAR、LaLonde、Card、Angrist–Evans、Lee–Moretti–Butler、城堡法、波士顿房贷歧视），对照论文的数字，解释所有差异，再用新的方法检查结论。
  • 计量经济学进阶：非线性模型与 GMM：回归系列的续篇：多项与有序选择、计数模型、Tobit、Heckman 样本选择、分位数回归、GMM 和动态面板。
  • 随机前沿分析：复合误差模型与效率估计、分布假设与检验、无效率决定因素的一步法、面板随机前沿、与 DEA 的比较和 TFP 分解。
  • 结构方程模型：路径分析与中介，探索性和验证性因子分析，拟合指数，信度与效度，完整的结构方程模型和测量不变性，结果与 lavaan 逐一核对。
  • 空间计量入门：地图数据与坐标系、空间权重矩阵、Moran’s I 与 LISA、空间滞后/误差/杜宾模型与溢出效应、空间面板与区域收敛，以及权重敏感性、伪溢出和 MAUP 这些常见陷阱。
  • 复杂网络分析：用 NetworkX 存储和描述网络，中心性与社区发现，随机图与零模型检验，传播与韧性，金融相关性网络，网络数据的计量问题，以及这个博客自己的链接网络。
  • DID 从入门到精通：做实证研究，想用双重差分法评估政策效果。
  • 因果推断从入门到精通：DID 的姊妹篇，讲清楚随机实验、匹配与倾向得分、工具变量、断点回归、合成控制和双重机器学习该在什么时候用、怎样用。
  • 时间序列计量从入门到精通：分析 GDP、通胀、股价这类按时间记录的数据：平稳性与单位根、ARMA 与预测、协整、VAR、GARCH 和结构突变。
  • 实证研究工作流：计量方法之外的功夫：项目怎样一键复现、用 Git 管理修改、清洗和检查数据、让论文中的表和数字都由代码生成。
  • 统计学习与机器学习：写给做实证研究的人的机器学习：交叉验证与数据泄漏、正则化、树模型与梯度提升、模型解释，以及预测和因果的界限。
  • 深度学习入门：用 NumPy 手写神经网络，PyTorch 与训练技巧，卷积网络、LSTM 与 Transformer，以及在表格数据和宏观时间序列上与简单方法的诚实比较。
  • 金融实证方法：金融学论文最常用的实证工具：CAPM 与因子模型、GRS 检验、组合排序、Fama–MacBeth 回归和事件研究。
  • 期权定价与衍生品：无套利与看涨看跌平价、二叉树、Black–Scholes 公式、希腊字母与 delta 对冲、蒙特卡洛定价、隐含波动率与 Heston 模型。
  • 数据获取与文本分析：从网页和 API 获取数据，再把文本变成变量：中文分词、TF-IDF 与相似度、词典法、主题模型与文本分类，全部以这个博客本身为练习对象。
  • SQL 与数据库：用 SQLite 建立和维护研究数据库，写对汇总、连接和窗口查询，用 DuckDB 和 Parquet 在笔记本电脑上分析几百万行的数据。
  • 正则表达式：三篇讲透正则表达式，从基础语法、分组与环视，到 pandas 和中文文本清洗的实战，附速查表。
  • 文献综述与元分析：怎样写文献综述，怎样做系统综述与元分析：检索筛选、效应量、随机效应模型、异质性、元回归、发表偏倚的诊断与校正、依赖效应量、敏感性分析和报告规范。
  • 用 Python 做期货回测：以豆粕为例：从拼接主力连续合约讲起，写出不偷看未来、扣除成本的回测，再检验均线、突破、跨期套利、加仓和多品种组合这些策略到底赚不赚钱。
  • 优化建模从入门到精通：用线性规划、整数规划等方法解决生产、运输、排程等实际决策问题。
  • 运筹分析：效率评价、随机系统与动态决策：DEA 与 Malmquist 指数、熵权法和 TOPSIS 等综合评价方法的检验、库存与排队、离散事件仿真、动态规划与马尔可夫决策过程。

想轻松地了解实证研究在做什么，可以先读两篇单篇文章：三个改变经济学的研究：霍乱地图、最低工资与征兵抽签和数据会骗人：辛普森悖论、伯克森悖论、幸存者偏差与均值回归。

论文写作相关的单篇文章（怎样找研究选题、文献检索与管理、LaTeX 论文排版入门、怎样写实证论文的引言和回复审稿意见）都在 学术写作 分类下。

怎么找文章

  • 学习路线：第一次来，先看 学习路线，按你的情况推荐阅读顺序，并列出全站所有文章的介绍。
  • 专栏：适合按顺序系统学习。文章顶部可以展开整个系列的目录，底部是系列内的上一篇和下一篇。
  • 分类、标签：按主题浏览；归档：按发布时间列出全部文章。
  • 搜索：点右上角的放大镜，标题和正文都能搜到。
  • 文章目录：电脑上在文章右侧；手机上点右下角的目录按钮。

在手机上阅读

  • 添加到主屏幕：像 App 一样从手机桌面直接打开。
  • 离线阅读：在文章顶部点“保存到本机”，这篇文章（连同图片）就会保存在手机上，没有网络时也能打开；不点就不会保存。已保存的文章在菜单的 离线阅读 里，可以逐篇删除。
  • 深色模式：跟随手机的设置，也可以点右上角的月亮图标手动切换。
